Microsoft AI、「MAI Code 2」など新モデル7つを一挙投入【Ignite 2026】
コーディング、セキュリティ、画像、音声、判断の各分野で“価格性能比”を追求
樽井 秀人
2026年11月19日 15:37
「Microsoft Ignite 2026」でのMAIの基調講演
米Microsoftは11月17日（現地時間）、年次開発者イベント「
Microsoft Ignite 2026
」で、同社のAI部門Microsoft AI（MAI）が開発した7つの新しいモデル群を発表した。トークン消費が急増するなか、エージェントを24時間365日動かせるだけの“価格性能比”を重視したという。発表されたおもなモデルは、以下の通り。
コーディング：「MAI Code 2」「MAI Code 2 Flash」
コーディング向けモデル
「MAI Code 2」
は、「GPT-6.1 Sol」の98％の性能を40％のコストで実現（4つのベンチマークの平均。推論強度max、MAIは50％割引のプロモーション価格）。基礎科学研究や非常に長期のエージェント作業にはまだ最適化されていないが、企業における日常的なコーディングには十分で、コスト・性能バランスに優れる。
Microsoftによる「MAI Code 2」の性能・タスク単価比較（推論強度max、MAIはプロモーション価格）
「MAI Code 2 Flash」は「MAI Code 2」の軽量版で、コードの説明や小規模な編集、定型的な修正に適する。
両モデルとも「GitHub Copilot」で利用可能。「Flash」は「Microsoft Foundry」でも限定プレビューとして提供される。

AIコーディング
品質は上がったのに価格は1/4 ～Microsoft、軽量コーディングモデル「MAI-Code-1.1-Flash」を発表
業務アプリ：「MAI Work Flash」
「MAI Work Flash」は、「MAI Code 2 Flash」をベースに「Microsoft 365」や「FabricIQ」向けに最適化したモデル。「Excel」「PowerPoint」の操作では「GPT-6 Luna」と同等の精度・トークン効率を示す。
Microsoftの社内Excel評価における「MAI Work Flash」と「GPT-6 Luna」の成功率・トークン数の比較
さらに「Word」では、「GPT-6.1 Sol」と同程度の性能を呼び出しあたり約42％少ない入力トークンで実現。「Teams」や「FabricIQ」の処理にも活用される。
セキュリティ：「MAI Cyber 2 Flash」
「MAI Cyber 2 Flash」
はセキュリティ特化モデル。脆弱性発見の評価「CyberGym-E2E」で「GPT-6 Astra」を上回り、タスクあたりのコストは2％未満だったという。今後のAI時代ではセキュリティ・監視・防御エージェントを24時間稼働させることが重要になると見られており、最高性能だけでなくコストも重視した「MAI Cyber 2 Flash」は有力な選択肢となる。
なお、本モデルはMicrosoftのセキュリティ製品専用。同社の「MDASH」（multi-agent vulnerability identification and remediation harness：マルチエージェント脆弱性検出・修復ハーネス）では12月中旬から対象顧客のMAIプロファイルで使われているモデルを自動的に置き換えるとのこと。

画像：「MAI Image 2.7」「MAI Image 2.7 Flash」
画像生成モデル
「MAI Image 2.7」
は、「Artificial Analysis」の画像編集ランキングで1位を獲得。「GPT Image 2.6 Sunburst（max）」を5分の1の価格で上回ったという。価格は1,000枚あたり約35米ドルで、高速版の「MAI Image 2.7 Flash」は約10米ドル。

画像生成
Microsoft、画像生成AI「MAI-Image-2.6」を発表 ～「Text-to-Image Arena」で2位を獲得
いずれも「Microsoft Foundry」でパブリックプレビュー中で、「MAI Labs」では「Flash」を使った画像の作成・編集環境「Canvas」も提供される。
音声：「MAI Realtime 1」「Dragon Copilot Transcribe」
「MAI Realtime 1」
は、割り込みや相づちに対応する同社初のリアルタイム音声対話（speech-to-speech）モデル。料金は音声1分あたり0.01米ドルから（推論は別料金）。「MAI Labs」で試せるほか、「Microsoft Foundry」の限定プレビューへの登録も受け付けている。
また、
「MAI-Transcribe-2」
をベースにした「Dragon Copilot Transcribe」も稼働を開始。月1,000万件の診療で医師と患者の会話を書き起こし、多言語ワークフローのエラー率を半減させたという。
判断：「Decision 1.1」
「Decision 1.1」
（Microsoft-Decision-1.1）は、テキストを生成しない判断特化モデル（decision model）。あらかじめ用意された選択肢ごとに確率を返し、分類や判断を素早く行うことに特化しており、大規模言語モデル（LLM）よりも大幅に遅延とコストを抑えられる。
10月に発表
されたばかりの「Microsoft-Decision-1」の後継だ。
同社によると、「GPT-6.1 Sol」比で速度は50倍、コストは約79分の1。4,000の顧客が利用している。
自社環境で動かせる「MAI Licensed Weights」
あわせて、顧客自身のAzure環境でMAIモデルを運用・カスタマイズできる
「MAI Licensed Weights」
も発表された。データとカスタマイズの成果は顧客に帰属し、Microsoftによる学習利用には明示的な同意が必要。「Frontier Company」の取り組みを通じて近日提供される。
また、ハードウェア面では同社の第2世代AIアクセラレーター「Maia 200」が本番稼働に入ったことが明らかにされた。同社最大規模のモデルを動かしており、ワットあたりのトークン数は1.7倍に向上したという。
