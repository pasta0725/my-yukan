来たる「Windows Server 2028」は既定で32bitアプリを実行できない！ 「WoW64」が削除
必要ならオンデマンド機能として追加可能、マルウェア対策の一環
樽井 秀人
2026年11月25日 06:45
「やじうまの杜」では、ニュース・レビューにこだわらない幅広い話題をお伝えします。
「Microsoft Ignite 2026」のセッション「What’s new and what’s next for Windows Server」
次期サーバーOS
「Windows Server 2028」では、32bitアプリの実行に必要な「WoW64」が既定でアンインストールされる
とのこと。米Microsoftがテクニカルカンファレンス
「Ignite 2026」
のセッションで明らかにしています。動画は「YouTube」で視聴可能。
What’s new and what’s next for Windows Server | BRK418
「Windows Server 2028」では、従来の
“互換性重視”
から
“初期状態で安全”（Secure by Default）
へと、セキュリティ方針が大きく転換されました。これに伴い、
「Windows PowerShell 5.1」「WDS」が非推奨になるほか、「WSUS」や「SMB 1.0」、「VBScript」などが削除される予定
です。
「Windows Server 2028」で非推奨・削除となる機能（セッション動画より）
その一環として、「WoW64」も標準搭載ではなくなり、必要に応じて追加できるオンデマンド機能（FoD）となる見込みです。
「Windows Server 2028」では「WoW64」が既定でアンインストールされる（セッション動画より）
「WoW64」は、64bit OSで32bitアプリを動かすためのサブシステム。「Windows Server」は「Windows Server 2008 R2」（2009年リリース）以降、64bit版のみの提供となっていますが、これがあるおかげで古い32bitアプリも引き続き動かすことができたわけです。
しかし、「WoW64」は32bitのマルウェアも動かせてしまいます。また、メンテナンスが行われなくなった古い32bitアプリはセキュリティ攻撃の標的となるおそれもあります。そこで攻撃面を減らすため、既定ではOSに含まれなくなるとのこと。将来的にはサポートされなくなることも考慮に入れ、できるだけ早く、後継アプリや代替ソリューションへの移行を検討すべきでしょう。
そのほかにも、このセッションでは
レガシーBIOS（PCAT BIOS）のサポート削除
（UEFI必須）なども公表されています。また、「Hyper-V」で「Windows Server 2028」をゲストOSとして動かすには
第2世代（Gen2）仮想マシン
が必須となります。「Windows Server 2028」は現在、
パブリックプレビュー
が実施中です。
