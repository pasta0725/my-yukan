スタパ齋藤のApple野郎
レトロパソコンな見た目がたまらんッ!!!「HAGiBiS」のディスプレイつきUSB-Cハブが楽しい!!
スタパ齋藤
2026年11月25日 00:00
おもしろいような〜役立つような〜無駄なような〜みたいなガジェットをまた購入してしまった。HAGiBiSの「USB C Hub with Second Screen」というUSB-Cハブと外付けディスプレイの複合品である。
HAGiBiS「USB C Hub with Second Screen」は、USB-C接続のハブ（メモリーカードリーダー/USB-Cポート/USB-Aポート）であり、画面はPCのサブディスプレイ（USB-C Altモードによる表示）として機能する。写真はMacのサブディスプレイとして機能させている様子で、画面表示は「サブディスプレイの壁紙をMD-DOSっぽいものにした」だけのものだ。
コレ、AliExpressで9827円で購入した。Amazonでは17999円で売られていて、「う〜ん楽しそう……だけど高いっ！」て感じで我慢したが、AliExpressでは「この価格ならいいかっ！」って感じだったので買った。
てゅーか、この昔のパソコンみたいな外見っ！　デカい筐体に嵩張るCRTモニター！　こういうカタチのオモチャは多いが、この製品の場合は「ディスプレイ部分がマジなUSB-Cサブディスプレイ」となっており、現代のPC画面上に映るアレコレのほとんどを映せるッ!!!　こりゃたまらん♪　みたいな？
こーゆーよーなオモチャ的なガジェットは以前も買った。レトロパソコン系だと、「Maclock」と呼ばれるデジタル時計。初代Mac（Macintosh）のカタチをしたデジタル置き時計である。
「Maclock」というデジタル置き時計。複数ブランドから同じものと思われる「Maclock」が発売されていて、価格レンジに幅があるので購入時はご注意を。画面表示はカレンダーなどにも変えられる。
こんなサイズ感。サイズは80×91×112mmで重さは229g。USB-Cで充電して使い、バックライトをオフにした状態で最長約60日間動作する。
上記「Maclock」は「かっわいぃぃ〜ん」だが、単機能なので「萌え」はあまり長続きしない。置き時計なので役立ちはするが、そのうち「いつもの初代Macintosh型時計」という存在になり、飽きてくるでもないが、「見るたびに楽しい」って感じは薄れてくる。
だがHAGiBiS「USB C Hub with Second Screen」は、PCのUSB-Cハブでありサブディスプレイでもある。とくにサブディスプレイという汎用性を備えているので、そのうち飽きちゃう指数が低いっていうか「萌え」が長続きするガジェットだと感じている。実際、これを買ったのは2026年9月なのだが、長雨の間頻繁にコレで遊んでいたものの、まだ「あっアレを表示させたら楽しくない？」的なアイデアが出てきて、現在でもちょいちょい楽しんでいる。
というわけで今回は、このレトロパソコン型のUSB-Cハブ＆サブディスプレイ、HAGiBiS「USB C Hub with Second Screen」を軽くレビューしてゆきたいっ!!!
好きに表示して、レトロパソコンの世界に浸るもよし、実用するもよし
HAGiBiS「USB C Hub with Second Screen」の良さは、レトロパソコンのフィギュアのなかに、USB-C Altモード（USB-C Alternate Mode/オルタネードモード）でPCとつないで使えるサブディスプレイが内蔵されている点。サイズは小さいが、普通一般のサブディスプレイなので、表示は自由自在。
たとえば壁紙を変えるだけで、このレトロパソコン・フィギュアの表情が一変し、楽しさも大きく変わる。以下に表示例を示してゆきたいっ!!!
サブディスプレイなのでMacの拡張ディスプレイやミラーリング表示を行える。フツーにファインダーなんかも表示でき、画面は小さいもののまあギリギリ実用範囲だ。「この画面で原稿を書きなはれ」と言われたら、たぶんすぐに眼精疲労で頭痛がしてくると思うが。
このガジェットの雰囲気をガラリと変えるにおいて手軽な方法は、壁紙の変更。macOSに用意されている壁紙を表示可能だ。手持ちのグラフィックをmacOS壁紙として使えるので、実質的には「どの画像でもレトロパソコン・フィギュアの表示にできる」という感じ。
MS-DOSっぽいフリーの壁紙を少し改造してレトロパソコン・フィギュアの表示としてみた。わ〜98時代〜♪
ナゼかWindows95の起動画面のスクリーンショットを持っていたのでこれを壁紙に。初期のWindowsパソコンが蘇っ……てはいないが、雰囲気たっぷりで愉快。
昔のMacでCU-SeeMeというインターネットビデオチャットツールを使っているスクリーンショットを、ちょっと改造してレトロパソコン・フィギュアの壁紙に。
好きな画像をなんでも「レトロパソコン・フィギュアの表示」にすることができる。
手軽な方法なので壁紙を例にとったが、システム状況をグラフィカルに表示するアプリを全画面で表示させたりすると、このレトロパソコン・フィギュアが実用的なシステムモニターとなる。写真アプリでスライドショー表示にすれば、レトロパソコン・フィギュアがデジタルフォトフレームに！　とまあ、アイデア次第で「しっかり活用できるオモチャ的ツール」なのである。ゆえに、なかなか飽きが来なくてグレイト!!!
ちなみに上記のレトロパソコン・フィギュアの画面表示は、このディスプレイのmacOSでのデフォルト解像度となる960×540から、960×640に変更している。960×540はアスペクト比16:9のディスプレイ用の解像度だが、HAGiBiS「USB C Hub with Second Screen」の画面解像度は3:2。解像度を960×640に変更すると、アスペクト比は3:2になる。実画面のアスペクト比と解像度のアスペクト比を合わせないと、表示の縦横比が食い違って像が歪んで「なんか像の歪みでレトロ感とか全部台無し」になってしまう。
けっこうちゃ〜んとした品質のHAGiBiS「USB C Hub with Second Screen」
前後したが、HAGiBiS「USB C Hub with Second Screen」の主要なスペックなどを。
前述のとおり、USB-C Altモードでサブディスプレイとして使えて、さらにUSB-Cハブとなっているという製品だ。価格はAliExpressで9827円だったが、初期モデルと最新モデルがあって、ディスプレイ解像度が低い初期モデルが激安で中古市場などに流れていたりする可能性があるので購入時には注意が必要かもしれない。
USB-Cハブとしては、本体前面に、SD3.0/TF3.0（UHS-I）対応のSDカードスロット×1とmicroSDカードスロット×1、USB 3.0（最大5Gbps）対応のUSB-Cポート×1とUSB-Aポート×2がある。カードスロットはプッシュ・プル（Push-Pull）式で、パネで押し出すプッシュ・プッシュ（Push-Push）式ではないので、ちょっとだけ使いにくい。
本体背面には、USB-C電源入力ポート（5V/2A・補助給電専用）×1、USB-C HOSTポート（PC接続用/映像・データ同時伝送）×1、HDMI INポート（映像入力）×1、3.5mm AUXイヤホンジャック（音声出力用・スピーカー非内蔵）×1がある。USB-C電源入力ポートは、HDDやSSDなどを接続して電力が足りない場合などに使用する。
本体サイズは、約幅9.9×奥行7.1〜7.2×高さ9.4cm。3.5インチ IPS液晶（広視野角178°/アスペクト比3:2）を採用し、ディスプレイサイズは幅10.0×高さ6.9cm。本体はABS樹脂製。対応OSはmacOSとWindows（別途アプリやドライバーソフトエアは不要で接続すれば使用できる）。なお、写真は付属の角度調整用シリコンパッド（敷くと画面が約5度上に傾く）を装着した状態。これを敷くと画面が見やすく、本体が滑りにくくてなかなか快適だ。ほか長さ約1mのUSB-Cケーブル（USB 3.1 Gen 2/10Gbps/Altモード対応/USB-A変換アダプター付き）が付属する。
ディスプレイ部のネイティブ解像度は960×640。この解像度でmacOSにて各種表示を行うと、まあ小さすぎて見にくいものの、見ることができ、マウスポインターによる操作もまずまず可能。ディスプレイ自体は発色がよく視野角も広く、な〜んかとってもキレイ♪　デジタルカメラ用のディスプレイを使っているのかもしれない。
なお、ディスプレの明るさは画面右上のボタンで6段階で調節できる。また画面右下のボタンでUSBハブ/ディスプレイの電源をオンオフできる。
ちなみに、仮想的な対応解像度は800×600〜2560×1600ピクセルとなるが、1280×960ピクセルあたりを超えて高めると、キレイに見えはするが、操作は厳しい。素直にネイティブ解像度の960×640ピクセルで使うのがいいかもしれない。
ほか、全体的に使いやすい。ちょっと使いにくいのはカードスロット部がバネ式ではないところくらいで、ほかは文句なし。よくできていると思う。
てな感じのHAGiBiS「USB C Hub with Second Screen」。AliExpressにて9827円で買ったわけだが、このくらいの実用性があり、品質もそこそこ高く、そして非常に楽しく、その楽しさが長持ちしている。なので、俺的には「安いッ!!!」と思えてならない。WindowsでもmacOSでも使えるし、たぶんマニアな感じの方の多くが楽しめるガジェットだと思うし、プレゼントなお値段としてもイイ感じなので、興味があればゼヒ!!!
