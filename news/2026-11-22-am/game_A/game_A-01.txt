2018年のゲームがなぜ8年たって発売されるのかというと，海外のパッケージ事情が関係しているようだ。
当時，国内ではパッケージ版も用意され，数量限定特典として
「ロックマンX 歴代8大ボス有効武器早見表2」
が同梱されていた。
一方，
カプコンの海外公式サイト
によると，Switch用「Mega Man X Legacy Collection 1 + 2」は，「Mega Man X Legacy Collection」のカートリッジと「同2」のダウンロードコードをセットにしたものだった。
今回はLimited Run GamesのSwitch用「Mega Man X Legacy Collection 2」のカートリッジと
オリジナル特典
がポイントになる。
特典の内容は，メットールのキーホルダーと，2本のソフトをセットでしまっておけるスリップケース，そして作中の「ライトカプセル」を再現し，ライト博士の姿が浮かぶホログラムキャニスターライト，そしてワッペンだ。関連グッズをコンプリートしたいコアなファンなら見逃せないだろう。
価格は，「Mega Man X Legacy Collection 2」単体のパッケージ版
「Standard Edition」
が6500円。「Mega Man X Legacy Collection」と「Mega Man X Legacy Collection 2」のセットである
「Double Pack Edition」
が1万2900円。特典も加えた豪華版
「Maverick Hunter Edition」
は2万2600円となっている（いずれも税抜）。
「Standard Edition」
「Double Pack Edition」
予約の締め切りは日本時間
2027年1月4日1：59
。商品の発送は「Mega Man X Legacy Collection 2 Maverick Hunter Edition」が2027年9月1日〜11月30日，そのほかのバージョンは2027年4月1日〜6月30日が予定されている。
ソフトはリージョンフリーで，
Limited Run Games公式Xアカウント
を見ると，日本への発送にも対応している。
最近，ダウンロード販売が一般的になった一方，物理版の価値も再認識されているようだ。物理版の価値は，配信が終わっても手元にゲームを保存しておけること，そして品物を所有しているという満足感にある。
ここにオリジナルの特典も加わるとなればコレクターとしてはさらに嬉しいところだ。今後の展開にも注目したい。
