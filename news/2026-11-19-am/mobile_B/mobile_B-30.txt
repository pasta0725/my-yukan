「Windows Server 2028」のパブリックプレビューが開始 ～Microsoftの次期サーバーOS
既定で堅牢化された構成、NVMe対応の強化や「Intune」による管理も
樽井 秀人
2026年11月18日 14:40
「Windows Server 2028」のパブリックプレビューを告知する公式ブログ
米Microsoftは11月17日（現地時間）、「Windows Server 2028」を発表した。同日よりパブリックプレビューとして公開されており、「Windows Server Insider Program」で新機能を試せる。
「Windows Server 2028」は、
「Windows Server 2025」
に続くメジャーリリース。セキュリティとアクセス保護の水準を引き上げ、エンタープライズインフラを高速化し、大規模な管理を簡素化するとしている。
また、企業が自ら運用するインフラでAIの推論を実行する“エンタープライズハイブリッドインテリジェンス”への取り組みも始まる。ハードウェア面では、AMDのAIアクセラレーター「Instinct MI350P」が2027年上半期から、サポート中の「Windows Server」と「Windows Server 2028」でプレビュー提供される予定。ランタイム面では、「Foundry Local」「Windows ML」「vLLM」「llama.cpp」といった技術で、オープンウェイトモデルやカスタムモデルをサポートすべく取り組んでいるという。
ただし、これらのハイブリッドインテリジェンス機能は早期アクセスプログラムを通じて一部の顧客に限って提供される。OSとは別のハードウェア要件もある。
そのほかの主な強化点は、以下の通り。
セキュリティ
：初期状態からセキュリティを強化
・デフォルトで強化された「Server Core」構成
・新しいセキュリティベースライン
・「Trusted Launch」によるVM起動の保護
・「Confidential VM」のサポート開始
・自動証明書管理
・耐量子計算機暗号（Post-Quantum Cryptography）への対応
ストレージ
：最新のストレージに対応
・ネイティブNVMeストレージスタックを既定で有効化
・NVMe over TCP/RDMA対応
・ReFSからのブート対応
管理
：複雑な管理をよりシンプルに
・対象となる永続的なサーバー環境で、「Microsoft Intune」による構成・コンプライアンス・アプリ・更新の管理をプレビュー提供
・クライアントPCとサーバーを同じ管理フレームワークで運用可能
・「Azure Arc」との連携継続
・「Windows Admin Center Virtualization Mode」（WAC vMode）が正式提供（GA）
同社は「Windows Server 2028」をAI対応インフラ基盤と位置付け、AIワークロードをクライアントデバイス、オンプレミスの「Windows Server」、「Azure」クラウドの間で柔軟に配置できる世界を目指すとしている。
