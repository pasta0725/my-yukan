「MySQL」「Oracle VM VirtualBox」など幅広い製品ファミリーに影響

「Oracle Critical Security Patch Update Advisory - November 2026」
窓の杜から
ダウンロード
米Oracleは11月17日（現地時間）、「Critical Security Patch Update」（CSPU）を実施した。「Oracle Database Server」「Oracle Java SE」「MySQL」「Oracle VM VirtualBox」など幅広い製品ファミリーに対し、655件の新規セキュリティパッチが発行されている。
「CSPU」は、同社が
四半期ごとに実施している累積的な「Critical Patch Update」（CPU）
を補完するもの。優先度の高いセキュリティ修正をより小さく的を絞った形で提供することで、運用への影響を最小限に抑えつつパッチの適用を促すのが狙いだ。セキュリティパッチは毎月第3火曜日にリリースされており、今後の予定は以下の通り。
2026年12月15日：CSPU
2027年1月19日：CPU
2027年2月16日：CSPU
2027年3月16日：CSPU
Oracle Java SE
「Oracle Java SE」製品ファミリーでは、11件の脆弱性が修正された。いずれも認証なしでリモートから悪用が可能で、「CVSS 3.1」ベーススコアは最大で「8.1」と評価されている。
この「8.1」と評価された「CVE-2026-114938」は、
「Java4Shell」
とも呼ばれるリモートコード実行（RCE）につながる可能性がある脆弱性だ（
「CVSS 4.0」
での暫定評価は「9.2」）。外部から送信された不正なBase64データが認証前の処理に渡される構成のアプリケーションなどで、認証を必要とせず悪用可能と報告されており、「OpenJDK」にも影響する。
JFrog Security Researchによると、「Java4Shell」が影響する主な系列と修正版は以下の通り。
OpenJDK/Java SE 17：v17.0.21.1への更新が必要
OpenJDK/Java SE 21：v21.0.13.1への更新が必要
OpenJDK/Java SE 25：v25.0.5.1への更新が必要
OpenJDK/Java SE 27：v27.0.1.1への更新が必要
なお、本脆弱性はBase64デコーダーのx86-64向け実装に存在するメモリ破壊の不具合だ。AVX-512 VBMIをサポートするx86-64 CPUにのみ影響し、ARM64環境などは影響を受けない。
MySQL
「MySQL」製品ファミリーの新規修正は10件で、うち3件は認証なしでリモートから悪用が可能。もっとも深刻なものは「CVSS 3.1」ベーススコアが最大の「9.8」と評価されている。
修正版はv8.4.13.1、v9.7.4.1、v26.10.0.1だが、執筆時点ではまだ公開されていないようだ。
仮想化（Virtualization）
仮想化製品に関する新規の脆弱性修正は、全11件。「CVSS 3.1」ベーススコアの最大は「8.6」で、認証なしでリモートから悪用可能なものも3件含まれる。Oracleのリスクマトリックスでは、いずれの脆弱性も「Oracle VM VirtualBox 7.2.22」に影響するとされている。
修正版はまだリリースされていないようだが、公開され次第アップデートしておきたい。
