「Windows Server 2016」の延長サポート終了まであと60日を切る ～Microsoftが注意喚起
基本的には2027年1月の「Windows Update」が最後のパッチ
樽井 秀人
2026年11月18日 16:45
「Windows メッセージ センター」に掲載された告知
米国太平洋時間2027年1月12日（日本時間13日）、「Windows Server 2016」の延長サポートが終了する。米Microsoftが11月13日（現地時間）、「Windows メッセージ センター」で改めて注意を呼び掛けている。
「Windows Server 2016」は2016年10月に
リリース
されたサーバーOS。メインストリームサポートは2022年1月にすでに終了しており、現在はセキュリティ更新プログラムなどのみが提供される延長サポートの期間にある。
延長サポートにおける最後のアップデートは、2027年1月のセキュリティ更新プログラム（Windows Update）となる。それ以降もセキュリティ更新を受け取るには、企業向けに提供されている
「拡張セキュリティ更新プログラム」（ESU）
への加入が必要（基本的に有償）。最大で2030年1月7日（米国太平洋時間）までセキュリティ更新を受け取れる。
ただし、ESUの対象はStandardとDatacenterのみ。Essentialsは対象外で、［Remote Web Access］などの固有機能もサポートを終了するため、移行が必要だ。
