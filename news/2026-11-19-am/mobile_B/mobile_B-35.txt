MicrosoftがAI戦略を大幅アップデート、Copilotは「仕事の新しいOS」へ。Salesforce連携やGPT-6.2提供も【Ignite 2026速報】
エージェントによる自律型サイバー防衛システムも提供開始
高橋 正和
2026年11月18日 10:40
Microsoft Ignite 2026
Microsoftのテクニカルカンファレンス「
Microsoft Ignite 2026
」が2026年11月17日（米国時間）に開幕した。米サンフランシスコ会場とリモートのハイブリッドで開催している。
基調講演ではMicrosoftのCEOのSatya Nadella氏が登壇し、「Building the frontier ecosystem（最先端のエコシステムを作る）」のテーマのもと、同社の提供するAIについて語った。
MicrosoftのCEOのSatya Nadella氏
そのための3つの柱として「Copilot」「IQ」「Agent 365」を挙げ、さらにそれを支えるAzureのインフラもあわせて紹介。それぞれについて新発表をアナウンスした。
3つの柱
本記事では、それらの発表についてレポートする。
「Copilot」分野
「Copilot」分野については、Copilotとさまざまなアプリケーションとの統合がアナウンスされた。
Copilotは「仕事の新しいOS」になる
Nadella氏は「Copilotは『New OS for Work（仕事の新しいOS）』」と語り、企業はそこで「Home」「Copilot内のOffice」「Code」「Autopilot」が使えるとアナウンスした（Frontierプログラムでの公開）。
Copilotでの「Home」「Copilot内のOffice」「Code」「Autopilot」
また、Copilotを特定の業務に適合させるためのスキルやコネクター、プラグインを整備して提供するとアナウンスした。
スキルやコネクター、プラグインの整備
Salesforceとのパートナーシップ「Copilotforce」
Salesforceとのパートナーシップ「Copilotforce」も発表された。Salesforceを、CopilotやTeams、Fabricとつなぎ、相互にデータを利用できるようにし、たとえばSalesforce上のデータをCopilotで扱えるようにする。また、Accentureが、設計や実装のパートナー、さらに先行顧客として参加する。
パートナーシップ「Copilotforce」
SalesforceのRohan Kumar氏が登壇
GitHub Copilotの新機能
そのほか、傘下のGitHubについて、10月下旬に発表されたリポジトリを横断してプロジェクトを管理する「GitHub Copilot Projects」や、モデル自動選択の「GitHub Copilot Fusion」も紹介された。
GitHub Copilot Projects
GitHub Copilot Fusion
情報やファイルをチームやAIと共有する「Copilot Workspaces」
プロジェクトの情報やファイルをまとめて、チームやAIと共有する「Copilot Workspaces」もアナウンスされた。「Copilot Notebooks」からのリニューアルだ。
Copilot Workspaces
「IQ」分野
「IQ」分野では、AIのモデルやデータ関連が発表された。
350以上のサードパーティのIQ Connector
まず、Microsoft IQにおいて、350以上のサードパーティのIQ Connectorが用意されているとアナウンスされた。
350以上のサードパーティのIQ Connector
「選択肢を選ぶ」判断特化のAIモデル「Microsoft Decision 1.1」が一般提供、高速かつ安価に
判断特化モデル（decision model）の「Microsoft Decision 1.1」がGA（一般提供開始）となった。
文章を返すのではなく、Yes/Noや選択肢の中から答えを判断して返すモデルだ。これにより、高速で安価に利用できる。
Microsoft Decision 1.1
GPT-6.2シリーズもMicrosoft Foundryで提供開始
Azure上のAIプラットフォーム「Microsoft Foundry」で、GPT-6.2シリーズのAIモデルがGA（一般提供開始）となった。
Microsoft Foundry上のGPT-6.2シリーズのAIモデルがGAに
Meta「Muse Wonder」など最新モデルもMicrosoft Foundryで利用可能に
同じくMicrosoft Foundryで、Metaの最新のモデル「Muse Wonder」「Muse Spark 1.3」「Muse Ember」が利用になったこともアナウンスされた。
Metaの最新のモデルがMicrosoft Foundryに
MicrosoftのAIモデル「MAI」シリーズの重みを提供する「MAI Licensed Weights」ライセンス
MicrosoftのAIモデル「MAI」シリーズについて、AIモデルの重み（モデルのデータ）を提供する「MAI Licensed Weights」ライセンスが発表された。ユーザー企業が独自のAzure環境に、MAIモデルをデプロイしたりカスタマイズしたりできるようになる。
MAI Licensed Weights
MAIシリーズのコーディングモデル「MAI Code 2」「MAI Code 2 Flash」
コーディングモデルにおいては、「MAI Code 2」および軽量版の「MAI Code 2 Flash」が発表された。MAI Code 2はコーディングタスクで、GPT 6.1 Solの98%のパフォーマンスを40%のコストで、Claude Opus 5.5の96%のパフォーマンスを5%のコストで実現すると謳われている。
MAI Code 2
他コーディングモデルとの比較
MAI Code 2 Flash
「MAI Image 2.7」「MAI Cyber 2 Flash」「MAI Realtime 1」も
そのほか、画像の「MAI Image 2.7」や、サイバーセキュリティの「MAI Cyber 2 Flash」、リアルタイム音声の「MAI Realtime 1」も発表された。
MAI Image 2.7
MAI Cyber 2 Flash
「Agent 365」分野
「Agent 365」分野では、AIの管理に関する新発表がアナウンスされた。
AIへの支出を分析する「Agent 365 Business Analytics」
AIへの支出をモニターして分析する「Agent 365 Business Analytics」が発表された（Frontierプログラムでの公開）。
Agent 365 Business Analytics
Agent 365 Business Analyticsのデモ
AIエージェントによる自律型防衛システム「Microsoft Perception」がGA
サイバーセキュリティの分野では、AIエージェントによる自律型防衛システム「Microsoft Perception」がGA（一般提供開始）となった（従来の名称は「Project Perception」）。
昨今のAIを使ったマシンスピードのサーバー攻撃を想定し、AIエージェントが、攻撃者視点で脆弱性を発見する「Red team」、脅威を発見し調査する「Blue team」、修正する「Green team」に分かれて、検出と対応を繰り返す。
Microsoft Perception
業界エコシステム「AI Transparency Initiative」
AIモデルとエージェントに関する企業から信頼を得るための業界エコシステム「AI Transparency Initiative」も発表された。
AI Transparency Initiative
Azureのインフラ分野
これらを支えるものとして、Azureのインフラにおける新発表もアナウンスされた。
PostgreSQL互換「Azure HorizonDB」がGA、「Fabric HorizonDB」も発表
データインフラ分野では、PostgreSQL互換のマネージドデータベース「Azure HorizonDB」がGA（一般提供開始）となった。
また、Microsoft Fabricで動くサーバーレスの「Fabric HorizonDB」も発表された（パブリックプレビュー）。
Azure HorizonDB
Fabric HorizonDB
独自のARMプロセッサ「Cobalt 200」を使ったVMが提供開始
Azureで、Microsoft独自のARMプロセッサ「Cobalt 200」を使ったVMがGA（一般提供開始）になったことも発表された。14リージョンで開始し、2026年内に23リージョンに拡大する予定。
「Cobalt 200」を使ったVMがGA
