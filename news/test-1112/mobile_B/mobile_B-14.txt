無料プラン廃止とストレージ制限の衝撃！　「Microsoft 365 Education」新プランに見る――“アメとムチ”の戦略でGoogleの牙城は崩せるか

[

ITmedia

Microsoftは11月5日（米国時間）、教育機関向けに提供している
「Microsoft 365 Education」のプラン改定を発表
した。同社は近年、クラウド型生産性向上スイート「Microsoft 365」でAIアシスタント機能「Copilot」をバンドル提供するのに合わせ、既存プランの整理を進めている。Microsoft 365 Educationもこの流れに沿った形だ。
一方で今回の改定は、既存の無料プラン廃止に伴う新プランの登場、プラン全体へのストレージ容量制限、これまで無料版にはなかったデスクトップ版Officeアプリの提供など、利用者にとってメリットとデメリットが入り交じった複雑な内容となっている。
教育分野でライバルに既存顧客を奪われず、将来のビジネスの“種”となる学生ユーザーをいかに確保するか――Microsoftの苦慮する姿が浮かび上がってくる。

Microsoft 365 Educationのページ
旧プランと新プランの比較に見るアメとムチ
まずは新旧プランを比較してみよう。旧プランの機能比較チャートと、新プランのティア表を並べたので確認してほしい。
従来、Microsoft 365 Educationは「A1」「A3」「A5」の3プランで構成されていた。A1は無料プランで、A3とA5は有償プランだ。チャートを見ると分かるが、A1は教育機関（のドメインを持つ組織）であれば誰でも利用できる一方、デスクトップ版Officeは使えず、Web版のみとなる。
OneDriveのストレージ容量は1ユーザーあたり100GB（組織ドメインのテナント合計で100TB以内）で、メールなどもこの範囲内で利用できる。
またMicrosoft 365 Education特有の仕組みとして「Student Use Benefit」（学生使用特典）がある。A3またはA5の有償プランを包括契約すると、1ライセンスにつき40ライセンス分の生徒・学生向けライセンスが追加費用なしで付与される。つまりA3／A5は教員向けのライセンスであり、教室内の最大40人の学生にStudent Use Benefitを適用することで、比較的安価にMicrosoft 365を利用できるというわけだ。
旧プランのMicrosoft 365 Educationで提供されるA1／A3／A5の機能比較（抜粋）
これに対し、11月5日に発表された新プランではA1が廃止され、代わりに「A0」「A2」「A7」が新設された。正確には、A7は発表済みで2026年10月1日に提供を開始しており、A2は12月1日から提供を開始する。新たな無料プランとなるA0は、A1の廃止日である2028年1月1日から提供が始まる。
廃止予定のA1は、11月5日時点で既にWeb経由での一般提供を終了している。2027年5月1日にはCSP（クラウドソリューションプロバイダー）経由などでのボリュームライセンス提供を終え、2028年1月1日をもってサービス自体が終了する。
つまり既存のA1ユーザーは、それまでに無料のA0か有償のA2へ移行しなければならない。加えて、同じタイミングで前出のStudent Use Benefitも廃止されるため、A3／A5の包括ライセンスで学生向けアカウントを提供していた組織も、A0かA2への移行を迫られることになる。
新プランのMicrosoft 365 Educationで提供されるA0／A2／A3／A5／A7の機能比較とストレージ容量
問題は、新プランではStudent Use Benefitほど有利な仕組みがなくなり、実質的に有償プランへ誘導される可能性が高いことだ。A0は従来のA1のように「組織全体を無償ライセンスで契約する」ことはできず、Student Use Benefitと同様、有償プランとの組み合わせが必須条件となる。
しかも、その比率は「1：40」から「1：20」に減らされた。一般的な学校の1クラスあたりの人数が30〜40人であることを考えると、教員向けプランを多めに契約するか、生徒・学生向けにもA0ではなくA2以上の有償プランを用意する必要がある。
A0のもう1つの難点は、Microsoft 365の基本といえる機能が一切付いていないことだ。メールやスケジュール管理のExchange、コラボレーションツールのTeams、ファイル共有のSharePoint Onlineなどはデフォルトで用意されない。Teamsは全プラン共通で付与の有無を後から選ぶ形だが、A2にはCopilot ChatやMicrosoft Classroomが付くなど、上位プランほど標準機能が増える仕組みだ。
有償プランへの誘導が前提である以上、生徒・学生ごとに必要な機能を見極め、複数のプランを組み合わせる運用が基本になる。さらにA0の標準ストレージ容量は「0」で、教員向けなどA2以上の有償プランが提供するストレージプールの容量を共用することになる。
デメリットばかりが目立つA0だが、唯一といえるメリットもある。従来の無料プランであるA1では使えなかったデスクトップ版Officeが利用できる点だ。Web版OfficeともどもWindows上での利用が条件となるが、制限だらけのA0にあってこの点は大きいだろう。
ただし、Student Use Benefitでは標準でデスクトップ版Officeを利用できていた。Student Use Benefitの既存ユーザーがA0へ移行した場合、この点は条件が変わらず、むしろ他の機能が制限されるぶん“デグレード”したという印象の方が強くなるかもしれない。
