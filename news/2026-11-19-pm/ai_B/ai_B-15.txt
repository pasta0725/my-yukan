Windows Server 2028がパブリックプレビュー公開。Microsoft FoundryなどAIによる推論の実行基盤へと拡張
2026年11月19日
マイクロソフトは日本時間11月18日未明に開幕した年次イベント「Microsoft Ignite 2026」で、次期サーバ向けOSとなる
Windows Server 2028のパブリックプレビュー公開を発表しました
。
企業内のAI推論基盤へと拡張
Windows Serverはこれまで、Active Directoryによるユーザーやリソースの管理、アプリケーションの実行基盤などとして利用されてきました。
Windows Server 2028では新たにMicrosoft FoundryやWindows ML、vLLM、Llama.cppなどによる企業内でのAI推論を実行するための基盤としての役割も担うようになります。
セキュリティやストレージ、管理面も強化
セキュリティ面での強化も予定されており、Server Coreのセキュリティ強化、仮想マシン群のブート整合性を保証し仮想マシンの保護を拡張するTrusted Launch、処理内容をハードウェアレベルで暗号化することで外部から内容を読み取られないようにするConfidential VM機能、自動証明書管理やポスト量子暗号技術なども搭載予定です。
ストレージではNVMeストレージをデフォルトで有効にし、ストレージとの接続プロトコルとしてNVMe over TCPとRDMAにも対応。ReFSからの起動も可能にしました。
プレビューとなったWindows Server向けのMicrosoft Windows Intuneサポートにより、Windows Serverのコンフィグレーション、コンプライアンス、アプリケーション、更新状況などのエンドポイント管理ワークフローが提供されます。
Windows Server 2028は現行のWindows Server 2025に続くメジャーバージョンアップとなる予定です。
