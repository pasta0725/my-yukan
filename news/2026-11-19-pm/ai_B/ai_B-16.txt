［速報］マイクロソフト、コーディング用AIモデルとして高性能かつ低価格「MAI Code 2」「MAI Code 2 Flash」発表
2026年11月18日
マイクロソフトは日本時間11月18日未明に開幕した年次イベント「Microsoft Ignite 2026」で、同社が開発したコーディング用AIモデルのフラグシップで高性能かつ低価格を売り文句とする
「MAI Code 2」と、さらに安価な「MAI Code 2 Flash」を発表しました
。
競合と同等性能を低価格で提供
MAI Code 2とMAI Code 2 Flashは企業における日常的なコーディング作業向けに設計された2つの新しいコーディング用のAIモデルです。
いずれも競合製品と同等の性能をより安価に提供することをセールスポイントとしています。
MAI Code 2は本番環境などに対応
MAI Code 2は本番環境用のコード生成や難しいデバッグ、リポジトリの推論、ダッシュボードやビジュアライゼーションなどのUI構築において優れたAIモデルです。
マイクロソフトによると、GitHub Copilotで日常的に見られる企業向けコーディングタスクを対象とした4つのベンチマークの平均値では、MAI Code 2はGPT 6.1 Solの98%、Claude Opus 5.5の96%の性能を発揮しつつ、コストはGPT 6.1 Solの40％、Claude Opus 5.5のわずか5%だとしています。
MAI Code 2 Flashは低コストで高品質
MAI Code 2 Flashは、コードの解説、局所的なコードの編集、ルーチンワーク的なコードの修正など、日常で大量に発生する作業向けに設計されたAIモデルで、徹底的な低コストと品質の両立を実現するものです。
マイクロソフトによると、日常的に多く発生するルーチンワーク的なコーディング作業に関わる3つのコーディングベンチマークにおいて、MAI Code 2 FlashはGPT-6 LunaやClaude Haiku 5.5と同等の性能を発揮しつつ、コストはGPT-6 Lunaの65%、Claude Haiku 5.5の20%程度だとしています。
