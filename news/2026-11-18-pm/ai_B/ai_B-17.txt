［速報］Azure SQL Databaseをローカルで実行する「Azure SQL Database local development container」パブリックプレビュー
2026年11月18日
マイクロソフトは日本時間11月18日未明に開幕した年次イベント「Microsoft Ignite 2026」で、Azure SQL Databaseをローカルで実行する「Azure SQL Database local development container」の
パブリックプレビューを発表しました
。
Azure SQL Database local development containerは、クラウドであるMicrosoft Azure上のAzure SQL Databaseで使用されているのと同じデータベースエンジン、T-SQL、システムビュー、接続プロトコル、ドライバ、Always Encrypted、ベクターサーチなどを備えています。
そのため開発者は、これまでAzure SQL Databaseで使っていた同じフレームワークやライブラリ、Visual Studio Codeなどのツールを使って、ローカル環境で稼働するAzure SQL Databaeに接続し、開発やデバッグ、ビルドやテストなどを実行できるようになります。
またVS CodeからSQL Serverを操作できるMSSQL extension for VS CodeにはローカルのAzure SQL Databaseからクラウドへ移行するための新機能「Local-to-Cloud Deployment Wizard」が同じくパブリックプレビューとして搭載されました。
