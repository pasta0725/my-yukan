AIが時代遅れのWebサイトを書くのを防ぐスキル「Modern Web Guidance」が安定版に
「Edge」「Firefox」も参加、Webサイトのモダナイズにも
樽井 秀人
2026年11月17日 10:02
「Modern Web Guidance」のドキュメント
米Googleは11月10日（現地時間）、「Modern Web Guidance」v1.0を安定版としてリリースした。「Modern Web Guidance」は、AIコーディングエージェントに、最新のWeb開発手法やブラウザー互換性の知識を与えるスキル集。今年5月の「Google I/O」で早期プレビュー版が発表されていた。
AIが生成するコードは、動作してもアクセシビリティや性能、安全性に改善の余地がある。JavaScriptで複雑に実装した処理を、最新のHTMLやCSSで簡潔に書ける場合もある。
「Modern Web Guidance」は、対応させたいブラウザーの条件に合わせ、適切な機能や実装方法をエージェントに提案する。
v1.0の主な特徴
v1.0の主な特徴は以下の通り。
既存のHTML、CSS、JavaScriptや「package.json」を解析し、最新化できる箇所を提案するワークフローを追加。当初は静的解析で検出できる一部のパターンが対象
専門家が検証したガイドを拡充し、技術分野ごとの責任者やアクセシビリティ専門家によるレビューを強化
全ガイドを評価対象とし、導入効果を公開ダッシュボードで提示
また、v1.0では「Google Chrome」だけでなく、「Microsoft Edge」や「Firefox」が加わったのもトピック。クロスブラウザーのプロジェクトとなり、それぞれのWebブラウザーで互換性の改善やプロジェクトへの貢献も行われる。
使い方
「Modern Web Guidance」は、プロジェクトのディレクトリで以下のコマンドを実行すればインストールできる。以前のバージョンからは「update」コマンドでv1.0へ更新可能。
npx modern-web-guidance@latest install
そのほかにも、「Claude Code」「Codex」「Cursor」「Antigravity」「Copilot」「WebStorm」「Kimi Code」「Grok Build」といった主要なコーディングエージェントのプラグインマーケットプレイスからもインストール・更新できる。
同社は
「Chrome DevTools for agents」
との併用も推奨している。「Modern Web Guidance」で実装を支援し、「Chrome DevTools for agents」で実際の動作や性能を検証することで、改善を効率よく進められるという。
