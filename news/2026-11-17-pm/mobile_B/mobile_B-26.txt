インプレス、AI機能を網羅した『Visual Studio Code完全入門 改訂2版』を発売
新たに第7章『GitHub Copilotを活用しよう』を追加
長谷川 正太郎
2026年11月17日 11:58
『Visual Studio Code完全入門 改訂2版 GitHub Copilot対応 Webクリエイター&エンジニアの作業がはかどる高機能エディターの操り方』
（株）インプレスは11月17日、プログラミングやWeb制作の現場で広く使われる「Visual Studio Code」の解説書『Visual Studio Code完全入門 改訂2版 GitHub Copilot対応 Webクリエイター&エンジニアの作業がはかどる高機能エディターの操り方』を発売した。価格は2,860円。
本書は2022年3月に刊行された初版の改訂版であり、約4年ぶりの全面見直しとなる。初版の特徴であった『初めて使う人がインストールから順に読み進めれば一通り使えるようになる』という構成を維持しつつ、すべての画面と手順を最新版に合わせて更新している。これに伴い、ページ数も初版の272ページから304ページへと増加した。
今回の改訂における最大の変更点は、AI（人工知能）機能に関する解説の追加。2024年12月にAI機能「GitHub Copilot」の無料プランが提供開始された背景などを受け、新たに第7章『GitHub Copilotを活用しよう』が設けられた。また、第1章でも2026年4月よりエディターに標準搭載となった［GitHub Copilot］や、同年5月にプレビュー版が公開された［エージェント ウィンドウ］の紹介が含まれている。
新設された第7章では、GitHub Copilotの全体像や料金プランの解説をはじめ、AIによるコードの提案やインラインチャットといった主要機能を取り上げている。さらに、チャット機能における『Ask』（質問）、『Plan』（計画）、『Agent』（実行）という3つのエージェントの使い分けや、MCP（Model Context Protocol）を利用した実践的な手順までカバーしている。
追加された第7章『GitHub Copilotを活用しよう』
本書は、Webクリエイターや若手エンジニア、プログラミング入門者だけでなく、使い慣れた環境のままAIを活用したコーディングを始めたい人や、AIの支援を受けながらプログラミングに挑戦したいビジネスパーソンなどを対象としている。
