Adobe MAX 2026 Sneaksで10の新技術、うち2つは今すぐ試せる
笠原 一輝
2026年11月12日 11:31
Adobe MAXのSneaksの様子
Adobeは11月10日から、同社の年次イベント「Adobe MAX 2026」を、米国フロリダ州マイアミビーチ市の会場で開催している。その2日目の夕方には、Adobeの年次イベントで恒例となっている「Sneaks」(スニークス)が開催された。AdobeイベントでのSneaksは、Adobeの研究開発部門となる「Adobe Labs」に属する若手研究者が自分の進めている研究を発表する晴れの場。このSneaksで認められて、その後Photoshopの機能に採用されたり、新しいアプリとしてCreative Cloudのラインナップに加わったりなどもあり、若手研究者にとっては「登竜門」となるイベントでもある。
その反面、Adobe MAXの参加者というAdobeを見る目には一家言あるクリエイターに「批評」を受ける場にもなる。特にSneaksは夕方に開催されるということもあり、夜に行なわれるAdobe MAX全体の巨大パーティとなる「BASH」の前哨戦として、観客にはビールなどのアルコール飲料が配られるため、つまらない発表を行なうとブーイングまではいかなくても、「沈黙」という厳しい批評が研究者に浴びせられることになる。
今回のSneaksでは動画、音声、静止画の3つの分野で、合計10の開発中のソフトウェアやサービスが公開された。たとえば、手を使って編集を行なうProject Hands Onや、背景などの凹凸に自動で調整して文字などを書き込めるブラシのProject Deep Brushなどが注目を集めた。
真面目な雰囲気の中で行なわれる基調講演とは異なりくだけた雰囲気の中で行なわれるSneaks
2日目の基調講演の様子、映像監督でインフルエンサーのドレックス・リー氏によるデモ
Adobe MAXは、同社の主力製品であるCreative Cloudを利用して創作を行なうクリエイターを対象としたイベントだ。このため、初日の基調講演では、同社の幹部(今回の場合は現CEO シャンタヌ・ナラヤン氏、次期CEO アニール・チャクラヴァーシー氏)が登壇し、同社のクリエイターツールの戦略や新製品などに関して説明している。

上記の基調講演は、午前中の9時から行なわれることもあり、真面目なビジネスの内容も含み、参加者も真剣な面持ちでそれを聞いているというものになる。2日目の基調講演はもう少しカジュアルで、世界の著名なクリエイターがゲストとして呼ばれ、自分がどのような創作活動を行なっているのかを説明する内容になっている。
今回は米国の映像監督でインフルエンサーのドレックス・リー氏、クリエイティブ・ディレクターのシオバン・マローニ氏などのクリエイターをゲストとして呼び、Adobeクリエイティブ・エヴァンジェリズム責任者ジェイソン・ラヴィーン氏などが登壇して創作のあり方などに関して議論が行なわれた。

Adobe MAXではそうした基調講演や、Breakout Sessionと呼ばれる分科会(より細かいテーマに関して説明される会議のこと)が行なわれ、Creative CloudやFireflyなどに関しての詳細や使い方などが説明されたりする。
また、「Creative Park」と呼ばれる展示会では、そうした発表された製品などのデモが行なわれており、クローズドベータで、まだ実際に試すことができないような新製品や新機能などを試すことができる。
そうした講演や展示会などは、米国でのIT企業の年次イベントでは一般的なもので、その意味ではAdobe MAXもほかの年次イベントと大きな違いがあるわけではない。
しかし、1つだけ大きな違いがあるとすると、夕方から行なわれるSneaksだ。Sneaksは現地時間の18時から1時間という、絶妙な時間から行なわれる。Adobe MAX全体のスケジュールでいうと、このSneaksの後には「BASH」(バッシュ)と呼ばれるイベント全体のパーティが行なわれる予定になっており、俗な言葉でいえば皆「準備万端」という状況になっている。それに加えて、SneaksではBASHの前哨戦としてビールなどのアルコール飲料が配布される。といっても、1本ないしは2本といったところではあるが、人によっては既に出来上がった状態で見ているという状況だ。
こうした状況に加えて、ステージ上でプレゼンしているのは、Adobeの幹部社員ではなく、Adobeの若手研究者だ。これだけの条件が整えば見ていて面白くないわけがない。参加者はみなステージの出し物をゲラゲラ笑いながら見ている。もちろん、自分のビジネスである創作活動に本当に役に立ちそうだと思えば、ヤンヤの歓声を上げるし、そうでなければ沈黙で応える……そうしたユニークなイベントがSneaksなのだ。
このため、SneaksはAdobeの年次イベントの中で最も人気のセッションとされており、Adobe MAXに来たからにはこれを見ずには帰れないというセッションだ。
Adobeにとっては将来製品に採用する技術やアプリなどを公開して反応を見る場として活用
Sneaksでのデモ。Adobeの若手研究者が登壇してプレゼンする
Adobe側にとっても、このSneaksは大きな意味がある。というのも、このSneaksに研究を発表する若手研究者は、Adobeの研究開発部門であるAdobe Labsに属している。Adobeにとってもビジネスを成長させるために、今の主力製品であるPhotoshopやPremiere、Illustratorなどの機能を強化していくのはもちろんのこと、新しいアプリケーションを開発して投入していく必要がある。
このSneaksで発表される「Project～」はそうした将来の新機能や製品の候補となる。そうした発表前の製品や技術などを、Adobeにとっての最重要の顧客であるCreative Cloudのユーザーであるクリエイターに公開して、その反応を見て将来の製品化への参考にするという側面がある。
なお、Adobeでは開発中の技術や製品は「Project～」の開発コードネームで呼ばれている。近年でいえば、Classicではないクラウドベースの新しいLightroomの開発コードネームが「Project Nimbus」だ。そこまで大規模な製品ではなくても、Photoshopの新機能として昨年(2025年)搭載された「調和」は「Project Perfect Blend」として2024年10月のAdobe MAX Sneaksで公開された機能が実装されたものになる。

Adobeのデザインエヴァンジェリストのケルセイ・スレイ氏(左)、俳優・テレビ司会者 テリー・クルーズ氏
今回のSneaksは、米国の俳優・テレビ司会者のテリー・クルーズ氏とAdobeのデザインエヴァンジェリストのケルセイ・スレイ氏が司会をする中で行なわれた。
SneaksはAdobe MAXと、Adobeのもう1つの年次イベントで、大企業向けのクラウドソリューションのイベントであるAdobe Summitのどちらでも行なわれているのだが、いずれもAdobeの「しゃべれる」エヴァンジェリストと「ツッコミ」ができるコメディアンや俳優という組み合わせで行なわれるのが定番になっている。今回のSneaksでもそうで、クルーズ氏が鋭いツッコミを入れて、Adobeの研究者が立ち往生というシーンが何度も見られ、その度に観衆からはヤンヤの歓声が起こった。
なお、今回Sneaksで発表された「Project Deep Brush」と「Project Hands On」に関しては
Adobe LabsのWebサイト
で実際に試すことが可能になっている。従来はベータ版になるまで試すことができなかったので、実際に自分ですぐに試すことができるのは嬉しいところで、興味ある方はぜひ試してみていただきたい。
Project Screen Test
Project Screen Testでは、架空のキャラクターの外見、声、性格を作り込み、そのキャラクターと会話しながら、人物像やさまざまなシーンでの反応を探ることができる。キャラクター作りをはじめとする物語づくりの工程を、会話を通じてより直感的で表現豊かなものにできるかを探るプロジェクトだ。
Project Link Up
Project Link Upは、クリエイターのジェスチャーから意図をくみ取り、デザイン要素を1つの絵にまとめ上げる手法を探るプロジェクトだ。たとえば、イラストの駐車スペースに車をドラッグすると、プロジェクトが遠近感、スケール、スタイルをシーンに合わせて調整する。できたイラストは、さらに磨き込める編集可能なベクターアートワークになる。
Project Scene Sweep
複数のショットにわたって動画を編集すると、同じ変更を何度も繰り返すことになりがち。Project Scene Sweepでは、シーケンス全体にわたる登場人物、ロケーション、シーンを理解し、カットやカメラアングルをまたいで一貫した編集を適用できるようにする。クリエイターがクリエイティブな判断を一度行なうだけで、それがシーン全体に反映されるのを確認できる。
Project Rinse Repeat
Project Rinse Repeatは、画像のある部分で行なった編集を取り込み、別の部分に、その領域に合わせてインテリジェントに調整しながら適用する。編集はPhotoshopのネイティブツールで再現されるため、編集可能な状態のまま、さらに調整を加えられる。同じような手順を何度も繰り返してやる必要がないというAIベースでクリエイターを助けてくれるツール。
Project On Cue
Project On Cueでは、生成された動画の中でアクション、光の点滅、そのほかのイベントのタイミングを指定できる。編集可能なタイミング信号は、手で描くことも、動画や音楽から抽出することもでき、動きとサウンドをぴたりと合わせられる。動画の中で何がいつ起こるかを、細かく調整して指示できるツールだ。
Project Deep Brush
Project Deep BrushはAIを使って画像の形状、色、ライティングを理解し、新しい描き方や編集方法を可能にする。ブラシストロークは面の輪郭に沿わせることができ、自然な影を保ったまま色を変更でき、光をシーンに直接描き込むこともできる。まるでブラシが、描いている画像を理解しているかのように動くツール。
Project Sound Bender
動画を作成するときに、そのシーンにあった適切なサウンドを見つけるだけでも大変だが、それをストーリーに合わせて動かし、変化させるのはさらに大変だ。Project Sound Benderでは、サウンドを言葉で説明して完成したミックスから取り出し、インタラクティブなキャンバス上でバリエーションを探すことができる。サウンドをリアルタイムで形づくったり、動きを動画に合わせたり、説明文から新しいものを生み出したりが可能になる。
Project Live Set
再生中の動画を、そのまま監督になっていろいろと変えられたら……という発想から生まれたのがProject Live Set。シーンが進行している間に、被写体を変更したり、環境を変化させたり、カメラの動きを切り替えたりできる。動画が、その瞬間に応えるクリエイティブなキャンバスのように感じられるツール。
Project Sight Span
Project Sight Spanは、1枚の静止画を、クリエイターが中に入って探索できるナビゲート可能な3Dデータに変換し、カメラのアングルを変えるような形で、新しいアングルを見つけたり、元のフレームの外までショットを構成したりできるようにする。アップスケーリングの機能も用意されており、高解像度に変換することも可能。1枚の画像が、世界全体の始まりになるようなイメージのツール。
Project Hands On
Project Hands OnはAIを使って画像に何が写っているかを理解し、キャンバス上に直接コントロール点を作成して、クリエイターがそれを調整することでサイズを縮めたり、伸ばしたりできる。そうした直感的な画像編集を可能にするツール。
