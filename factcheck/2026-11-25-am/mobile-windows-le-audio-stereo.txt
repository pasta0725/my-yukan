===== https://www.notebookcheck.net/Windows-11-fixes-muffled-Bluetooth-headset-audio-during-mic-use.1456773.0.html
(status 200)
Microsoft has released Windows 11 Insider Preview Build 26340.10032 to the Experimental channel, and its main change tackles a long-standing Bluetooth headset complaint. The November 20, 2026, build for Windows 11, version 26H2, lets compatible Bluetooth LE Audio headphones, earbuds, and speakers play full-range stereo at 48 kHz while their microphone is in use.             
Microsoft lists game chat, voice calls, voice typing, and voice chat in Copilot Chat as the main use cases. Windows 11 already offered super wideband stereo during mic use on some version 24H2 systems running Build 26100.4484 or newer. The new build adds a higher-fidelity 2-channel, 16-bit, 48000 Hz option.             
How to enable 48 kHz stereo playback
Insiders
 should first confirm that Use LE Audio when available is switched on under Settings > Bluetooth & devices > Devices. Next, open Settings > System > Sound, select the arrow beside the Bluetooth device under Output, and expand Output settings. The new option sits in the Format when the microphone is active dropdown.             
Microsoft suggests switching back to Mono (1 channel) if a headset drops out or distorts in stereo. If the system-wide Mono audio toggle under Settings > Accessibility > Audio is enabled, Windows warns that stereo may not work correctly.             
Hardware requirements and rollout
The option needs a PC that supports Super Wideband Stereo, meaning the right Bluetooth adapter and driver stack, as well as an LE Audio-enabled accessory capable of 48 kHz playback. Basic Bluetooth headsets with no advanced codecs or profiles miss out, and Microsoft warns that a PC marketed with Bluetooth LE may still lack LE Audio. Without LE Audio on both ends, Windows still drops to mono when the mic activates.             
The feature is arriving through Controlled Feature Rollout, so not every Insider will see it immediately. Microsoft has not announced when it will reach stable Windows 11 releases.             
Other changes in Build 26340.10032
The build also adds a People widget showing contacts from Phone Link or WhatsApp, one of which must be set up. Windows Search gains richer results for definitions, currency conversions, and web queries, and File Explorer search adds file type and date filters. WinRE will now be rebuilt from cumulative updates, with no changes needed on BitLocker devices.             
Microsoft also released 
Beta Build 26320.10022
, 26H1 Beta Build 28020.3562, 26H1 Experimental Build 28120.3571, and Future Platforms Build 29712.1013. Moves into Future Platforms are open again after last week's pause, though leaving requires a full Windows reinstall. A known issue stops Task Manager's CPU speed readout from updating.
