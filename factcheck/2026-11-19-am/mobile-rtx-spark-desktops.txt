NVIDIA「RTX Spark」搭載の小型デスクトップPCが11月18日発売　4399ドルから　“常時稼働のAIエージェント拠点”に
»
2026年11月18日 23時00分 公開

ITmedia
]
　NVIDIAは11月18日（米国太平洋時間）、同社のWindows向けSoC「RTX Spark」を搭載する小型デスクトップPCが、同日に各社から発売されると発表した。価格は4399ドルからとなる。
　RTX Spark搭載PCは、
10月16日にノートPCが先行して発売
されており、今回の小型デスクトップPCでラインアップがそろう形だ。
→
月1200ドルのAIコストが電気代20ドルで済む？　NVIDIA「RTX Spark」搭載PCのデモで見えた“ローカルAI”の実力
RTX Sparkを搭載する小型デスクトップPCは11月18日に発売される。現状で7社が製品を投入する。写真はMSIの「
EdgeMesa N AI+
」だ
20コアCPU＋6144コアGPUの上位SoCを搭載　7社から登場
　小型デスクトップPCを投入するのは、Acer、ASUSTeK Computer、GIGABYTE、Dell Technologies、HP、Lenovo、MSIの7社だ。
　SoCは、ノートPCの上位モデルと同じ「RTX Spark N1X」（20コアCPU＋6144コアGPU）を採用する。Blackwell世代のRTX GPUと、MediaTekと共同開発した20コアのGrace CPUを毎秒600GBの「NVLink C2C」で接続し、最大128GBのユニファイドメモリを共有する。AI演算性能はFP4演算時で1PFLOPSだ。
　NVIDIAは小型デスクトップPCの特徴として、常時稼働でAIエージェントを動かせること（Always On Intelligence）を挙げる。1200億パラメーターのAIモデルを、100万トークンのコンテキストでローカル実行できるという。
　用途としては、RTX対応ゲームやコンテンツ制作、大規模な3Dシーンの処理、ローカルモデルを使ったAIエージェント、画像／動画生成を想定している。
　なお、ノートPCは「18コアCPU＋5120コアGPU」（メモリ24GB〜32GB）と、「20コアCPU＋6144コアGPU」（メモリ24GB〜128GB）の2構成があり、価格は2699ドルからだ。
こちらはASUSの「
ProArt GR1X
」
ゲームとクリエイティブアプリの対応も進む
　AIエージェントの実行基盤は、WindowsとNVIDIAのランタイム「OpenShell」が担う。その上で動作するエージェントに対し、RTX Spark向けAIモデル「Nemotron 3.5 Bolt」、ローカルとクラウドのAIモデルを使い分ける「NeMo Switchyard」、複数のPCにAI処理を振り分ける「
NVIDIA PAIR
」を組み合わせる構成だ。
　エージェントから操作できるアプリやツールも増えている。GmailやOutlook、Slack、GitHub、VS Code、Blender、Photoshop、DaVinci Resolveなどに加え、新たにNVIDIA appやBroadcast、RTX Remix、Omniverse、PAIR、CUDA-X向けのスキルが用意された。
　小型デスクトップPCならではの使い方として、同社は“家庭用エージェント”を提案する。省電力で常時稼働するAIアプライアンスとして、家電や照明、水漏れセンサー、スプリンクラーなどのホームオートメーションや、セキュリティ、家族の予定管理を任せるというものだ。
　家族それぞれのPCで動くパーソナルエージェントの処理を、NVIDIA PAIRで振り分ける使い方も示した。RTX Spark搭載ノートPCやRTX搭載PCに加え、MacBookも接続対象として紹介している。
　ゲームでは、DLSS 5への対応と、Arm版Windowsへのネイティブ対応が進んでいる。

　PhotoshopはローカルAIで動作する削除ツールを備え、Premiereは対応するRAW形式を拡充した。IllustratorとInDesignはネイティブ対応により、性能が30％向上したという。「Blender 5.3」は、DLSS 4.5のレイ再構成に対応する。

デスクトップ版RTX Sparkはどこまで速い？128GB搭載のノートPC版と比較
芹澤 正芳
2026年11月18日 23:00
128GBのユニファイドメモリを搭載するMSI「EdgeMesa N AI+」(右)とMicrosoft「Surface Laptop Ultra」(左)。同じRTX Spark N1Xを搭載する2台で、筐体の違いが性能にどう表れるかを調べた
 　2026年11月18日にRTX Sparkを搭載するデスクトップPCの発売が開始される。先行したノートPC版に続く、RTX Sparkの第2の形態だ。ここでは、デスクトップ版の実機としてMSIの小型デスクトップ「EdgeMesa N AI+」(128GB)を、比較相手にノートPC版の米Microsoft「Surface Laptop Ultra」(128GB)を用意し、同じ条件で測った。 
 　搭載されるチップは同じだ。CPUは20コア、GPUは6,144CUDAコア、メモリは128GB。スペック表だけ見れば2台はほぼ同じに見える。ところが実際に測ると、ゲームでは約3割、画像生成でも約3割の差が付く一方で、CPUのテストではほとんど差が付かない場面もある。今回は「どこで差が出て、どこで出ないのか」をベンチマークで探っていこう。 
RTX Sparkとは？ CPUとGPUで最大128GBを共有
 　RTX Sparkは、ArmベースのNVIDIA Grace CPUとBlackwell世代のRTX GPUを組み合わせたWindows 11向けのプラットフォームだ。CPUとGPUがLPDDR5Xメモリを共有するユニファイドメモリ構成を採り、今回試した2台は上位構成の128GBを搭載する。 
 　一般的なディスクリートGPUのように容量の決まった専用VRAMを別に持つ構成とは異なり、大きなローカルAIモデルや3Dデータにメモリを振り向けやすい。ただし、128GBすべてが専用GPUメモリになるわけではない。CUDAを使うAIアプリに加え、対応ゲームではレイトレーシングやDLSSが使える点も特徴だ。 
 　デスクトップ版として各社が発表しているのも、いわゆる「ミニPC」サイズの製品だ。ノートPC版と同様、コンパクトな筐体に大きなAI処理能力を詰め込んだWindows PCという特徴は変わらない。その省スペース性を保ったまま、据え置き向けの電力枠で性能をどこまで伸ばせるのかが、今回の見どころになる。 
デスクトップ版とノートPC版ではTDPとNPUが違う
 　今回用意したデスクトップ版RTX Sparkは、MSIのEdgeMesa N AI+だ。サイズは152×147×53mmで容積1.2L。本体の設置面積は約15cm四方で、デスクの一角やディスプレイ脇に収めやすい。ACアダプタと配線の場所、吸排気のための空間は必要だが、本体が作業スペースをほとんど圧迫しないのは魅力だ。 
 　ローカルAIや3D制作、ゲームをこなすWindows PCを、このサイズで置ける。比較用に用意したMicrosoftのSurface Laptop Ultra(128GB)は15型のタッチディスプレイを備え、外出先にも同じ作業環境を持ち運べるのが強みだ。

 　まずはデスクトップ版とノートPC版の仕様を確認しておこう。

 　同じコア数でも、TDPはデスクトップ版が140W、ノートPC版が45～80Wだ。後者はNVIDIAが示すノートPC版の仕様範囲であり、Surface Laptop Ultraの個体に設定された上限を測ったものではない。もう1つの違いがNPUだ。デスクトップ版では省かれている。 
 　その理由はNVIDIAによると、NPUは軽量なAI処理を低消費電力で実行し、ノートPCのバッテリ消費を抑えるのに役立つと説明。一方、常時電源に接続するデスクトップ版では、そうした処理をより高速に実行できるBlackwell GPUを中心とした構成を採用しているという。なお、ノートPC版はCopilot+ PC対応だが、Copilot+機能の具体的な利用可能時期は、現時点では案内できる日程がないとのことだ。 
左がデスクトップ版のタスクマネージャー。NPUは確認できない。右はノートPC版でNPUが存在している
CPUは小差、ローカルAIでは画像生成の待ち時間に差
 　検証機はどちらもWindows 11 Proで、NVIDIAドライバは621.24。Windowsの電源モードは両機とも「バランス」に設定し、NVIDIAアプリのGPUメモリ割り当ては64GBにそろえた。以下の性能差はSurface Laptop Ultraを基準に計算している。 
GPUへのメモリ割り当ては64GBでそろえた。なお、この容量を超えるAIモデルでもメインメモリに空きがあれば、それを自動的に割り当てるので、64GBが絶対的な上限になるわけではない
 　まずは、CGレンダリングとして「Cinebench 2026」と「Blender 5.3.0」を実行しよう。前者はCPU、後者はGPUを使ってレンダリングを行なう。 
Cinebench 2026の結果
Blender 5.3.0の結果
 　Cinebench 2026のCPUマルチスレッドはデスクトップ版が5.8%上回った。逆にシングルスレッドは545対558で、ノートPC版がわずかに上だ。Blender 5.3.0でGPUを使用した結果は、シーンによってデスクトップ版が7.0～9.4%上となった。ここではGPUを使う処理のほうが差が大きくなっているのを確認できる。 
 　続いてAI関連だ。1つ目は、ローカルLLMを実行した際のテキスト生成性能を測定する「Procyon AI Text Generation Benchmark」。2つ目は、現代的なAIモデルを使ってテストを行なう「Procyon AI Computer Vision 2.0 Benchmark」だ。 
Procyon AI Text Generation Benchmarkの結果(スコア)
Procyon AI Text Generation Benchmarkの結果(生成速度)
Procyon AI Computer Vision 2.0 Benchmarkの結果
 　AI Text Generation Benchmarkは、4モデルともデスクトップ版のスコアが約16%上だった。ただし、内訳を見ると回答が出始めるまではデスクトップ版のほうが高速だが、生成速度だけを見ると4モデルで約2～4%の差にとどまる。「スコアが約16%高い」イコール「文章が約16%速く伸びる」ではない点には注意したい。GPUを使ったAI Computer Vision 2.0 Benchmark(TensorRT、FP16)のスコア差は12.6%だった。 
 　続いて試すのはComfyUIだ。両機で同一のワークフローファイルを使い、ウォームアップ1回を除く5回の平均を比較した。「FLUX.2 [dev]」はFP8混合精度の生成モデルで1,024×1,024ドットの画像を1枚生成。「MiniMax H3」はINT8版を使い、約5秒の動画を生成した。ステップ数はどちらも20だ。 
ComfyUIによる生成時間を測定した結果
 　画像は1枚当たり約21秒、動画は1回当たり約52秒、いずれもデスクトップ版のほうが短い。プロンプトや構図を変えて何度も出し直す作業では、この差が効いてくる。一方、ノートPC版でも同じワークフローが完走した。外でも同じ環境で生成できるという点では、同じ128GBを搭載するノートPCにも意味がある。 
ゲームでは特に大きな差、GPUクロックに注目
 　ゲームについては「マーベル・ライバルズ」と「サイバーパンク2077」を用意した。2,560×1,440ドットでDLSS バランスと3倍フレーム生成を使い、実用的な画質設定での動作をチェックしている。どちらも内蔵ベンチマーク実行時のフレームレートをFrameViewで計測した。 
マーベル・ライバルズの結果
サイバーパンク2077の結果
 　フレーム生成オフの平均では、サイバーパンク2077で約15%、マーベル・ライバルズで約33%の差が付いた。マルチフレーム生成3Xではどちらも平均100fpsを超えたが、フレーム生成数が増えると完成したフレームをディスプレイに送るまでのPC内部の遅延は増えていく。たとえば、サイバーパンク2077の平均PC遅延はデスクトップでも40.8から62.1msに増加。見た目の滑らかさと操作へのレスポンスのよさは別だ。 
 　なお、サイバーパンク2077のフレーム生成オフ時のFrameViewログを見ると、平均GPUクロックはデスクトップが2,313MHz、ノートPCが1,762MHz。GPUのセンサー電力は平均79.2W対33.2Wだった。平均CPUクロックは2,666MHz対2,625MHzで、GPUほど差は開いていない。TDPの差はおもにGPUクロックに効いてくるといえそうだ。 
小型据え置きAI PCの新たな選択肢に
 　今回の2台で、デスクトップ版の持ち味が出たのは、ゲームの平均fpsや、画像・動画を繰り返し生成する時間だ。逆に、CPUのシングル性能や、文章の出力が始まった後の生成速度には大きな差が出なかった。 
 　同じ128GBなら、使いたいワークフローを外にも持ち出すのか、重い処理を机のそばで何度も回すのかが選び分けの基準になる。デスクトップ版は、ノートPCと同じメモリ容量を受け継ぎつつ、ミニPCサイズに収まる省スペース性も備える。持ち運びを必要とせず、机の一角に置ける強力なWindows AI PCで、GPUを長く使う処理の待ち時間を短くしたい人に向く存在だ。 
 　最近ではローカルAI需要によって大容量ユニファイドメモリを搭載したミニPCが数多く登場しているが、デスクトップ版RTX Sparkはその中でも強烈なインパクトを持つ存在だ。その勢力図がどのように変わるか楽しみだ。

　RTX SparkはAIエージェントをローカル環境で存分に動かすためのプラットフォームだ。その第1弾である「RTX Spark N1X」（以降、RTX Sparkと略）を搭載したノートPCに続き、RTX Sparkを搭載したミニPCの販売が2026年11月18日よりグローバルにて解禁される。国内販売価格は筆者のもとに届いていない。しかし、ほぼ同じハードでメモリー128GB版の「DGX Spark」が110万円〜140万円程度であることをふまえると、RTX Sparkもほぼ同価格帯になると思われる。
　RTX Sparkは最大128GBのユニファイドメモリーを備え、CUDAのみならずDLSSやReflex、G-SYNCといったGeForceの技術資産がすべて運用できる。その上でArm64版ながらWindows 11が動作することを最大の武器にしている。AIだけなら上位版である「DGX Spark」があるが、Windowsのアプリ資産を使いたいならRTX Sparkが良いと言っているわけだ。
本格的なAIを使った開発もでき、Windowsのアプリ資産も（有名どころは）ほぼ利用できる。そして、ゲームもそのまま動く（Prismを使ったエミュレーションを含む）ので、ホビー寄りの運用も一応OKという「なんでもいいところどり」がRTX Sparkの立脚点となる。とはいえ、ゲーマー向けというよりはゲーム開発者向けという立ち位置だ
　そして、NVIDIAはRTX Sparkの強みを「AIモデルのDay 0サポート」と位置づけている。現状、「Strata」のようにVRAMが少ない環境でもパラメーター数の多いAIモデルを運用可能な推論エンジンが話題だが、今後出るAIモデルがStrata（のようなエンジン）で動くとは限らないし、動いても対応の時間が必要なケースもある。最初から多量のメモリーを搭載しているRTX Sparkはすぐに対応できる、というのがNVIDIAの主張である。
新しいAIモデルが出ても、Strataのようなエンジン上で動くとは限らない。出た直後、つまりDay 0でキャッチアップするには多量のユニファイドメモリーを備えたRTX Sparkが最適という主張
TDP 140WのデスクトップPC版RTX Sparkを検証
　今回筆者は幸運にもASUS製の小型デスクトップPC「ProArt GR1X」（以降、GR1Xと略）をテストする機会に恵まれた。

GR1Xの公式ページ。原稿執筆時点では価格情報がなく、法人窓口へのボタンがあるのみだった
　RTX Sparkの性能傾向はMicrosoftの「Surface Laptop Ultra」検証（【

　敗因を考えるに、メモリー帯域の細さ（300GB/sとRTX 5050よりも細い）に、CUDAコア数やL2キャッシュの問題（CUDAコア数は6144基だが、L2キャッシュがRTX 50シリーズの半分）などが挙がるが、もうひとつ疑っている要因がある。それは、Surface Laptop UltraはノートPCであり、RTX SparkのTDPは45W〜80Wに制限されている点である。
　今回テストするGR1XはミニPCであり、TDPは最大140Wと電力制限は大幅に上昇している。ノートPC版のRTX Sparkの性能限界が電力制限にあるのなら、デスクトップPC版のRTX Sparkはもっと性能が出る可能性がある。今回はそこを検証したい。

===== https://blogs.nvidia.com/blog/rtx-spark-desktop-local-ai-available-now/
(status 200)
New 
NVIDIA RTX Spark compact desktops
 from ASUS, Dell and MSI are available today, bringing local AI agents, image and video generation, and model fine-tuning to a dedicated Windows PC.
With up to 128GB of unified memory and NVIDIA’s AI software stack, these systems provide room for larger local models alongside RTX-accelerated creative and development tools. A dedicated desktop can keep agents and scheduled tasks running while a laptop travels or handles other work.
Alongside the new desktops, an expanding software ecosystem brings more creative and development workflows to RTX Spark laptops and compact desktops.
Native Windows on Arm applications from Adobe, the NVIDIA DLSS Ray Reconstruction feature in Blender and local generation workflows in ComfyUI expand what creators and developers can do on RTX Spark — all on one Windows PC.
A Windows PC Built for Local AI
As workflows expand to include local AI models and agents, more work can continue beyond an active editing session — from generating assets to processing long renders or scheduled tasks. 
RTX Spark compact desktops give developers, creators and AI enthusiasts a dedicated Windows PC for local models and always-on agents. They bring together image and video generation, model fine-tuning, creative applications and development tools in one compact system.
Running supported models locally keeps locally processed code and files on the PC and avoids per-token cloud application programming interface (API) charges for those tasks.
RTX Spark compact desktops like the ASUS ProArt GR1X mini PC are built to run personal AI agents 24/7.
RTX Spark desktops are equipped with a 20-core NVIDIA Grace CPU, an NVIDIA Blackwell RTX GPU with 6,144 CUDA cores and up to 128GB of unified memory, delivering up to 1 petaflop of AI performance. Ten-gigabit Ethernet connectivity enables fast transfers of large datasets, model files and creative assets between RTX Spark compact desktops and networked storage.
This advanced hardware unlocks incredible capabilities for creators, developers and AI enthusiasts, including:
Running massive 120-billion-parameter large language models locally
Rendering 90GB+ 3D scenes in real time
Smoothly editing 4:2:2 video in real time
The MSI EdgeMesa N AI+ Series RTX Spark compact desktop.
New compact desktops are available for purchase from ASUS, Dell and MSI, joining the RTX Spark family of laptops available today. Mini PCs from Acer, GIGABYTE and HP are coming soon, along with the 
Microsoft Surface RTX Spark Dev Box
.
From Local Agents to AI Creation
Native CUDA support and Linux development tools through Windows Subsystem for Linux give developers a foundation for building and running local AI workflows. Developers can set up agents with Hermes Agent or NVIDIA NemoClaw blueprints and fine-tune supported models using Unsloth.
RTX Spark can run creative agents that connect familiar applications and local AI tools, helping creators move from an idea to finished work with natural-language instructions.
NVIDIA Switchyard, now available in Hermes, automatically routes agent tasks between local and cloud models. Everyday tasks can run on device, while advanced reasoning draws on cloud models, helping manage cloud costs across creative workflows.
These capabilities come together in creative workflows that connect Photoshop and ComfyUI through Hermes Agent. Using natural-language instructions, creators can turn sketches into rendered images and animations, or animate an image entirely on device — from isolating a subject and defining its motion to generating the finished video.
NVIDIA brought these workflows to life at Adobe MAX, where attendees used natural-language instructions to turn sketches into rendered images and animations for a shared digital Miami landscape.
The RTX Video Frame Generation and RTX Video HDR features, already available in ComfyUI, extend the pipeline: a generated clip can be expanded to 60 frames per second and converted to high dynamic range for color grading, all within a single ComfyUI workflow on RTX Spark.
Adobe Accelerates the Full Creative Stack for RTX Spark
NVIDIA and Adobe are expanding native Windows on Arm support and RTX acceleration across Adobe’s creative applications, helping video editors, photographers, designers and 3D artists work more efficiently on RTX Spark.
Adobe Premiere 
accelerates a range of AI-powered editing features through 
NVIDIA TensorRT-RTX
, including Enhance Speech, Object Mask, Scene Edit Detection and Auto Reframe — so editors spend less time waiting and more time cutting. 
GPU acceleration also extends to Film Impact transition and effects plug-ins. The update improves support for professional video formats, including Canon RAW, Red RAW, ARRI RAW, ARRICORE, ARRI HDE, H.264 and HEVC in MXF, ProRes RAW and long-GOP video. This lets editors realize more than 50% quicker turnaround on everyday H.264 video deliverables.
Adobe Photoshop 
adds TensorRT-RTX acceleration for the Remove Tool and ArmRTX Spark-native Camera Raw support, helping photographers remove unwanted objects faster and work with RAW images without relying on emulation. At Adobe MAX, Adobe previewed a next-generation image processing engine with extensive GPU acceleration, including interactive Gaussian blur and Light Leaks filters.
Adobe Substance 3D Painter 12.2
 is now optimized for RTX Spark with native support on Arm for the first time in public beta. Artists in games, visual effects and visualization can run Substance Painter natively on RTX Spark laptops and compact desktops, with no compatibility layer required.
Adobe Illustrator
 and 
InDesign
 now offer native Windows on Arm versions optimized for RTX Spark. Adobe Illustrator delivers up to 30% higher performance than its emulated version, helping accelerate illustration, graphic design and page-layout workflows on RTX Spark.
Blender 5.3 Adds DLSS Ray Reconstruction to the Viewport
Blender 5.3 integrates DLSS 4.5 Ray Reconstruction into the Cycles viewport, helping artists evaluate lighting and materials with near-final-quality ray-traced previews as they work. 
The practical difference is immediate: instead of navigating a noisy, resolving preview, Ray Reconstruction delivers near-final-quality lighting, reflections and materials in the interactive viewport in real time. 
DLSS 4.5 Ray Reconstruction support requires Blender 5.3 and the latest NVIDIA Game Ready Driver or NVIDIA Studio Driver. Download the 
NVIDIA App
 to get automatic notifications when the latest drivers are available, optimize games and applications from a unified GPU control center, and discover the latest NVIDIA tools and software.
Windows Server 2028 Coming to DGX Station for Windows
Announced at Microsoft Ignite, Windows Server is evolving for organizations that need to run AI closer to their enterprise applications and data.
Microsoft is expanding hardware choice through support for the latest AI silicon, helping customers take advantage of accelerated inference and increasingly capable models in their own environments. NVIDIA DGX Station for Windows platform powered by the GB300 Grace Blackwell Ultra Desktop Superchip is expanding to include support for Windows Server 2028. 
New accelerator platforms and the breadth of the Windows silicon ecosystem provide customers options at different capability levels and price points for advanced AI development, local inference, and agent workloads at scale.
Windows ML Updates Give Developers More Options
Also announced at Microsoft Ignite, developers can now bring any GGUF model from Hugging Face and run it within Windows ML using the llama.cpp backend.
The DxCGC backend, now available as an experimental release, is an integration for game developers that compiles and runs machine learning models through DirectX 12, allowing them to execute AI workloads alongside graphics.
Windows APIs let applications integrate platform-provided AI capabilities adding GPU support for AION Instruct and VSR.
Developers can also build high-performance AI models for Windows ML using the command line interface.
