マイクロソフト、AIによるサイバー攻撃にAIエージェントで対抗する新サービス「Microsoft Perception」提供開始
2026年11月19日
マイクロソフトは日本時間11月18日未明に開幕した年次イベント「Microsoft Ignite 2026」で、AIによるサイバー攻撃に対抗するためのAIエージェントによる新サービス「Microsoft Perception」の
提供開始を発表しました
。
Now generally available, Microsoft Perception brings red, blue and green team agents together through playbooks to simulate attacks, detect threats and remediate, delivering security outcomes at machine speed, with you always in control. #MSIgnite https://t.co/DHSCo1P36i
— Microsoft (@Microsoft) 
November 17, 2026
AIを用いたサイバー攻撃は完全に自動化されつつあるため、発見から攻撃までの時間や攻撃そのものにかかる時間は劇的に短縮されています。
そのため人間による操作では、もはやAIを用いたサイバー攻撃に対応することが困難になっており、対抗する側もAIエージェントによるマシンの速度で動く必要があります。
今回提供開始が発表された「Microsoft Perception」は、こうしたAIのサイバー攻撃に対抗するためのAIエージェント群により構成される新サービスです。
3つのエージェントチームがサイバー攻撃に対抗
Microsoft Perceptionの最大の特徴は、「レッドチーム」「ブルーチーム」「グリーンチーム」の3つのチームエージェントにより構成される点です。
レッドチームエージェントは、攻撃が行われる前に攻撃者視点で脆弱性を発見する役割を担います。
ブルーチームエージェントは、サイバー攻撃の検知と調査、インシデント対応を担います。
グリーンチームエージェントは、脆弱性やバグの修復あるいはリスク低減を担います。
この3つのチームエージェントは、「プレイブック」と呼ばれる手順書に従って日常的に協調して自律的に動作し、サイバー攻撃が発生することを未然に防ぎ、あるいはサイバー攻撃に対してマシンスピードでの対応を実現します。
ただし重要な判断が必要な段階では人間の判断を仰ぐようになっています。
グリーンチームエージェント用のプレイブックでは、マイクロソフトのプラットフォームだけでなく、AWS、Google Cloudもカバーしていると説明されています。

===== https://www.securityweek.com/microsoft-takes-perception-agentic-security-platform-out-of-preview/
(status 200)
Microsoft used its Ignite 2026 conference on Tuesday to announce the general availability of Perception, a product designed for coordinating teams of AI agents to handle security tasks.
Unveiled in July as 
Project Perception
, the system has been in public preview inside Microsoft Defender since August.
Playbooks direct the agents, which are split into red, blue and green teams. Red agents play the attacker and probe for weaknesses; blue agents handle detection, alert triage, and investigations; and green agents fix problems.
The four blue team agents that are now generally available cover alert triage, attack investigation, detection authoring and threat intelligence. According to Microsoft, the Alert Triage Agent can handle roughly 80% of alerts in a typical Defender queue, based on an analysis of approximately 8 million alerts across its security products.
The Recon Agent, one of the red team agents, is also generally available, and a Web App Pen Test Agent has entered preview.
Two new green team playbooks work across Microsoft, AWS and Google Cloud. The agents behind them include Posture Prioritization, which is generally available, and Risk Reduction, which is in public preview.
Advertisement. Scroll to continue reading.
The Risk Reduction Agent can recommend vulnerability shielding when a fix isn’t immediately available. This preview feature temporarily protects vulnerable assets until a permanent patch can be rolled out.
“Your team sets the guardrails and signs off on high-impact actions, and automated triggers launch playbooks when an incident meets the criteria you set,” Aleš Holeček, president and chief architect of Microsoft Security, wrote in a 
blog post
.
Microsoft is also previewing integrations that link Perception to SIEM, SOAR and IT service management tools via MCP and APIs.
The company also addressed the risk posed by AI agents, which it views as a new kind of insider with broad access to data and tools.
In preview, Agent 365 and Entra Suite can detect 60 types of local AI agents, including Claude Code, OpenAI Codex and GitHub Copilot. Intune policies can keep supported agents on the device.

 AGENTIC SYSTEM 
 Microsoft Perception 
 Specialized red, blue, and green agents coordinate in playbooks to expose gaps, investigate threats, and remediate continuously. You set the guardrails and approve high-impact actions. 
 Overview 
Multi-agent defense
 Coordinated agents. Shared intelligence. Protection that never stops. 
 Move at machine speed 
 Attackers now move at machine speed, and defense has to match it. Microsoft Perception orchestrates red, blue, and green team agents as one team: red agents simulate attacks, blue agents detect and triage, and green agents remediate and harden. Agents share intelligence across tools and workflows, so a finding moves straight to a fix, with fewer handoffs and less repeated analysis. 
 Drive outcomes, not tasks 
 Security value is measured in outcomes, not completed tasks. Perception runs comprehensive playbooks that orchestrate teams of agents towards a security outcome, grounded in agent-ready context, informed by Microsoft Threat Intelligence and broad signals across Microsoft Security. 
 Stay in control 
 Autonomous defense scales only when you trust it enough to turn it on. Microsoft Perception inherits your existing governance and compliance policies, runs agents with least-privilege access, and asks for approval before critical actions. Every agent action is logged and auditable, so your team delegates with confidence and stays in control. 
 WHAT’S INCLUDED 
Inside Microsoft Perception
 The building blocks of agentic defense — intelligence, agents, and models to power your security stack while keeping humans in charge. 
 Playbooks 
Repeatable security outcomes
 Agentic playbooks orchestrate agents toward security outcomes. Describe an objective or select a playbook, and Perception coordinates the right agents for each task. 
 Agents 
Red, blue, & green agents
 Specialized agents that expose weaknesses, detect and respond, and remediate and harden across the entire attack lifecycle. 
 Harness 
Orchestration and governance for agents
 The framework, tools, and controls that coordinate and govern every agent and model: one control plane, least-privilege access by default, approval before critical actions, and every action logged and auditable. 
 Models 
Purpose-built cyber models
 Task-optimized model selection balances quality, speed, and cost across frontier and specialized models, including the MAI-Cyber-Flash lineage, Microsoft's specialized models, purpose-built for cybersecurity tasks. 
 Context 
Agent-ready security context
 Turn enterprise-wide signals and threat intelligence into a connected, agent-ready understanding of what is happening, what is at risk, and what matters most in your environment. 
 Signals & actuators 
From signal to action across your estate
 Sensors built into the Microsoft Security portfolio feed agents real-time signals, and actuators let agents act on what they find, such as containing a threat or hardening defenses. 
 THE AGENTS 
Meet your team of red, blue, & green agents
 Three specialized agents that cover you across the full attack lifecycle, and hand off to each other automatically.

 01/ 
What is Microsoft Perception?
Microsoft Perception is an agentic system that brings a team of specialized AI agents to reason over your security data, tools, and workflows – delivering continuous, proactive defense with a human in control of every critical decision.
 02/ 
Which capabilities are included in Microsoft Perception?
Microsoft Perception includes red, blue, and green agents; playbooks that coordinate agents toward a security outcome; purpose-built models, including the MAI-Cyber family; and an orchestration harness. These build on agent-ready security context and on signals, sensors, and actuators across Microsoft Security.
 03/ 
How is Microsoft Perception different from Microsoft Security Copilot?
Microsoft Perception is an agentic system where specialized agents coordinate and act across your estate: AI that acts. Microsoft Security Copilot is a generative AI-assisted chat interface: AI that assists. They're complementary and priced separately.
 04/ 
How does an agentic system work?
An agentic security system uses AI agents to perform tasks autonomously or work together through coordinated workflows, using shared context to achieve security outcomes.
 05/ 
What do red, blue, and green security agents do?
Red agents identify exploitable weaknesses, blue agents investigate threats, and green agents prioritize security risks and recommend actions to strengthen defenses.
 06/ 
How does agentic security improve threat investigation and response?
Agentic security helps you investigate threats faster by automating repetitive tasks, correlating security signals, and coordinating response workflows.
 07/ 
How do you keep humans in control of AI-driven security actions?
You stay in control through role-based permissions, policy guardrails, human approval for high-impact actions, and auditable agent activity.
 08/ 
How do you start adopting agentic security safely?
Start with focused, low-risk security use cases. Set clear policies and approval requirements, monitor agent activity, and expand automation as confidence grows.
 09/ 
How is Microsoft Perception priced? What are the different ways to buy?
Microsoft Perception uses consumption-based pricing, with two ways to purchase: Pay-as-you-go or via the AI Flex plan. If you have an active Microsoft Azure Consumption Commitment (MACC), your pay-as-you go and AI Flex Plan usage counts toward it.
 10/ 
How do I estimate costs for Microsoft Perception? Where can I track usage and spend?
Perception comes with a cost estimator tool that customers can access at set up or at any time while using the product. You can access the usage dashboard in the Defender portal under Setup & configuration > Microsoft Perception. This shows spend and outcomes delivered across agents, playbooks and users. You can also set a budget and track spend against it. 
 11/ 
What is AI Flex Plan?
 AI Flex Plan is a new, simpler way to buy services across the Microsoft AI portfolio. It’s one commitment you can use across eligible Microsoft AI services, including Microsoft Foundry, Microsoft Copilot, GitHub Copilot, Microsoft Perception, Microsoft Security Copilot, and Microsoft IQ. You can shift your usage between AI services as your priorities change.
 Choose a 1- or 3-year term and pay monthly or up front.
