JEDEC、次世代メモリ「DDR6」プレビュー公開。モジュールは74mmに小型化
劉 尭
2026年11月20日 11:23
 　半導体標準化団体のJEDEC Solid State Technology Associationは18日(米国時間)、次世代DRAM標準「DDR6」のプレビューを発表した。なお、DDR6は現在開発中のため、今回示された機能は計画を反映したもので、開発および承認過程において変更される可能性があるとしている。 
 　DDR6は現在開発中の次世代メモリ規格で、帯域幅、容量、電力効率、信頼性の大幅な向上を目指した新しいアーキテクチャとなる。DDR6 RDIMMでは、転送速度は12.8GT/sからスタートし、14.4GT/s以上へ高速化を目指す。また、データバス幅はDDR5の64DQから96DQへと50%拡大される。 
 　自作PCユーザーにとって何よりの注目点はモジュールの長さだ。DDR6のモジュール長は74mmで、ついにというべきか、SDRAM時代から約30年間続いた133.35mmから短縮される。この133.35mmは奇しくも5.25インチちょうどで、光学ドライブなどを収める5.25インチベイの呼び名と同じ数字だが、これが小型化されるわけだ。 
 　また、フォームファクタはRDIMM、UDIMM、CAMMの3種が定義される見込み。ここには、ノートPCに広く使われてきたSO-DIMMが並んでいない。そもそもモジュールが74mmとなれば、今のDDR5 SO-DIMMの69.6mmよりわずかに大きいだけだ。デスクトップPCとノートPCで同じモジュールを兼用する(もしくはノートPCはLPCAMM2といった別の規格を利用する)可能性が高くなりそうだ。 
 　そのほか、DDR6ではメモリアクセスを疑似チャネル(pseudo-channel)に分割するアーキテクチャを採用。バンク数はDDR5の2倍となり、リフレッシュ動作も改善する。さらにDRAMダイの密度は最大128Gbに対応。パッケージ内のダイ積層の最適化により、実装面積あたりの密度も高められる。 
 　信頼性の面では、複数のシステム側エラー訂正(ECC)の実装をサポートし、システムレベルでコスト、電力、信頼性のバランスを取ることができる。インターフェイスは高容量モジュール向けに最適化し、汎用コンピューティングに加え、CPUに近い場所でより多くの容量と性能を求めるAI推論やエージェント型AIを想定した構成となっている。

JEDEC's DDR6 preview highlights improvements in various areas, including performance, capacity, reliability, and power efficiency. These advancements align with the upgrades DDR5 brought to the table when it launched.
One of the most notable differences is that DDR6 memory modules will measure just 74mm in length, 44% shorter than DDR5’s 133mm memory modules. This makes DDR6 only 6% longer than DDR5 SO-DIMM modules, which you commonly find in laptops and mini-PCs.

JEDEC has maintained the pin count for many years, sticking to 288 pins for DDR4 and DDR5. However, DDR6 may finally break that mould. Given the substantial reduction in length with DDR6 and the data bus width upgrade, it is reasonable to assume that DDR6 will have a completely different pinout and density. Sadly, JEDEC has not revealed the pin count for DDR6.
Early rumors suggested that DDR6 may be limited to CAMM form factors to feed the AI boom. However, JEDEC's announcement at least does not rule out other form factors. It appears JEDEC is still determining which form factors DDR6 will use. Potential options include RDIMM, UDIMM, and CAMM formats, just like DDR5.

Notably, JEDEC has increased the data bus width in DDR6 to 96 bits, a 50% boost over DDR5's 64 bits. The channel architecture for DDR6 will also change substantially. While DDR4 and DDR5 leveraged a single 64-bit channel and two 32-bit sub-channels, DDR6 takes a different approach. JEDEC will implement a design with four 24-bit sub-channels.
Using the baseline for comparison, DDR6 offers up to 153.6 GB/s of total module bandwidth, compared to DDR5's 38.4 GB/s. That is a 4X uplift in bandwidth. If we compare DDR5-9200 RDIMMs, which max out at 73.6 GB/s per module, with DDR6-12800 RDIMMs, the uplift is a little more than double.

At least on the server side, DDR6 RDIMMs will start at DDR6-12800, whereas DDR5 RDIMMs topped out at DDR5-9200. JEDEC anticipates DDR6 reaching DDR6-14400 and beyond. This is for the server and enterprise market, though. It remains to be seen which DDR6 speed will launch in the consumer market. DDR5 commenced at DDR5-4800.
DDR6 may be shorter than DDR5, but it makes up for it by having 2X the bank count. This will help push higher data rates and capacities. DDR6 will support 128Gb (16GB) dies, which represents a massive leap. We are looking at 4X the density of early DDR5 memory modules. Instead of placing chips side by side on the PCB, DDR6 enables die stacking, allowing manufacturers to place multiple dies on top of each other via Through-Silicon Vias (TSVs).
Consumer DDR5 memory modules currently sit at 64GB per module, while server RDIMMs have reached 
512GB
. DDR6 could raise module capacity to 128GB or 256GB and potentially scale RDIMMs to 1TB or more per slot.
DDR6 has no official launch date. Many believe 2029 is a realistic target for commercialization. However, in the current state of things, it would be a miracle if DDR6 had no setbacks.

[News] JEDEC Previews Preliminary DDR6 Specs, Targeting Over 50% Higher Bandwidth and 12.8 GT/s Speeds
2026-11-19
Semiconductors
                    editor                
JEDEC 
has unveiled preliminary specifications for its next-generation DDR6 DRAM standard, targeting higher bandwidth, capacity, power efficiency, and reliability to meet growing demand from AI, cloud computing, data centers, servers, and client devices. According to JEDEC, DDR6 is expected to deliver over 50% higher memory bandwidth at introduction through faster data rates and a wider data bus, with further gains planned as speeds increase.
Specifically, DDR6 RDIMMs are expected to start at 12.8 GT/s, up from DDR5’s 9.2 GT/s, with a roadmap extending to 14.4 GT/s and beyond. The standard will also expand the data bus width from 64 to 96 data lines, representing a 50% increase. Alongside these improvements, DDR6 will introduce a new memory architecture organized around pseudo-channels. The design aims to increase bandwidth per DRAM package while allowing more flexible memory configurations to support system reliability and more efficient data movement.
DDR6 Targets Higher Memory Density, Improved Power Efficiency and Compact Modules
Beyond bandwidth improvements, DDR6 is designed to support greater memory capacity, with planned support for DRAM die densities of up to 128Gb. Optimizations for die stacking are also expected to increase memory density within each package. At the module level, JEDEC is targeting a more compact 74mm design, significantly shorter than DDR5’s 133mm module length. The smaller footprint is intended to help systems accommodate higher memory density.
Power efficiency is another focus of DDR6 development. JEDEC aims to improve performance per watt compared with DDR5 through the adoption of VSS-terminated I/O and low-power operating modes designed for data center applications. Meanwhile, DDR6 is being developed to support multiple module form factors, potentially including RDIMM, UDIMM, and CAMM. This flexibility is intended to address different computing requirements.
Memory Makers Begin Early DDR6 Development
Major memory manufacturers have already begun early preparations for commercialization. According to a May report by 
The Elec
, citing industry sources, Samsung Electronics, SK hynix, and Micron have asked substrate suppliers to begin preliminary development based on initial design specifications. The suppliers are developing substrates that account for memory thickness, stack-up structures, and wiring, with early prototypes undergoing testing and validation.
As The Elec notes, DDR6’s higher data rates present greater challenges for signal integrity and power efficiency, prompting closer collaboration between memory manufacturers and substrate suppliers from the early design stages. Industry sources expect DDR6 commercialization to begin in 2028–2029 or later, although mass production will depend on end-customer demand.

DDR6 modules could be considerably smaller than standard DDR5 DIMMs.
JEDEC has published an early preview of the DDR6 memory standard, outlining changes to memory bandwidth, capacity and module dimensions. One of the more interesting details is a proposed 74 mm module length, compared with 133 mm for standard DDR5 DIMMs. This would make the new module approximately 44% shorter than today’s full-size desktop and server memory modules.
The standard DDR5 DIMM measures 133.35 mm in length, a form factor shared with previous DDR generations. JEDEC’s proposed DDR6 design would reduce this to just 74 mm. The smaller dimensions are intended to increase memory density in systems where motherboard space is limited, including servers and data center platforms.
Shorter modules designed for higher memory density
The reduced module length could allow system manufacturers to fit more memory sockets into the same motherboard area. This would be useful for high-capacity server configurations, where memory slots compete for space with processors, cooling hardware and other components. However, JEDEC has not indicated that every DDR6 module will use the 74 mm form factor.
