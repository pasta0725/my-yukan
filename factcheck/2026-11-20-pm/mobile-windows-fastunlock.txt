A newly disclosed Windows 11 security vulnerability could allow someone with physical access to a locked PC to execute programs without entering the owner’s password or PIN. The flaw, dubbed FastUnlock, exploits Microsoft’s built-in Narrator accessibility feature and reportedly works even on systems protected by BitLocker drive encryption.
Security researcher Abdelhamid Naceri, also known as Nightmare Eclipse, publicly disclosed the vulnerability on November 19, 2026, through a GitHub repository detailing the issue. Naceri claims the exploit works consistently on tested Windows 11 systems, including a machine running Windows 11 version 26H2 with the November 2026 security updates installed.
The vulnerability affects how Windows Narrator handles its interface while an account remains locked. According to Naceri’s disclosure, certain accessibility and account recovery interactions can expose Windows interface elements that should remain inaccessible before authentication.
The researcher describes a sequence involving the Microsoft account recovery interface and Narrator’s keyboard navigation controls. Although the relevant windows can remain hidden behind the lock screen, keyboard focus reportedly allows interaction with them. This can provide access to Windows Settings and potentially create opportunities to launch software without completing the normal sign-in process.
Naceri states that successful exploitation can execute code within the Windows lock-screen account, identified as WsiAccount. His published demonstration shows access to Windows interface controls, but it does not demonstrate the complete execution of a program from removable storage. That final stage remains a claim rather than a fully demonstrated result in the publicly available material.
An early third-party test provides some additional support for the discovery. A system administrator posting under the username danrhodes1987 on Reddit reported reproducing the behavior on Microsoft Intune-managed devices. The administrator claimed it was possible to launch programs within the context of an existing user session and interact with applications left open before the device was locked.
However, these initial reports do not establish that the vulnerability affects every Windows 11 PC or that all claimed capabilities work across different configurations.
The BitLocker implications are particularly significant for gaming laptops and other portable Windows PCs. BitLocker protects stored information through drive encryption, helping prevent unauthorized access when a computer is lost or stolen.
FastUnlock does not appear to break BitLocker’s encryption algorithms or reveal the encryption keys directly. Instead, the reported attack targets a running Windows environment where the encrypted system drive has already been unlocked during normal startup.
If an attacker can execute software inside that environment without authenticating, some of the practical protections users expect from the combination of BitLocker and the Windows lock screen could be undermined.
The distinction matters because a successful lock-screen bypass is not necessarily equivalent to decrypting a powered-off BitLocker drive. The disclosed technique concerns unauthorized access through an active Windows session, rather than a demonstrated cryptographic defeat of BitLocker itself.
Naceri identifies two important requirements: an attacker must have physical access to the computer, and at least one Windows account must be connected to an online Microsoft account. The researcher has specifically tested Windows 11 26H2 but has not established whether the same behavior affects Windows 10 or other Windows 11 releases.
For PC gamers, the most relevant scenario involves a gaming laptop left unattended in a shared space, taken while locked, or stolen while Windows remains running. Depending on the affected configuration and the attacker’s resulting privileges, personal documents, saved application sessions and locally stored information could potentially be exposed.
The disclosure arrives amid Microsoft’s continuing efforts to strengthen Windows 11 security. The company’s recent 
expansion of Memory Integrity protections
 addresses a different category of system-level threats and should not be confused with a fix for this lock-screen vulnerability.
As of the November 19 disclosure, no Microsoft security advisory, assigned CVE identifier or confirmed patch specifically addressing FastUnlock had been identified. There is also no verified evidence establishing widespread exploitation of this particular vulnerability in real-world attacks.
Until its scope is clarified, owners of Windows gaming laptops and other portable PCs should prioritize physical security, avoid leaving devices unattended while signed in, and fully shut down sensitive systems before transporting or storing them in potentially insecure locations. Keeping Windows updated remains important, although existing updates should not be assumed to resolve this newly reported issue.
The original research establishes a credible basis for investigating the lock-screen flaw, but the full extent of its impact, affected Windows versions and potential BitLocker-related consequences remain subject to further independent testing and Microsoft’s response.
