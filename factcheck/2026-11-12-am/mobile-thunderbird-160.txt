「Thunderbird」v160.0
 　Mozillaは11月10日、メールソフト「Thunderbird」の最新版v160.0を公開した。本リリースでは、利便性を向上させる新機能や仕様変更に加え、多数のバグ修正および重要なセキュリティアップデートが行われている。 
 　新機能として、［メッセージフィルター］ダイアログで［Ctrl］＋［A］キーを押すとすべてのフィルターを選択できるようになった。また、OAuthによるサインイン画面において、ブロックされたCookieがログインを妨げる可能性がある場合に、その旨を説明する表示が追加。さらに、「Office 365」のアカウント設定時に、EWS構成の自動提示が廃止されている。 
 　不具合の修正は多岐にわたる。特定の操作でソフトウェアがクラッシュする問題が修正されたほか、メールの管理においては、IMAPの保持設定において、古いメッセージではなく新しいメッセージが誤って削除されてしまう重大な問題が修正された。また、メッセージを削除したあとに［元に戻す］機能が無効化されて復元できなくなる問題や、LFの改行コードを持つPOP3およびニュースメッセージが正しく解析されない不具合などが解消されている。 
 　セキュリティ面では、103件もの脆弱性が修正された。内訳は、深刻度がMozillaの基準で4段階中2番目に高いHighとされたものが59件、3番目に高いModerateとされたものが27件、最も低いLowとされたものが17件となっている。Thunderbirdではメール閲覧時のスクリプトが無効化されているため、メールを通じた直接的な悪用は防がれているものの、Webブラウザーに似た機能の中でリスクとなる可能性があるため、最新版へのアップデートが推奨される。

Security Vulnerabilities fixed in Thunderbird 160
Announced
November 10, 2026
Impact
high
Products
Thunderbird
Fixed in
Thunderbird 160
Many of these flaws cannot be exploited through email in the Thunderbird product because scripting is disabled when reading mail, however they may pose risks in browser or browser-like contexts.
Note
: We have changed how we publish advisories. We no longer roll all internally identified memory safety vulnerabilities into a single CVE and are now issuing an advisory for every individual bug.
#
CVE-2026-126132: Attachments could be replaced with local file content when forwarding
Reporter
Christopher Bohn (Protectstar Inc.)
Impact
high
Description
When a message was forwarded inline, edited as new, or had an attachment dragged into a compose window, a specially crafted link attachment (a .desktop file on Linux, or a .url or .lnk file on Windows) was replaced with the content of the file or URL it pointed to when the message was saved or sent. This could disclose local files, or content from the user's network, to the message recipients or to the mail provider.
This bug only affects Thunderbird on Linux and Windows. Other operating systems are unaffected.
References
Bug 2081919
#
CVE-2026-126133: Calendar server credentials could be sent to an HTTP proxy
Reporter
Christopher Bohn (Protectstar Inc.)
Impact
moderate
Description
When a CalDAV or ICS calendar was accessed through an HTTP proxy that requested authentication, Thunderbird could answer the proxy with the calendar server's username and password. This affected both setting up a new calendar and syncing existing calendars, where a saved password could be sent without any user interaction. A malicious or compromised proxy could use this to obtain the calendar credentials, even for calendars served over HTTPS.
References
Bug 2083485
#
CVE-2026-126134: Feed subscriptions could leak NTLM credentials on Windows
Reporter
Magnus Melin
Impact
moderate
Description
Thunderbird allowed feed subscriptions to file: URLs that point to a network share. If a user was tricked into subscribing to such a URL, Thunderbird connected to the attacker's server when fetching the feed. Windows then sent the user's NTLM credentials to that server.
This bug only affects Thunderbird on Windows. Other operating systems are unaffected.
References
Bug 2083584
#
CVE-2026-126135: SMTP and POP3 response injection when using STARTTLS
Reporter
Ibrahim Alghamdi
Impact
moderate
Description
If an attacker was able to perform a man-in-the-middle attack on an SMTP or POP3 server connection using STARTTLS, the attacker could inject server responses before the TLS handshake completed. Thunderbird would process these responses after the handshake, as if they had been received from the server over the encrypted connection. This could be used to make Thunderbird report a different outcome for sending or fetching mail, and to show attacker-controlled text in error messages. The encrypted connection itself was not compromised, and credentials were not exposed. Connections using SSL/TLS instead of STARTTLS were not affected.
References
Bug 2085343
#
CVE-2026-126136: OAuth2 access token could be sent over an unencrypted connection with Exchange accounts
Reporter
Álvaro Chico Martínez
Impact
moderate
Description
For Exchange accounts using EWS or Microsoft Graph with OAuth2 authentication, Thunderbird sent the OAuth2 access token to the server even when the configured server URL used unencrypted HTTP. An attacker able to observe network traffic could obtain the token and use it to access the user's mailbox until the token expired. An attacker positioned on the network during account setup could cause such a URL to be configured.

===== https://linuxiac.com/mozilla-thunderbird-160-fixes-imap-email-deletion-and-exchange-issues/
(status 200)
The Thunderbird team has just released Thunderbird 160, the latest version of their open-source email client. This version includes fixes for several issues, including IMAP message deletion, disappearing folders, Exchange account configuration, and calendar problems.
One of the key fixes addresses a bug in the IMAP retention settings that could have caused Thunderbird to delete newer messages rather than older ones. The update also fixes an issue where IMAP folders could disappear after an app restart when connecting to servers that use compression.
Message management gets a number of fixes. The Undo command was previously unable to be used after emails had been deleted. Thunderbird 160 addresses that issue and also fixes a problem whereby folders would disappear from saved searches if they’d been renamed or moved. Plus, dragging multiple selected folders now moves all of them rather than just one.
Mozilla Thunderbird 160
The release also improves Microsoft Exchange and Microsoft 365 account configuration. Exchange autodiscovery now correctly deals with redirects to different email addresses, and Microsoft Graph account setup no longer fails for tenants that don’t have a SharePoint license.
Additionally, Office 365 account setup no longer automatically includes the option to configure Exchange Web Services. The OAuth sign-in windows have also been updated to explain that blocked cookies may be the reason why you’re unable to authenticate.
For CardDAV users, there were compatibility issues in Thunderbird 160 which resulted in contacts being saved in a format which some servers didn’t support. Contacts with multiline street addresses no longer appear blank, and photos in vCard 3.0 contacts should now display correctly in other applications.
Message filtering also gets the nod. Previously, empty filter conditions could result in incorrect matches, and address book filters would occasionally fail to match a message where the address was missing. Both of those have now been fixed. The only new feature explicitly mentioned is the 
Ctrl+A
 shortcut for selecting all the filters in the Message Filters dialog.
Calendar users will find fixes for CalDAV reminders that couldn’t be dismissed or snoozed, missing attendance options for some recurring events, and WebCal subscriptions that were incorrectly blocked. Thunderbird also fixes an issue where changing events could result in invalid ICS calendar files being overwritten.
Finally fixes the crashes that would occur when opening a window or when updating a message database. Fixes incorrect parsing of certain POP3 and newsgroup messages and the freezes that would occur in new mail notification when certain sender addresses were involved. There are a number of news reader, feed reader, and interface enhancements, as well as a number of security fixes.
