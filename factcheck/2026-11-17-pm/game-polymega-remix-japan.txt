PSやセガサターンのCD-ROMゲームをPCでプレイ可能にする互換機「Polymega Remix」の国内向け正規販売が決定
編集部：小西利明
　2026年11月17日，Playmajiの正規代理店であるエヌケー貿易は，レトロゲーム互換機「
Polymega Remix
」（型番：PM-RMX-01）の予約販売を通販サイト「World Game Express」で行うと発表した。
　税込価格は
4万8400円
である。
Polymega Remix
　Polymega Remixは，Playmajiの据え置き型レトロゲーム機「
Polymega Base Unit
」からゲームの実行機能を分離し，Windows PCと接続してPC側でPlayStation 1やセガサターンのゲームをプレイできるようにした機器だ。
　ちょっと分かりにくいが，以下のように理解すればいい。
Polymega Base Unit：単独でレトロゲームをプレイできるゲーム機
Polymega Remix：PCと接続してゲームディスクを読み込むためのドライブユニット。
ゲームプレイにはPCが必須
　Polymega RemixはPCとUSBで接続して使い，挿入したPlayStation 1やセガサターン，メガCD，NEO GEO CD，PCエンジン CD-ROM2などのゲームをPC側にインストールする。インストールしたゲームの実行には，PC上で動作するアプリ「Polymega App」を使う。
　このような仕組みであるため，PC側にインストールしたゲームのプレイにPolymega Remixは不要だ。Playmajiでは，ノートPCや携帯型ゲームPCを持ち出してレトロゲームをプレイできるとアピールしている。
　さらにPolymega Remixは，別売りの「Polymega Element Modules」と組み合わせることで，カートリッジ式のゲームにも対応可能だ。
　Polymega Element Modulesは，NES（海外版ファミコン）やSuper NES（海外版スーパーファミコン），メガドライブやTurboGrafx-16（海外版PCエンジン）など，各種レトロゲーム機のゲームカートリッジと純正ゲームパッドを，Polymega Base UnitやPolymega Remixに接続するための拡張ユニットである。
Polymega Remixと，Super NES対応のPolymega Element Modules「EM02」を組み合わせたイメージ
　対応するゲーム機ごとに異なるモジュールが用意されているので，ゲームに合わせたモジュールを選ぶ必要がある点に注意したい。
左はSuper NES用の「EM02」，右はメガドライブや「Genesis」用の「EM03」をPolymega Remixと組み合わせた状態
　Polymega RemixとPolymega Element Modulesを組み合わせて使う場合，ゲームカートリッジからそのままゲームをプレイすることもできるし，PC側にゲームをインストールしてプレイすることも可能とのことだ。
　単体ではゲームをプレイできず，PCが必要という点は多少のハードルとなりそうだが，レトロゲームファンには響くところのある機器といえそうだ。

レトロゲーム実機資産を、PCでも。Polymega新デバイス「Polymega Remix」日本上陸
PS1・サターン・ネオジオCDのディスクをWindows PCでそのまま遊べる新ハードと、スーファミ対応「EM02 スーパーエレメントモジュール」をWorld Game Expressにて販売
エヌケー貿易株式会社
2026年11月17日 09時00分
いいね！数を読み込み中です
エヌケー貿易株式会社
（直営オンラインショップ：WorldGameExpress）は、米国Playmaji, Inc.が展開するレトロゲーム互換機ブランドPOLYMEGA（ポリメガ）の「
Polymega Remix（ポリメガ リミックス）
」を、POLYMEGA日本国内唯一の正規輸入代理店として、当社運営の通販サイト「
World Game Express
（https://worldgameexpress.jp）」にて予約販売いたします。
実機のディスクやカセットを吸い出してデジタルライブラリ化できるPOLYMEGAの体験が、Remixの登場により、ついにお手持ちのWindows PCやポータブルゲーミングPCへと広がります。
POLYMEGAとは 
POLYMEGAは、PS1・セガサターン・ネオジオCDをはじめとする往年の名機のゲームディスク・カセットを、実物のソフトからそのままHD画質でプレイ／インストールできるオールインワンのレトロゲーム互換機です。モジュール式の拡張により対応ハードを追加できる独自設計と美しい管理画面で、世界中のコレクターから高い評価を得ています。当社はPOLYMEGAの日本国内唯一の正規輸入代理店・取扱店として、本体・モジュール・ソフトを継続的に国内へ供給しています。
Polymega Remix — ポリメガの体験を、あなたのPCに 
Polymega RemixはUSB経由でWindows 11 PCに接続し、無料のPolymega Appを通じてオリジナルゲームディスク（PS1、セガサターン、セガCD、ネオジオCD、PCエンジンCD）をプレイできる</cite>新デバイスです。従来のPolymega Base Unit（テレビ接続型のスタンドアロン機）に対し、Remixは「PCと組み合わせて使う」新しいスタイルのポリメガ。ノートPCや携帯型ゲーミングPCと組み合わせれば、レトロゲームコレクションをまるごと持ち歩けます。
おすすめポイント
実物のディスクをPCでそのまま再生・インストール
RemixベースユニットをUSBで接続し、Polymegaアプリを起動して、お手持ちのレトロゲームコレクションをインストールするだけ。CD/DVDタイトルに対応する内蔵光学ドライブにより、お気に入りのゲームを簡単に楽しめます。エミュレータ環境の構築のような面倒な作業は一切不要です。
Elementモジュールで、カセット6世代ぶんに拡張できる
カセット式ゲームに対応するPolymegaモジュールを追加すれば、オリジナルカセットもプレイ可能。後述のEM02（スーファミ用）をはじめ、ファミコン・メガドライブ・PCエンジン・N64用など各種モジュールに対応します。
ゲーミングUMPCとの相性抜群、ライブラリを持ち歩ける
インストールしたコレクションは、Remixを外した後もPolymegaアプリでまるごと持ち出し可能。発売時点でIntelベースのノートパソコン、ROG AllyやLenovo Legionなどの携帯型ゲーミングPCを含む数千種類のWindows対応デバイスと互換性があり、自宅の大画面でも外出先でも、同じプレミアムなポリメガ体験を楽しめます。

Element Moduleシリーズ — 遊びたい世代を、1つずつ足していく
POLYMEGAの最大の特徴が、このモジュール式の拡張システムです。Remix（およびBase Unit）にElement Moduleをドッキングすると、そのモジュールに対応した実機カセットがそのまま挿せるようになります。各モジュールには世代ごとの専用レトロコントローラーが付属し、モジュール前面には実機の純正コントローラーを接続できるポートも搭載。「あの頃のカセットを、あの頃のコントローラーで」が、そのまま叶います。

モジュール共通のおすすめポイント
国内版・海外版カセットにマルチ対応
各モジュールは日本版カートリッジに加え、北米版・欧州（PAL）版にも対応。海外でしか発売されなかったタイトルも、リージョンを気にせず1台で楽しめます。
実機の純正コントローラーがそのまま挿せる＋専用コントローラー付属　
モジュール前面には実機純正コントローラー用ポートを搭載。当時のままのリアルな操作感で遊べるうえ、馴染み深いデザインの専用有線レトロコントローラーも各モジュールに付属します。
カセットレス化を叶えるインストール機能
お持ちのカセットを挿入すれば、Polymegaの美しい管理画面上に瞬時にアートワークや情報が追加されます。システム内へゲームデータを吸い出して保存すれば、次回からは一瞬で起動するデジタルライブラリが完成。大切なカセットを抜き差しによる劣化から守りながら、快適にプレイできます。

POLYMEGA  ·  REMIX
レトロゲームコレクションを、
どこへでも。
お手持ちの実物レトロゲームを、Windows 11 PCやポータブルゲーミングデバイスでプレイできる時代がやってきました。Polymega Remixは、あなたのゲームコレクションをデジタル化し、いつでもどこでも遊べるようにする、まったく新しいレトロゲーム体験デバイスです。
主な特徴
01 / BRING YOUR OWN DEVICE
お手持ちのPCをレトロゲーム機に
Windows 11搭載のデスクトップPC、ノートPC、ポータブルゲーミングPCに、Remixを介してゲームをインストールできます。
02 / PHYSICAL MEDIA
実物のコレクションをそのまま
ゲームCDやカートリッジ（別売Elementモジュール使用）を直接セットして、コレクションをデジタル化できます。
03 / PORTABLE LIBRARY
本体を外してもプレイ可能
一度PCへゲームをインストールすれば、以降はRemix本体を接続していなくてもプレイできます。
04 / EXPANDABLE
別売モジュールで対応機種拡大
カートリッジ用の「エレメントモジュール」（別売）を追加することで、さらに多くの機種のゲームに対応します。
内蔵ドライブでCD/DVDゲームに対応
Remix Base UnitをUSBでお使いのデバイスに接続し、無料のPolymega Appを起動。お手持ちのCD/DVDゲームをセットして、コレクションをインストールするだけ。準備ができたらRemixを取り外して、ゲームライブラリをまるごと持ち出せます。
