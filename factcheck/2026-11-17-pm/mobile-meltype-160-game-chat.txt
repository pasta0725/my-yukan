「Meltype」v1.6.0
 　［半角/全角］キーを押さなくても日本語と英語を打ち分けられる無償の日本語入力アプリ「Meltype」が11月14日、v1.6.0へアップデートされた。Windows版の「Meltype IME」がゲーム中も使えるようになるなど、多くの改善が行われている。 
漢字の変換処理
 　v1.6.0では、かな漢字変換の処理がすべてのOSで「Mozc」（「Google 日本語入力」のオープンソース版）と
「Zenzai」
（ニューラルネットワークを利用した変換エンジン）で行われるようになった。従来はWindows版が「Mozc」と「Microsoft IME」、Mac版が「azooKey」で変換していたため、OSごとに変換結果が異なっていたが、これが統一される。 
 　これに伴い、「変換エンジン」設定は廃止。Windows版では「Microsoft IME」に登録した語が候補に出なくなるので、使いたい語は「Meltype」のユーザー辞書に登録しておくとよい。また、Mac版の対応OSは
「macOS Ventura 13.3」
以降となった。 
ゲーム中も利用可能に
 　Windows版の「Meltype IME」は、ゲームの中でも停止せず、英数入力で始まるようになった。チャットでは［半角/全角］キーなどで日本語に切り替えられ、［Enter］キーで確定するか［Esc］キーで取り消すと英数に戻る。 
 　これまでは「Minecraft」などのゲームで「Meltype IME」が動作しなくなり、日本語を打つ手段がなかったが、今後はゲーム内のチャットなどでも「Meltype」で日本語変換が行えるようになる。 
 　なお、［Meltype キーボード］はこれまで通り、ゲームでは動作しない。 
辞書の拡充
 　さらに、医療（病名・医薬品・部位）、IT、駅名、固有名詞、人名、法律の題名といった分野の辞書が追加され、変換できる語が増えた。分野辞書の語は候補一覧でひらがな・カタカナの後ろに並ぶため、普段の候補の順番は変わらない。英字の国名を、日本語の文の中でも英語として扱うようにする改善も加えられている。 
『こうえきつうほ』と入力すると、『公益通報者保護法』が候補に表示された
 　そのほかのおもな変更は以下の通り。 
通貨の換算額を有効数字2桁に丸めるように（例：『100どる』→『約1.6万円』）
Windows版の設定画面に［適用］ボタンを追加。設定画面を閉じずに変更を反映できる
Windows版で、前の版の「Meltype IME」が残っていて入力できないアプリでは、入力位置に「再起動してください」と表示
『ばーじょん』の候補に、OSと使っている入力方式も表示（例：『Meltype-1.6.0 (Windows / Meltype IME)』）
Windows版の［Meltype キーボード］で、入力途中に『?』などの［Shift］キーを使う記号を入力すると、［Shift］キーなしの文字（『?』は『・』）になる問題を修正
更新前に、自分で英字/かなに直したことのある語のうち、新しい版で判定が変わるものが一覧表示される
「Meltype IME」の更新を確認するダイアログ。更新には管理者権限が必要
 　「Meltype」は
「GitHub」
でホストされているオープンソースプロジェクトで、ライセンスは「GPL-3.0」。Windows版に加え、プレビューとしてMac版とLinux版（IBus/fcitx5の入力メソッド）が提供されている。Windows版の対応OSは、64bit版のWindows 10/11。現在、
「GitHub」のリリースページ
から無償でダウンロードできる。インストール版のWindows版は自動で更新される。

Meltype v1.6.0
漢字変換を、すべての OS で Mozc と Zenzai にそろえました。医療・IT・駅名・人名などの分野の辞書を足し、変換できる語を増やしました。Meltype IME はゲームの中でも使えるようになり、チャットで日本語を打てます。
変わったこと
漢字変換を、すべての OS で Mozc と Zenzai で行うようにしました
。これまでは Windows が Mozc と Microsoft IME、Mac が azooKey で変換していたので、OS ごとに変換結果が違っていました (
#1749
)。
設定「変換エンジン」はなくなりました。
Windows: Microsoft IME に登録した語は、候補に出なくなります。使いたい語は Meltype のユーザー辞書に登録してください。
Mac: 対応する macOS は 13.3 以降になりました。
Windows: Meltype IME は、ゲームの中でも止めずに英数で始めるようにしました
。チャットでは 半角/全角 などで日本語にでき、Enter で確定するか Esc で取り消すと英数に戻ります。これまでは Minecraft などのゲームで Meltype IME が何もしなくなり、日本語を打つ手段がありませんでした。Meltype キーボードは、今までどおりゲームでは何もしません (
#1859
)。
通貨の換算の額を、有効数字 2 桁に丸めるようにしました
。同梱したリリース時点のレートで計算した概算なので、細かい数字は出しません。例: 「100どる」で「約1.6万円」 (
#1882
)。
新しい機能
分野の辞書を足しました
。医療 (病名・医薬品・部位)、IT、駅名、固有名詞、人名、法律の題名の語を変換できます。候補の一覧では、ひらがな・カタカナの後ろに並ぶので、ふだんの候補の順番は変わりません (
#1861
, 
#1866
)。
英字の国名を、日本語の文の中でも英語として扱うようにしました
 (
#1861
)。
Windows: 設定画面に「適用」ボタンを追加しました
。設定画面を閉じずに、変更を反映できます (
#1853
)。
Windows: 前の版の Meltype IME が残っていて打てないアプリでは、打っている所に「再起動してください」と出すようにしました
。これまでは起動中に 1 回だけ出る通知を見逃すと、打てない理由が分かりませんでした (
#1844
)。
「ばーじょん」の候補に、OS と使っている入力方式も出すようにしました。例: 
Meltype-1.6.0 (Windows / Meltype IME)
。不具合を報告するときにお使いください (
#1881
)。
入力・変換の改善
Windows (Meltype キーボード): 打っている途中に 
?
 などの Shift を使う記号を打つと、Shift なしの文字 (
?
 が 
・
) になる問題を修正しました (
#1836
)。
読みと表記が違う語 (「きずく」の「気づく」、「ばいおりん」の「ヴァイオリン」など) も、Zenzai の変換結果を使うようにしました (
#1800
)。
その他の修正
誤変換を調べやすいように、確定のたびに、英語と日本語をどう区切ったかの理由をログに残すようにしました。打った文字は、設定「ログに入力した文字を残す」が ON のときだけ残します (
#1865
)。
不具合の報告フォームの項目を減らし、書きやすくしました (
#1563
)。
