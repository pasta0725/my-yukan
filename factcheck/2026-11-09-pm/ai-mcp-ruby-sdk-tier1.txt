MCP仕様を完全にサポートしたMCP公式のRuby SDKが登場。「MCP SDK Tier 1」に到達と
2026年11月9日
Linux Foundation傘下でMCP（Model Context Protocol）の仕様策定を行っている「Agentic AI Foundation（AAIF）」は、MCP公式のRuby SDKがMCP仕様を完全にサポートした
「MCP SDK Tier 1」に到達したことを明らかにしました
。
これによりRubyからMCPの最新機能であるステートレスな接続などを含む全機能を利用することが可能となり、Ruby開発者はMCPを活用したアプリケーションを安心して本番環境に投入できるようになります。
Tier 1は全機能のサポート
MCP SDKは、以下の3つのティア（Tier）に分かれています。
Tier 1
すべてのプロトコル実装を完全にサポートしたSDK
Tier 2
すべてのプロトコル実装を目指して積極的にメンテナンスされているSDK
Tier 3
実験的あるいは部分的に実装されているSDKあるいは特別版のSDK
Ruby SDKは今年（2026年）7月にバージョン1.0に到達していましたが、この時点でTier 2の状態でした。
今回のTire 1到達では、上記の図で示されるようにサーバとクライアントの全実装が適合し、ドキュメントでは非推奨化されているために明示的に除外された2つ以外が適合しています。
これでRubyはTypeScript、Python、C#、Go、Rustに続くMCP SDKのTier 1対応言語となりました。
またRuby SDKチームは、2027年3月下旬を目標とした次期MCP仕様のサポートも約束しているとのことです。
