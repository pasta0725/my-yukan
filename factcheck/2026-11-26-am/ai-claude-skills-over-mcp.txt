MCPに新機能「Skills over MCP」登場。ツールとの接続だけでなく使い方のスキルもMCP経由で提供
2026年11月26日
AIエージェントと外部ツールを接続する業界標準となっているMCP（Model Context Protocol）に、新機能として「
Skills over MCP
」が
β版として追加されました
。
Skills over MCPを利用することで、AIエージェントはMCP経由でMCPサーバからつねに最新のスキルを取得できるようになります。また、必要なときだけスキルを読み込めるためコンテキストの節約にもなります。
下図はMCPの開発を主導するAnthropicのブログ「
MCP servers can now ship skills, run tasks, and more with Claude
」からの引用です。
AIエージェントと外部ツールをつなぐMCP
MCPはAIエージェントと外部ツールを接続するためのプロトコルとして登場しました。
例えばAIエージェントがデータを集計するためにデータベースの操作を行う場合、あるいはAIエージェントがミーティングを設定するために共有カレンダーを操作する際などに、AIエージェントはMCP経由でデータベースや共有カレンダーなどの外部ツールと接続し、操作を行います。
このとき、AIエージェントが的確に外部ツールを操作するためには、AIエージェントにスキルを注入することが必要です。
いままでMCPとそれを使うスキルは別だった
これまでこのスキルは、AIエージェントの実行環境においてSKILL.mdファイルなどのスキルファイルを用いてAIエージェントに提供されてきました。
しかしこの方法だと、外部ツールがアップデートされて機能が追加されたり更新されたとしても古いスキルのまま放置される可能性があることや、最初から多数の外部ツールのスキルを読み込ませることで余計なコンテキストが増えてしまう、といった課題がありました。
MCPサーバからスキルを読み込ませる
今回β版となった新機能Skills over MCPは、AIエージェントがMCP経由で外部ツールを操作できるだけでなく、MCP経由でスキルも読み込むことができるようになるというものです。
これによりAIエージェントはつねに外部ツールが用意した最新のスキルを得ることができます。
またAIエージェントが必要なときだけスキルを読み込むことができるため、コンテキストを効率的に使うことも可能になります。
AnthropicはこのパブリックベータとなったSkills over MCPの対応を開始しており、ClaudeおよびClaude CodeのPro、Max、Ultraプランではデフォルトで有効化されるとのことです。

===== https://claude.com/resources/articles/skills-over-mcp-tasks-and-more
(status 200)
Skills over MCP is now in public beta in Claude, so MCP servers can ship skills alongside their tools. We're also giving servers ways to handle longer, more interactive work with Claude: Tasks and Elicitation are now generally available, and File Uploads is rolling out soon.
Two years ago, Anthropic 
launched the Model Context Protocol (MCP)
 as a new standard for connecting AI agents to the systems where data lives. The spec has kept evolving to meet the connectivity needs of agents in production, and is becoming foundational for agentic messaging and orchestration.
With today’s updates, Claude can work with a server more like it works with another agent: learning from it, delegating to it, and exchanging input and files along the way.
Ship expertise alongside tools with Skills over MCP
Tool names and descriptions tell Claude what a server can do, but don't cover how to handle specific use cases. With 
Skills over MCP
, servers can publish skills alongside their tools to help Claude take on longer, multi-step work. Claude loads a skill only when it's needed, keeping context use low. Skills update with the server, so developers can ship tools and guidance together and users have nothing separate to install.
Skills can cover best practices, step-by-step workflows, or even playbooks tailored to a user's account or organization. Using Skills over MCP:
Shopify
 helps Claude design and update a merchant's online store end to end.
HubSpot
 onboards customers and gets them set up in Claude.
Atlassian
 helps Claude draw on deep organizational context for insights and work analysis.
Carta
 will help Claude draft and issue equity from an uploaded document (coming soon).
Skills over MCP is in public beta in Claude and Claude Code, on by default for Pro, Max, and Ultra plans and available to Team plans once an admin enables it. Coming soon to Enterprise.
MCP servers can now take on long-running, interactive work with Claude
Agents in production are taking on longer, more consequential jobs. Servers can now support that work by running it in the background, checking in with users, and receiving files from Claude.
Hand off long-running work with
Tasks
.
 Tool calls used to have to finish before Claude could move on. With Tasks, servers can run operations that take time, or even full agent loops, while Claude keeps working and picks up the result when it's ready. Using Tasks, 
ZoomInfo
 runs deeper accounts and contact research that previously took several prompts.
Ask for input mid-call with
Elicitation
.
 Some actions need a user’s sign-off, like spending money or deleting data. With Elicitation, a server can pause to ask the user for input through a form or link, then continue where it left off. Using Elicitation:
Supabase
 confirms costs before creating a paid project and before running destructive SQL.
Railway
 asks before making potentially destructive changes, like removing a service.
GitHub
 has users enter a repository's name before an agent deletes it.
Tasks and Elicitation are now generally available in Claude and Claude Code for Pro, Max, and Ultra plans, and rolling out to Team and Enterprise organizations.
Send and receive files with
File Uploads
.
 Claude will be able to pass files to MCP servers, not just text. The File Uploads extension sends PDFs, spreadsheets, and images to a server without passing them through the context window.
File Uploads is rolling out soon in Claude and Claude Code to Pro, Max, Ultra, and eligible Team and Enterprise plans.
Add support to your plugins today
These features are part of the open MCP spec and its extensions, so a server that supports them works in any compatible client, not just Claude. To add support, see the docs for 
Skills over MCP
, 
Tasks
, 
Elicitation
, and 
File Uploads
.
Built on stronger foundations for connecting agents in production
Thanks to contributions from across the AI ecosystem, MCP now sees over 700 million monthly SDK downloads, and there are over 10,000 MCP connectors for Claude. We've worked with the MCP community to improve how MCP works in Claude. Over the past year, it has become:
More token efficient:
Tool search
 loads tool definitions only when needed, which can cut the context they use by over 85% in multi-server setups.
Easier to scale:
 The 
latest MCP spec
 is stateless and supported across Claude products, making it easier to build servers and maintain their reliability as they grow.
Simpler to authorize:
 The 
Enterprise Managed Auth
 extension lets admins authorize supported servers once, so users connect automatically.
More interactive:
 The 
MCP Apps
 extension brings full interfaces into Claude, beside the conversation or full screen.
Together, these improvements make MCP easier to build on and adopt, and give the standard a strong base to continue evolving for the needs of agents in production.
Thank you to the MCP community
MCP is an open standard, hosted by the 
Agentic AI Foundation
 and shaped by the people who build on it. 
Two years of progress
 came from the maintainers, contributors, and developers who wrote the spec, built the SDKs, shipped servers, and added client support. Thank you for making MCP what it is today.

MCP turns two! What started as a protocol for connecting AI apps to tools and data is evolving to standardize how agents communicate and orchestrate work.
We’re bringing more of these agentic capabilities to Claude with Skills over MCP and Tasks.

November 24, 2026
MCP
（Model Context Protocol）は、AIエージェントを外部のシステムにつなぐための規格で、Anthropicが2024年11月にオープンソースとして公開しました。
2025年12月には、AnthropicがMCPをLinux Foundation傘下のAgentic AI Foundationに寄贈し、以降MCPは特定の企業に属さないオープンな規格として、この団体のもとで運営されています。
MCPのSDKは、月間ダウンロード数が7億回を超え、Claudeで使えるMCPコネクタも1万を超えています。
サーバーがスキルを配布できる「Skills over MCP」
Skills over MCP
は、MCPサーバーがツールと一緒にスキルを公開できる機能です。スキルにはベストプラクティスや作業手順のほか、ユーザーのアカウントや組織ごとのやり方も盛り込め、Claudeが複数のステップにまたがる長い作業をこなす際に役立ちます。
スキルは必要なときだけ読み込まれるので、コンテキストの消費を抑えられるのも特徴。また、サーバーと一緒に更新されるため、開発者はツールとスキルをまとめて配布でき、ユーザーはスキルを別にインストールする必要もありません。
MCPサーバーは、Claudeが実行できる操作（ツール）と取り込める情報（リソース）に加え、ユーザーや組織に合わせた知識（スキル）を提供する（画像は
Claude公式サイト
より引用）
処理をまかせる「Tasks」と入力を求める「Elicitation」
Tasks
（MCPタスク）は、ビルドやレポートの書き出しのような処理から、エージェントループ全体といった、時間のかかる処理をサーバーにまかせる機能。Tasksを利用すれば、サーバーが処理を進めている間もClaudeは作業を続けられ、終わったら結果を受け取るといったことが可能です。
（画像は
Claude公式サイト
より引用）
Elicitation
（エリシテーション）は、サーバーが処理をいったん止め、ユーザーの了承が必要な場面などで入力を求め、中断したところから再開できる機能です。
TasksとElicitationは、ClaudeとClaude CodeのPro、Max、Ultraプランにおいて正式版として公開。TeamとEnterpriseの組織へは順次展開中です。
また、近日中にはMCPの拡張機能「
File Uploads
」により、ClaudeからMCPサーバーへテキストだけでなくファイルも渡せるようになる予定です。
これら4つの機能は、いずれもMCPのオープンな仕様とその拡張機能に含まれるため、対応したサーバーはClaudeだけでなく、同じ機能に対応したほかのクライアントからも使えます。
なお、Skills over MCPは記事執筆時点では開発中。正式版では変更される可能性があります。

===== https://thetrail.jp/news/claude-skills-over-mcp/
(status 200)
この記事の要点
Anthropic が2026年11月24日、MCP サーバーがツールと一緒にスキルを配れる Skills over MCP を、Claude と Claude Code で公開ベータにした。
時間のかかる処理を任せる Tasks と、処理の途中で利用者に入力を求める Elicitation は一般提供になった。
Skills over MCP は Pro、Max、Ultra で既定で有効になる。Team は管理者が有効にすると使え、Enterprise には近く提供する。
目次
6
何が発表されたか
Claude
 を提供する Anthropic は2026年11月24日、MCP サーバー向けの機能をまとめて発表した。MCP（Model Context Protocol）は、AI をデータのあるシステムにつなぐための共通の規格である。MCP サーバーはこの規格に沿ってサービスの機能を Claude に渡すプログラムだ。
中心は 
Skills over MCP の公開ベータ
である。
Anthropic の発表
によると、ツールの名前と説明は、サーバーに何ができるかを伝えるだけで、個々の用途での進め方までは伝えられなかった。今後はサーバーがツールと一緒にスキルを公開できる。スキルには作業のよい進め方や手順、利用者の組織に合わせた手引きを書ける。
Claude はスキルを必要なときだけ読み込むので、コンテキスト（AI が一度に扱う情報）をあまり使わない。スキルはサーバーと一緒に更新される。
利用者の側で、別に何かを入れる必要はない
。
発表には、MCP サーバーが Claude に渡す3つの層を示した図が載っている。スキルは利用者や組織に合わせた分野の知識、ツールは Claude が取れる行動、リソースは Claude が読み込める情報だ。
出典：Anthropic
使う例として、発表は Shopify、HubSpot、Atlassian を挙げている。たとえば Shopify は販売者のオンラインストアの設計と更新を、Claude が最初から最後まで進めるのを手伝う。Carta も近く対応する予定だ。
Tasks は時間のかかる仕事をサーバーに任せる機能である。これまでは、ツールの呼び出しが終わるまで Claude は次に進めなかった。Tasks では、サーバーが時間のかかる処理を動かす間も Claude は作業を続け、結果ができたら受け取る。発表にはこの流れを示した図も載っている。
出典：Anthropic
Elicitation はお金を使う操作やデータを消す操作のように、利用者の承認が要る場面のための機能だ。サーバーは処理を止め、フォームかリンクで利用者に入力を求めてから続ける。例として GitHub は、エージェントがリポジトリを消す前に、利用者にそのリポジトリの名前を入力させる。
File Uploads は近く提供が始まる。Claude が PDF、表計算のファイル、画像を MCP サーバーに渡せるようになる。
これらは公開されている MCP の仕様と拡張機能の一部で、対応したサーバーはほかの対応クライアントでも動くという。発表によると、MCP の SDK のダウンロードは月に7億回を超え、Claude 向けの MCP コネクタは1万を超える。
