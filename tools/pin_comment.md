# 固定コメントを固定する手順（2026-11-13〜、ユーザーの依頼「これから毎回固定」）

コメントの固定は YouTube の API ではできないので、パソコンの内蔵ブラウザで YouTube Studio を使う。パソコンが使えないときは何もせず終わる（次の日にまとめてやる）。

1. 対象：チャンネルの最近の動画のうち、自分（@星餓りな）のコメントがあってまだ固定されていない公開済みの動画（channel/shorts_log.csv の新しい順に、直近3本まで見る）。
2. 内蔵ブラウザで https://studio.youtube.com/video/<動画ID>/comments を開く（チャンネルID UCDIg0hL5OV6xB5V8GtV-g9A の Studio。「わかばのぱすた」になっていたら星餓りなに切り替える）。
3. 一覧の上の「返信状況: 未返信」の絞り込みを「削除」ボタンで外す（自分のコメントが隠れるため）。
4. ページの文字に「@星餓りな さんによって固定されています」があれば、もう固定済みなので次の動画へ。
5. @星餓りな のコメントの「操作メニュー」を押し、メニューの「固定」を押す（find で出ないときは JavaScript で、見えている tp-yt-paper-item の「固定」を click）。確認の「このコメントを固定しますか？」で「固定」を押す。
6. ページの文字で「固定されています」を確かめる。
7. 自分のコメントがない動画は何もしない（コメントを新しく書かない）。他の人のコメントは固定しない。
