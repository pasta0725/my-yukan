# 自動で賢くなる仕組み（2026-11-10〜、ユーザーの依頼）

活動全体（YouTubeショート・ニュースサイトとマイ夕刊・作業の質・お金と利用枠）を、数字を見て少しずつ良くする。
ユーザーの決定：**小さな調整は自動、大きな変更は相談**。

## 流れ
1. **毎日 09:13**：metrics.yml（tools/collect_metrics.py）が数字を集め、ブランチ metrics の metrics/<日付>.json に置く。
2. **毎週月曜 12:47**：予定作業「週1回の見直し」が、この文書の手順で数字を読み、週報を書き、params.json を少し動かし、大きな変更を提案する。
3. ユーザーが提案に答えたら（チャットで番号を言うなど）、Claude がその変更を行い、changelog.md に書く。

## 自動で変えてよいもの（params.json の値だけ）
- 1回の見直しで、各値は step まで、min〜max の中だけ動かす。理由と前後の値を changelog.md に1行で書く。
- 判断に使う数は、4本（4号）以上たまってから。2週続けて同じ向きのときだけ動かす（1回のぶれで動かさない）。
- **カテゴリの本数（edition.category_limits）**：1記事あたりの読まれ方（サイトのカテゴリ別訪問数 ÷ そのカテゴリの記事数、直近4週）が一番高いカテゴリを +1、一番低いカテゴリを −1（合計の本数は変えない）。ユーザーの関心の話題（spec.md の Personal-interest topics）は本数と別枠なので、ここでは触らない。
- **記事選びの点数（shorts.selection_points・category_bonus）**：公開から7日以上たったショートで、7日目の再生（あれば engagedViews、なければ views）を、カテゴリ・点数の項目ごとにチャンネル全体の中央値と比べる。中央値より2週続けて上なら +1、下なら −1。
- **公開時刻（shorts.publish_time）**：最初の4週は choices を1週ずつ順番に試す（毎週、次の時刻に変える）。全部試したら、7日目の再生の中央値が一番高い時刻に固定し、以後は2割以上の差が出たときだけ変える。
- 値を動かしたら、その週の週報に「何を・なぜ・前後の値」を書く。悪くなったら翌週に戻してよい。

## 相談すること（自動では変えない）
- 声・キャラクター・画面の作り・事実確認のやり方、ルール文書（style.md・spec.md・shorts_rules.md など）の書き換え。
- 予定作業の時刻や本数（1日の動画の本数、号の回数）、新しいサービスの導入、お金がかかる変更。
- params.json に無い数値、min〜max の外への変更。
- 書き方：週報の最後に「提案」として番号付きで、何を・なぜ（数字）・どう変わるか・リスクを2〜3行で。

## 週報で見ること
- **YouTube**：本数、7日目の再生・高評価・登録者の増え方（チャンネル全体と1本ずつ）、伸びた／伸びなかったものの共通点（カテゴリ・タイトルの型・冒頭の型・公開時刻・点数の内訳）。analytics が unavailable なら、ユーザーに「YouTubeの数字を読む許可（yt-analytics.readonly）を1回出し直す」よう提案に入れる。
- **サイト・マイ夕刊**：訪問数の推移、カテゴリ別・記事別、どこから来たか（YouTubeから来ているか）、号ごとの参考記事の平均・参考記事1本だけの数・画像なしの数・図解の数・Xの声の数。
- **作業の質**：「AIからの報告」の開いている件数と中身、失敗したワークフローの回数。同じ失敗が2回以上なら、直し方を提案（小さなバグ修正で、ルールや方針を変えないものは自分で直して報告してよい）。
- **お金と利用枠**：Modal の今月の使用額（30ドルを超えそうなら警告と対策）、Colab の残り単位、読み上げ（narration）・Codex・話す動画の実行回数（Gemini 読み上げは1モデル1日10回）。
- 月に1回（第1月曜）は、ユーザーに YouTube Studio の「スワイプされずに見られた割合」を見てもらうお願いを1行入れる（API で取れない数字）。

## 出すもの
- tools/learning/reports/<年>-W<週>.md（週報）、params.json（動かしたとき）、changelog.md（1行ずつ追記）。main に push（前に fetch → rebase）。
- 通知（PushNotification と SendUserMessage、日本語・短く）：今週の一言まとめ、自動で変えたこと、提案（番号付き）。「提案は番号で『1をやって』のように Claude に言ってください」。
