# Grok Bot ルーティン「マイ夕刊 Xの声」

Grok Bot に毎日 18:00（日本時間）に実行するルーティンとして登録する。Gmail（pastachannel0725@gmail.com）を Grok Bot に連携しておく。
Claude 側は毎日 18:40 ごろ Gmail で件名「マイ夕刊 Xの声」のメールを探し、本文の JSON を
`python3 -I tools/save_x.py <mail.txt> <date>` で data/x/<date>.json に保存して push する（サイトが自動で記事に足す）。

## ルーティンの指示文

マイ夕刊（私専用のニュースアプリ）の「Xの声」を集めて、メールで送ってください。

1. 次のページを開いて、今日の記事一覧（JSON）を読んでください。
   https://pasta0725.github.io/my-yukan/data/x-todo.json
   date が今日（日本時間）でなければ、30分待って読み直してください（2回まで）。それでも古ければ、そのまま進めてください。
2. 各記事（articles の1件ずつ）について、Xを検索して、そのニュースへの「個人の感想・意見」の投稿を探してください。
   - 載せる：その話題について自分の言葉で感想・意見・体験・期待・不満を書いている投稿（日本語）
   - 載せない：ニュースの見出しやリンクを共有しただけの投稿、記事の内容を要約しただけの投稿、ニュースサイト・企業・公式アカウントの投稿、宣伝・アフィリエイト・クーポン、ボット、20文字未満の短い投稿、別の話題の投稿、誹謗中傷や差別的な投稿
   - 記事の日付（date）の前後数日の投稿だけ
   - 1記事あたり最大10件。見つからなければその記事は空でかまいません。無理に集めないでください
   - 同じ投稿を2つの記事に入れないでください
3. 実在を確認した投稿のURLだけを使ってください。URLを推測したり作ったりしないでください。
4. 結果を pastachannel0725@gmail.com 宛てにメールで送ってください。
   - 件名：マイ夕刊 Xの声 (x-todo.json の date)
   - 本文：次の形の JSON だけ（説明文は不要）。text は投稿の本文をそのまま。
{"date":"(x-todo.json の date)","posts":{"(記事の id)":[{"url":"https://x.com/ユーザー名/status/数字","text":"投稿の本文"}]}}
