# Grok Bot に「Xの声」を集めてもらう指示文

下の「指示文」をそのまま Grok Bot に貼り付ける（ルーティンにするときも同じ文）。
答えの JSON は `python3 -I tools/save_x.py <answer.txt> <date>` で data/x/<date>.json に保存する。
サイトは data/x/<date>.json があれば、その号の記事に自動で足して表示する（表示できない投稿は自動で隠す）。

## 指示文

マイ夕刊（私専用のニュースアプリ）の「Xの声」を集めてください。

1. 次のページを開いて、今日の記事一覧（JSON）を読んでください。
   https://pasta0725.github.io/my-yukan/data/x-todo.json
2. 各記事（articles の1件ずつ）について、Xを検索して、そのニュースへの「個人の感想・意見」の投稿を探してください。
   - 載せる：その話題について自分の言葉で感想・意見・体験・期待・不満を書いている投稿（日本語）
   - 載せない：ニュースの見出しやリンクを共有しただけの投稿、ニュースサイト・企業・公式アカウントの投稿、宣伝・アフィリエイト・クーポン、ボット、20文字未満の短い投稿、別の話題の投稿、誹謗中傷や差別的な投稿
   - 記事の日付（date）の前後数日の投稿だけ
   - 1記事あたり最大10件。見つからなければその記事は空でかまいません。無理に集めないでください
3. 実在を確認した投稿のURLだけを使ってください。URLを推測したり作ったりしないでください。
4. 答えは次の形の JSON だけを、コードブロック1つで返してください（説明文は不要）。
```json
{"date":"(x-todo.json の date)","posts":{"(記事の id)":["https://x.com/ユーザー名/status/数字", "..."]}}
```
