# 星餓りな ショート動画の作り方メモ（次回以降に必ず守る）

岡野タケシ弁護士の人気ショート20本の構成解析レポートの型に合わせる。
2026-11-06 の「AIがAIを作る時代」を振り返って、足りなかった点を追記した。

## 構成（約45〜60秒）
1. 0〜4秒 つかみ：挨拶なし。一番強い絵＋結論を**4秒以内の1文で言い切る**（「〜かもしれません」でぼかさない）。
2. 4〜6秒 登場：星餓りなが大きく出て「このニュース、ざっくりまとめます」。ロゴは出さず、画面にはその日のニュースの見出し（何の話か）を出す。
3. いつ・どこ・誰：日付、国・地域、会社名を画面に出す。
4. 経緯：**3〜4秒ごとに絵を切り替える**（別カット、ズーム、図解の段階表示）。
5. 反転：「ただし」「ところが」＋赤スタンプ＋重い効果音。
6. 結末：数字や結論カードで言い切る。
7. 終わり：最強の一言で切る。声なしのロゴ画面は付けない（見ている人がスワイプして「最後まで見た」率が下がり、ループ再生もしにくくなる）。最後の一言が冒頭につながるとなお良い。登録のお願いはしない。

## 画面と字幕
- **星餓りなのロゴは動画に入れない**（隅のロゴも含む）。ショートの画面にはチャンネル名とアイコンが最初から出るので重複になり、図解の場所も取る。覚えてもらうのはロゴではなく、キャラと声と中身。
- 字幕は全部の発言に付ける。1画面5〜15字、**0.5〜1秒で切り替え、1本で40〜50回を目安**に細かく切る。
- 色の意味を固定：オレンジ＝数字・重要語・結論、赤＝注意・反転だけ、青＝会社名・人物・事実。
- 小さいキャラは**ずっと出さない**。登場・反転・結論など2〜3か所に絞り、ほかの場面は図解と絵を大きく見せる。
- 生成画像・生成動画には必ず「※画像はイメージです」と小さく表示する。実際の画像には出典を表示する。
- 引用（申請書の言葉、関係者のセリフ、ネットの反応）は別の声にする。

## 声
- 声11（Leda・気だるい・です／ます）を使う。話す速さは1分あたり約350〜380字。
- 原稿の「っていう」など、声の言い方に字幕を合わせる。

## 事実確認
- 断定する内容は、元記事（一次情報か大手メディア）で必ず確かめる。数字は2つ以上の記事で裏を取る。
