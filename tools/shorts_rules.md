# 星餓りな ショート動画の作り方メモ（次回以降に必ず守る）

岡野タケシ弁護士の人気ショート20本の構成解析レポートの型に合わせる。
2026-11-06 の「AIがAIを作る時代」を振り返って、足りなかった点を追記した。

## 構成（話し終わるまで約30〜45秒、最大1分）
1. 0〜4秒 つかみ：挨拶なし。一番強い絵＋結論を**4秒以内の1文で言い切る**（「〜かもしれません」でぼかさない）。
2. 4〜6秒 登場：星餓りなが大きく出て「このニュース、◯◯でまとめます」。◯◯＝この台詞のあと話し終わるまでの長さを10秒単位で切り上げた数で、**最大1分**。60秒のときだけ「1分」と言い、それ以外は「40秒」のように言う（最後のロゴ画面は数えない。tools/short_plan.py の {SEC} で自動計算。60秒を超えたら終了コード4なので台本を削る。2026-11-08 ユーザー決定）。
   - **りなは手でその数字を作る**：50秒→指5本、40秒→指4本、30秒→指3本、1分→指1本（plan の fingers）。片手を顔の横に上げて指を立てたまま話す絵（channel/rina_poses/rina_fingers_<本数>.png、緑背景・base_green と同じ構図）を口の動きの元画像にする（colab_longcat_remote.py の jobs で intro に画像名を指定）。指の本数が正しいか、書き出し後に必ず目で確かめる。
   - ロゴも、頭の上の見出しの文字も出さない（2026-11-07 ユーザー指示）。字幕はふつうのテロップ。
3. いつ・どこ・誰：日付、国・地域、会社名を画面に出す。
4. 経緯：**3〜4秒ごとに絵を切り替える**（別カット、ズーム、図解の段階表示）。
   - 新機能・新製品のニュースは「これまで → これから」の対比で、何が進化したのかを必ず言う。機能の一部（例：表を作る）だけ見せると「それだけ？」に見える（2026-11-07 ユーザー指摘）。
5. 反転：「ただし」「ところが」＋赤スタンプ＋重い効果音。
6. 結末：数字や結論カードで言い切る。
7. 終わり：最強の一言 → 声なしロゴ約2秒（ロゴを出すのはここだけ）。登録のお願いはしない。

## 画面と字幕
- **星餓りなのロゴは最後のロゴ画面だけ**。隅のロゴや登場場面の大きなロゴは出さない（ショートの画面にはチャンネル名とアイコンが最初から出るので重複になり、図解の場所も取る）。
- 字幕は全部の発言に付ける（吹き出しの中）。1画面5〜15字、**0.5〜1秒で切り替え、1本で40〜50回を目安**に細かく切る。
- 色の意味を固定：オレンジ＝数字・重要語・結論、赤＝注意・反転だけ、青＝会社名・人物・事実。
- **画面の形（2026-11-07 ユーザー決定：吹き出し型）**：1080×1920 で、
  - 上：図解・絵は y 約350〜1130 を使い切る（字幕の帯はもう無いので、上の方に空きを作らない。YouTubeのタブで隠れる y 330 より上には大事なものを置かない）。
  - 左下：りな（小さめ、全身。だいたい x 22〜400・y 1188〜1860、顔が y 1280〜1370 あたり）。下半身はYouTubeのタイトル表示（y 約1480〜）と重なってよい。
  - 右下：**字幕はりなのセリフとして吹き出しに入れる**。吹き出しは安全な範囲いっぱい（x 372〜915・y 1165〜1440、右のボタン列とタイトルにかからない）。しっぽはりなの顔に向ける。白地・青（ブランド色）の太い枠、文字は紺で数字はオレンジ。
  - 吹き出しの字幕は単語の切れ目で改行し、助詞・小さい字・「た」「だ」から行を始めない。2行が基本、長いときは3行。
  - **りなを大きく見せる場面（登場・結論）は吹き出しにしない**。りなの胸のあたり（y 約1330）に、白い縁取りのふつうのテロップを出す。
  - 吹き出しの白い地と青い枠は1本の輪郭で描く（しっぽの付け根に線が入らないように）。
  - 作り方の見本：shorts/_template/short.html（canvas の bubble()・bubbleText()・wrapJa()）。
- 絵は公式の画像・動画を優先する（.github/workflows/fetch-media.yml で media/<名前>/ に取り込む。urls.txt に「ファイル名 URL」）。アプリ画面の動画はスマホの枠に入れ、セリフに合う場面を選んで見せる（細かい所は拡大）。
- 生成画像・生成動画には必ず「※画像はイメージです」、実際の画像には出典を小さく表示する。出典は見出しと重ねず、絵の右下に白い小札で置く。
- 引用（申請書の言葉、関係者のセリフ、ネットの反応）は別の声にする。

## 声
- **息継ぎなしで話す（岡野タケシ風、2026-11-07 ユーザー指示）**：「。」のあとは息継ぎせずに次の文へ（間0.04秒、行と行のあいだも0.03秒）。「、」では息継ぎしてよい（間は最大0.3秒）。小さい「っ」などの短い無音（0.14秒未満）は削らない。tools/short_plan.py の period_pause=0.04・comma_max=0.30・gap=0.03、速さ speed は1.15前後。
- 声11（Leda・気だるい・です／ます）を使う。話す速さは1分あたり約350〜380字。
- 原稿の「っていう」など、声の言い方に字幕を合わせる。
- 音声ができたら各セリフの長さを数字で確かめる（同じ文を2回読んでいることがある。そのときは1回目だけ切り出す）。

## 作業の手分け（2026-11-07 ユーザー決定）
- 同時に進める：事実確認（元記事・公式・別メディアを分担）、場面ごとの絵・図解、セリフごとの音声、投稿準備（サムネ・タイトル・概要欄・タグ・英訳・字幕）、最終チェック（作った本人以外）。単純な作業は Sonnet のサブエージェント。
- 順番どおり：台本 → 音声 → short_plan.py → 口の動き → 書き出し。レイアウト・色の判断は1か所でまとめて行う。
- 書き出しは shorts/_template/render_par.js で分割して同時に描く（N=CPUの数）。

## 事実確認
- 断定する内容は、元記事（一次情報か大手メディア）で必ず確かめる。数字は2つ以上の記事で裏を取る。
