# 星餓りな ショート投稿時の項目設定ルール（AI自動入力用）

調査レポート「YouTubeショートの概要欄・タグ・設定と再生数」（2026年11月）をもとにしたルール。
再生数を決めるのは主に「冒頭1〜2秒でスワイプされないか」「最後まで見られるか」。設定は「何の動画かを正しく伝える」「規約違反・量産判定を避ける」「海外の入口を増やす」ためのもの。3か月ごとに公式ヘルプと照らし合わせて見直す。

## タイトル
- 全角28字以内（目標20〜26字）。主役の固有名詞を最初の10字以内に置く。
- 型の例：「{主役}が{何をした}｜{影響の一言}」。毎回同じ型にせず、疑問形・断定形・数字始まりを順番に使う。
- 【】は「【速報】」（発表から24時間以内）と「【まとめ】」だけ。絵文字なし。#shorts とハッシュタグはタイトルに入れない。
- 誇張（死亡・終了・崩壊・ヤバすぎ等）は事実でない限り禁止。数字は事実の数字だけ。サムネ・動画の中身と一致させる。

## 概要欄（300〜600字）
```
{1行目：何が起きたかを40字前後で。主役の固有名詞を含める}
りなの見方：{日本の利用者への影響・りなの見解}

▼ポイント
・{要点1}
・{要点2}
・{要点3}

▼出典
{媒体名}（{YYYY年M月D日}）
{URL}
{媒体名}（{YYYY年M月D日}）
{URL}
※ショート動画では、概要欄のURLはタップできません

▼星餓りなについて
毎日1本、AI・テックのニュースを1分で解説しています。

#{主役} #AIニュース #星餓りな
```
- 出典は2つ以上（一次情報を優先）、媒体名と日付を文字で書く。キーワードの羅列は禁止。
- 「AIで作っている」ことは書かない（ユーザーの方針）。

## ハッシュタグ
- ちょうど3個、概要欄の最後に、半角#・スペースなし：#{主役} #AIニュース #星餓りな（主役が決まらなければ #テックニュース）。
- #shorts・#viral・関係のない流行タグは禁止。

## タグ欄（5〜8個、500文字以内）
- 星餓りな, {主役の英語表記}, {主役のカタカナ}, {関連製品名の英語/カタカナ}, AIニュース, {話題の用語}。表記ゆれ・誤字対策が目的。

## 固定の設定
- カテゴリ：科学と技術
- 動画の言語・タイトルと説明の言語：日本語
- 子ども向け：いいえ／年齢制限：なし／有料プロモーション：案件のときだけ「はい」
- AIの使用（AI use）：原則「いいえ」（アニメ調キャラ・汎用AI音声・イラスト調のAI図解は対象外）。
  「はい」にする条件：写真のようにリアルなAI画像・映像／実在の人物の顔や声を模した／AI生成の音楽が主役／実際の映像や写真をAIで改変。迷ったら「はい」。
- ライセンス：標準／埋め込み：許可／登録者に通知：オン／リミックス：動画と音声を許可／高評価数：表示
- コメント：オン、管理「標準」（不適切なものは保留）
- 再生リスト：「毎日1分AIニュース」に必ず追加（テーマ別リストは本数が増えてから）
- 関連動画：同じ主役の過去のショート（あれば）

## 字幕・多言語
- 台本のテロップ（plan.js の tel）から日本語SRTを作り、字幕ページの日本語トラックに「ファイルをアップロード → タイムコードあり」で上書き公開する（channel/captions/）。
- 英語の翻訳タイトル（60文字以内）と翻訳概要欄（要約2〜3行＋出典＋ #Anthropic #AINews #星餓りな の形）を毎回入れる。
- 多言語音声（自動吹き替え）は保留。試すときは英語だけ1か月、言語別の再生時間で判断。

## 投稿・運用
- 毎日7:00に予約公開（速報はすぐ公開）。登録者1,000人を超えたら、分析画面の視聴時間帯で調整。
- 固定コメント：「{視聴者への質問}／出典：{媒体名}」（投稿前にユーザーに文面を確認）。最初の24時間のコメントには返信かハート。
- 見る指標：視聴された割合（Viewed vs. Swiped）、平均視聴率、エンゲージビュー、登録者の増減。再生回数そのものでは判断しない。

## 量産判定を避ける必須チェック（投稿前）
- 台本に、りな独自の見解（なぜ重要か・日本への影響・予想）が1つ以上ある。
- 冒頭のフックの文が、直近7本と同じ型でない。図解・構成も毎回変える。
- 出典2つ以上、日付を確認済み。タイトル・概要欄の主張が動画と一致。
- 1日1本を守る。

## YouTube Studio の操作メモ
- 内蔵ブラウザの Studio は、右上のアカウントから「アカウントを切り替える → 星餓りな」にしてから操作する（チャンネルID UCDIg0hL5OV6xB5V8GtV-g9A）。「わかばのぱすた」のまま操作すると、再生リストなどがそちらに作られてしまう。
- カスタムサムネイルとコメントの固定は、星餓りなチャンネルの確認（電話番号・ワンタイム認証）が終わるまでできない（確認はユーザーが行う）。
- コメントは youtube.com 側も右上のアカウントで「星餓りな」に切り替えてから、通常の動画ページ（/watch?v=）で投稿する。
- タイトル・概要欄は contenteditable に execCommand('insertText') で入力できる。タグ欄は入力欄をクリックして「,」区切りで入力し Enter。
- 字幕：字幕ページで日本語行の鉛筆 →「トラックの上書き」続行 → エディタ右上の︙ →「ファイルをアップロード」→「タイムコードあり」→ 公開。英語のタイトル・説明は「言語を追加 → 英語」の行の鉛筆から。英語の説明欄は textarea なので、focus → select → execCommand('insertText') で入れる（form_input や type だと途中に挿入されて崩れる）。
- ファイル（動画・字幕・サムネ）は、ファイル選択ボタンを押す前に HTMLInputElement.prototype.click を差し替えて、raw.githubusercontent.com から取ったファイルを入れる。差し替え後のクリックは反映が数秒遅れることがあるので、すぐに別の入力欄へファイルを入れ直さない（2026-11-08、動画をサムネ欄に入れてしまった）。
- 公開ボタンのあと「動画を保存できませんでした。再試行します」と出続けても、公開・タイトル・説明は保存されていることがある。動画の詳細ページ（/video/<ID>/edit）を開いて、公開状態とサムネを確かめる。
- 投稿画面は横幅が狭いと要素が隠れるので、内蔵ブラウザの表示を 1300x900 にしてから操作し、終わったら元に戻す。
