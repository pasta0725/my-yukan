プライバシーポリシー（星餓りな投稿）

「星餓りな投稿」は、YouTubeチャンネル「星餓りな」の運営者が、自分のチャンネルに自分の動画を投稿するためだけに使う個人用のツールです。

このツールは YouTube Data API を使い、運営者自身のチャンネルへの動画・サムネイル・字幕・再生リスト・コメントの登録だけを行います。ほかの人のデータは扱いません。

取得した認証情報は、運営者の非公開の設定にだけ保存し、第三者に提供・販売することはありません。YouTube API サービスの利用には YouTube 利用規約 と Google プライバシーポリシー が適用されます。

YouTube API サービスについて

このツールは YouTube API サービスを使用しています。利用には YouTube 利用規約 と Google プライバシーポリシー が適用されます。

アクセス権の取り消しとデータの削除

このツールへのアクセス許可は、いつでも Google アカウントのセキュリティ設定（サードパーティ アクセス） から取り消せます。ツールは YouTube から取得したデータを保存しません。保存している認証情報は、取り消しの申し出から7日以内に削除します（連絡先：pastachannel0725@gmail.com）。
