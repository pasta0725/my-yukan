# りなのポーズ（口の動きの元画像、緑背景 720x1280）
- base_green.png：ふつうに立って話す（全編・結論で使う）
- rina_fingers_1/3/4/5.png：登場の「このニュース、◯◯でまとめます」で使う。指の本数＝1分→1、30秒→3、40秒→4、50秒→5。
  2026-11-09 に可愛い型へ描き直し（ユーザーが4案から選んだ型）：少し前かがみ・首をかしげる・口を開けた笑顔・左手は背中・右手は胸の前で指を立てる。
  手のひらを見せているので、時計は手の甲側（手首の内側には黒いバンドだけ）。
- 動き（ユーザー指示 2026-11-09）：「このニュース、」はいつもの立ち絵（base_green）で話し、そこから指のポーズへ動いて、「1分／◯秒」と言う瞬間に指のポーズになっているようにする。
  作り方：セリフを「このニュース、」と「◯◯でまとめます」に分けて、前半は base_green、後半は指のポーズで口の動きを作る。間の読点の間（0.2〜0.3秒）に、前半の最後のコマと後半の最初のコマのあいだを動きのコマ（フレーム補間）でつなぐ。
