Sakana AI、企業向けAI接続の先行受付を開始

AI11月3日（火）の号出典：Sakana AI

3行でわかる

  1. Sakana AIが、会社向けのAI接続サービスの先行受付を開始
  2. 最初に使えるのはFuguとFugu Ultra。日本語向けNamazuは後日
  3. Fuguの月額は20〜200ドル。入力が学習に使われるか契約前に確認

Sakana AIは会社向けの「Sakana API Platform」を発表し、先行利用の申し込み受付を始めました。

先行受付で使えるもの

APIとは、自社のアプリからAIを呼び出す入り口のことです。最初に使えるのは「Sakana Fugu」と、上位版の「Fugu Ultra」です。複数の大手AIを仕事に合わせて組み合わせる仕組みです。日本語に強い「Sakana Namazu」は、後から加わる予定です。

Sakana AIの発表では、会社向けの管理機能がそろいます。入力内容をAIの学習に使わない取り決め、利用履歴の記録、利用額の上限設定です。他社のAPIと同じ形式なので、つなぎ先を変えるだけで試せるといいます。

Fuguは複数のAIを使い分け

VentureBeatによると、Fugu自身もAIで、状況に応じて別のAIに仕事を振り分けます。ふだん使い向けのFuguと、難しい仕事向けのFugu Ultraがあります。

OpenAI互換の形式でつなぐため、すでに他社のAIを使っているシステムにも載せ替えやすい点が売りです。使わせたくないAIを選んで、振り分けの対象から外せる点も、Blockportが紹介しています。

日本語向けNamazuは後日

Namazuは、日本語向けに追加学習したAIです。窓の杜によると、Moonshot AIが公開するモデルKimi K2.6が土台です。日本語と日本の仕事のやり方に合わせて調整しています。

Namazuは2026年8月にAPIとして公開済みです。既存のOpenAI互換のコードは、接続先を変えるだけで使えるとされています。企業向けの窓口にいつ加わるかは、まだわかっていません。

料金の目安と数字の見方

VentureBeatによると、Fuguの月額プランは3種類です。Standardが20ドル、Proが100ドル、Maxが200ドルです。使った分だけ払う方式も選べます。Fugu Ultraは、100万トークン（AIが文字を数える単位）あたり入力5ドル、出力30ドルです。

Namazuは入力0.95ドル、出力4ドルで、月額プランはなく使った分だけの支払いです。DataNorthによると、これらの数字や性能の評価はSakana AI側が出したもので、第三者の確認は済んでいません。使い心地が数字ほどではないという声もあります。

提供地域と、入力内容の扱い

Fuguは、EUとEEAが一時的に対象外です。Namazuは、EU・EEAのほかイギリスやスイスでも提供されておらず、請求もドル建てのみです。

入力内容の扱いは製品で違います。Fuguは学習に使わせない設定ができると、VentureBeatが伝えています。Namazuは通常の利用だと入力が学習に使われる場合があり、管理画面で止められると、GiftXが解説しています。処理が国内で完結する保証もないと、GiftXは注意しています。

月20〜200ドルFuguの月額プラン
5ドル/30ドルUltraの入力/出力料金

あなたへの影響・やること

  • 会社で使うなら、入力が学習に使われない取り決めになっているか、契約前に確認する
  • 料金と性能の数字はSakana AI側の発表なので、まず小さく試して自分の仕事で確かめる
  • 請求はドル建てで、地域によって使えない製品もあるため、申し込み前に提供地域を確かめる
