Microsoft、Copilotの土台を開発者に公開

AI11月3日（火）の号出典：Microsoft公式ブログ

3行でわかる

  1. MicrosoftがCopilotの土台「Copilot harness」を、開発者に試用版として公開
  2. 12月1日まで無料。その後は実行環境の計算量に応じた料金と、AIの利用料がかかる
  3. 20以上のAIから仕事に合うものを選べる。日本での提供や日本語対応は未発表

Microsoftは10月28日、Copilotの土台「Copilot harness」を、開発者向けに試用版で公開しました。

ハーネスとは何をするものか

ハーネスとは、AIそのものではなく、その周りで指示、実行環境、権限の管理、安全の仕組みをまとめて動かす部分です。Microsoftは「モデルの周りのすべて」と説明しています。今回は公開プレビュー（正式版の前の試用段階）での提供です。

もともとはGitHubの技術者が作ったもので、次の製品を動かしています。 ・Copilot Code ・Copilot Studio ・GitHub Copilotのアプリとコマンド版 ・VS Code Copilot Studioでは、名前が「Microsoft Copilot harness」に変わりました。既存のエージェント（自分で作業を進めるAI）は、機能も課金もそのままです。

使い方と選べるAIの数

使うのは、Microsoft Foundryの「Agent Service」からです。Microsoftが作業の実行と、安全な隔離環境を受け持ちます。使う側は、手順、道具、使うAIを決めます。企業は、管理をMicrosoftに任せたまま、自社のAIアシスタントを作れます。

20以上の有力なAIに対応し、仕事に合うものへ振り分けます。設定ファイルで定義し、開発者向けのコマンドで展開します。自前のAIを持ち込めるかどうかは、報道で説明が分かれています。

料金と日本での提供状況

料金は、12月1日まで無料です。それ以降は次のとおりです（いずれも1時間あたり）。 ・計算：0.0994ドル（CPU1つ分） ・メモリー：1GiBあたり0.0118ドル AIの利用料や一部の道具の料金は、別に請求されます。

日本で使えるか、日本語に対応するかは、発表されていません。提供する地域やAIの詳細も、まだ出ていません。

使う前に知っておきたい制約

ハーネスの種類は、エージェントを作るときに決まり、あとから変えられません。CPUやメモリーの割り当ても、Microsoftが決めます。一部の分析記事は、手軽さと引き換えに自由度が下がるとみています。

Microsoft自身の社内評価では、テストの合格率が上がりました。従来の標準ハーネスと比べて、OpenAIのモデルで10.8ポイント、Anthropicのモデルで22.1ポイントです。ただ、第三者の確認はまだありません。本番での利用は、詳細が出るまで今の構成のままが無難、との見方もあります。

あなたへの影響・やること

  • 試すなら、12月1日までの無料期間が目安。ただしAIの利用料は別にかかる
  • ハーネスの種類はあとから変えられない。本番で使う前に、小さく試す
  • 性能向上の数字はMicrosoft自身の評価。自社の用途で確かめる
  • 日本の企業は、提供地域と日本語対応の発表を待つ
