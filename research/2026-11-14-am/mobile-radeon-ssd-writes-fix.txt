AMD releases optional driver to fix excessive system drive writes
AMD has released its optional AMD Software: 
Adrenalin Edition 26.11.1 driver
. The update addresses two issues that could cause excessive writes to the system drive during normal desktop use.
The first fix covers excessive drive writes while the system is idle. AMD lists Radeon RX 7000 series graphics cards and newer as affected by this issue.
© AMD
The second fix addresses excessive writes when moving or resizing application windows. AMD lists this separately and does not specify which graphics products are affected.
We recommend downloading and installing the new driver if you have experienced either problem. Although AMD labels this release as optional (so basically a hotfix), it includes official fixes for both causes of excessive drive writes.
With an official update now available, we recommend using this driver instead of third-party tools or unofficial workarounds for the write issue. Users who already applied a workaround should check its instructions for restoring the default settings before installing the update.

ストレージにデータを書き込み続ける不具合が修正された「AMD Software 26.11.1」リリース
ライター：米田 聡
　米国時間2026年11月12日，AMDは，「Radeon RX 5000」シリーズ以降のGPUおよび，RDNAアーキテクチャ以降のGPUを搭載するAPU向けのドライバソフト「
AMD Software Adrenalin Edition 26.11.1
」（以下，AMD Software 26.11.1）をリリースした。
　WHQL（Windows Hardware Quality Labs）を通過したOptional版であるAMD Software 26.11.1は，AMDの
公式フォーラムなどで報告
されていた，ストレージに不要な書き込みが続く不具合を修正したドライバだ。
　具体的には，AMD Softwareに含まれるコンポーネントのひとつである「AMD External Events Client Module」（atieclxx.exe）が，
1秒あたり0.3〜0.5MB程度
（※使用状況によって変わる）のデータをストレージに書き込み続ける不具合である。
　Windowsにログオンすると同時に書き込みが途切れなく続き，
1時間あたり最大1.8GB
の書き込み量になるので，PCの使用時間が長いユーザーだと，SSDの寿命（TBW）を縮めかねないと指摘されていた。
　ちなみに，AMD External Events Client Moduleは，AMD Softwareのショートカットキーやディスプレイ制御，オーディオの切り替えといったユーザーインタフェースを司るサービスだ。ウインドウを移動させると書き込みが起きていたので，もしかするとデバッグ用の情報をストレージに書き込むコードが，リリース版に残っていたのかもしれない。
　原因はともかく，少なくともAMD Software 26.10.1以降には，この不具合が存在していたとされる。PCの使用時間が長いRadeonユーザーは，SSDメーカー製のユーティリティや，ストレージ関連アプリの「CrystalDiskInfo」を使って，システムストレージの残り寿命を確認しておくのがいいだろう。
　ちなみに筆者のPCは，AMD SoftwareによってSSD寿命を少なくとも数％削られたようだ。SSD価格が高騰する現状では迷惑な話である。
　そういう事情なので，RadeonユーザーはAMD Software 26.11.1へのアップデートを強く推奨する。公式Webページにて，自分が利用している製品名で検索し，適切なインストーラを入手するか，「AMD Install Manager」を利用してインストールしてほしい。

●AMD Software 26.11.1における既知の問題
Radeon RX 7000シリーズGPUで「Assassin's Creed Black Flag Resynced」（アサシン クリード ブラック フラッグ RE:シンクロ）をプレイ中，断続的にゲームがクラッシュしたり，ドライバのタイムアウトが発生したりすることがある
Radeon RX 5000シリーズGPUで「War Thunder」をプレイ中，断続的にドライバのタイムアウトが発生することがある。この問題が発生したユーザーは，AMD Software 26.9.1へのロールバックを推奨するとのこと
一部のRadeon RX 9000シリーズGPUにおいて，セカンダリディスプレイで動画を再生中に「FSR Upscaling」「Radeon Anti-Lag」を有効にし，かつゲーム側のフレーム生成機能を有効にして「Cyberpunk 2077」をプレイすると，断続的にゲームがクラッシュしたり，ドライバのタイムアウトが発生したりすることがある。この問題が発生したユーザーは，ゲーム側のフレーム生成機能を無効にすることを推奨するとのこと
Ryzen AI Max PRO 400シリーズAPUを搭載したPCで，「Call of Duty: Modern Warfare Remastered」をプレイ中に［Alt＋Tab］キーを押すと，ゲームがフリーズすることがある
Ryzen AI 9 400シリーズAPUを搭載したPCで，「Gears of War: Reloaded」を起動すると，画面が黒くなることがある。この問題が発生したユーザーは，ゲームの表示モードをウインドウモードに切り替えてから，改めてフルスクリーンモードに戻すことを推奨するとのこと
「Hugging Face」および「GitHub」へのアクセスが制限されている一部の地域で，AI Bundleに含まれるコンポーネントのインストール中にエラーが発生することがある
Windows 10では，ドライバのインストール後に「AMD Smart Access Memory」が無効になることがある
Radeon RX 9000シリーズGPUで，「Phantom Blade Zero」をプレイ中に，空や髪の描画に異常が発生することがある。この問題が発生したユーザーは，ゲーム中の設定で「High-Quality Hair」（高品質ヘア）の設定を無効にすることを推奨するとのこと
Radeon RX 9000シリーズGPUで，Call of Duty: Modern Warfare Remasteredをプレイ中に画面が黒くなることがある

Highlights
Fixed Issues
Excessive writes to the system drive may be observed while the system is idle on Radeon™ RX 7000 series graphics products and above.
Excessive writes to the system drive may be observed while moving or resizing application windows.
Known Issues
Intermittent application crash or driver timeout may be observed while playing Assassin's Creed Black Flag Resynced on Radeon™ RX 7000 series graphics products.
Intermittent driver timeout may be observed while playing War Thunder on Radeon™ RX 5000 series graphics products. Users experiencing this issue are recommended to use AMD Software: Adrenalin Edition 26.9.1.
Intermittent application crash or driver timeout may be observed while playing Cyberpunk 2077 with AMD FSR Upscaling, AMD Radeon™ Anti-Lag and in-game frame generation enabled during video playback on a secondary display on some Radeon™ RX 9000 series graphics products. Users experiencing this issue are recommended to disable in-game frame generation.
Call of Duty®: Modern Warfare® Remastered may become unresponsive while using Alt+Tab during gameplay on Ryzen™ AI Max PRO 400 Series processors.
Black screen may be observed when launching Gears of War: Reloaded on AMD Ryzen™ AI 9 400 Series processors. Users experiencing this issue are recommended to switch the in-game display mode to Windowed and then back to Fullscreen.
Failure to install may be observed while installing AI Bundle components in some regions with limited access to HuggingFace and GitHub.
AMD Smart Access Memory may become disabled after driver installation on Windows® 10 systems.
Visual corruption may appear on character hair while playing Phantom Blade Zero on Radeon™ RX 9000 series graphics products. Users experiencing this issue are recommended to disable the High-Quality Hair setting in the game.
Black corruption may be observed while playing Call of Duty®: Modern Warfare® Remastered on Radeon™ RX 9000 series graphics products.

If you experience issues using the AMD Software: Adrenalin Edition driver package downloaded from AMD.com, please install the OEM-provided drivers for full support and compatibility.
AMD Software: Adrenalin Edition does not include support for handheld gaming devices.  Users should check with the OEM for device specific drivers.
