Earlier this year, we launched 
interactive connectors
 (opens in new tab)
 to bring a small live view of tools into Claude. Starting today, where a connector supports it, you can open a tool beside your conversation or expand it to full screen, and ask Claude to work alongside you and make changes directly.
This is rolling out on the web and in the Claude desktop app on all plans, as part of the 
new Claude experience
 (opens in new tab)
 that brings chat and Cowork together. You’ll see these features once your account is updated with the new Claude or your organization turns it on.
What’s new:
Claude can work in your open tools.
 You can ask Claude to make changes to a page, row, or file that you have open and approve its actions the same way you approve a connector’s actions. Changes appear in the tool as Claude makes them, so you can keep working right alongside it.
The whole tool
opens next to your conversation.
 You can work in the tool and hide the chat or go full screen when you need room. For tools like Confluence or Notion, that means you get the full editor, signed into your own account, rather than a limited preview.
Open a connected tool directly, without having to write a Claude prompt. 
When you want Claude’s help, you can ask from the same screen.
Pin the tools you use most.
 You can arrange them alongside your 
artifacts
 and access them with one click in your sidebar and the + menu.
Work with Claude in the tools you use
We’re starting with a small group of tools from our directory, including Asana, Canva, Carta, Dropbox, monday.com, Smartsheet, Vercel, and Webflow.
Here’s what you can do with some of the tools available in Claude today:
Adobe.
 Ask Claude to retouch, edit and add effects to photos; highlight, edit and redact PDFs.
Atlassian.
 Open a Confluence page beside your chat, ask Claude to write and edit, and review its changes live on the page.
Box.
 Open a Box file beside your chat, ask Claude to revise it, and compare the versions side by side before you keep the changes.
HubSpot. 
Prioritize pipeline tasks and follow-ups, then act on them in Claude.
Notion.
 Ask Claude to create a Notion doc or database. Build as you chat, or edit it yourself, without leaving Claude.
Figma, Harvey, and Shopify are also building integrations, and we encourage other developers to do the same.
For developers: built on MCP Apps
Interactive connectors run on MCP Apps, the open extension to the 
Model Context Protocol
 (opens in new tab)
 that lets an MCP server bring its own interface into AI applications. An MCP App you build isn’t limited to Claude and can run in any AI application that supports the 
extension
 (opens in new tab)
.
Until now, MCP Apps in Claude have mainly appeared as interactive views in the conversation. Claude now supports more of the extension, such as app tools, along with embedded sites, so a developer’s full app can run inside Claude.
Support for these capabilities is in public preview for developers. Developers can start building with them today. Read our 
docs
 (opens in new tab)
 to start building.
Getting started
You can connect the tools we mention above from the 
directory
 (opens in new tab)
, then open any tool from your chat or pin it to your sidebar.
For admins:
 If your organization already allows all of a connector’s tools, its new features appear as they roll out. Admins can restrict a connector’s tools the same way they do today.

Anthropic reveals a host of updates for Claude to help users at work
Claude can now join meetings, analyze data and more
It can also effectively connect to third-party tools such as Adobe, Box and more
Anthropic has unveiled a host of updates for Claude which could see the AI platform play a much more integral role in some of your most common work tasks.
Among the next expansions are tools which allow Claude to join video calls as a participant, meaning it learns first-hand from your meetings and can start work immediately.
Joining its existing suite of office software tools are new Whiteboards, Sheets and Data services looking to help users work and create more effectively - and new interactive connectors will now allow Claude to work inside the full versions of common workplace apps such as 
Adobe
, Atlassian and HubSpot.

What's new with Claude for enterprise?
(Image credit: Anthropic)
"A year ago, Claude changed how developers work," Anthropic wrote in a blog post announcing the new tools. "Engineers stopped asking AI for snippets and started handing it whole tasks, which freed them to spend their time deciding what to build. For most other teams, work has stayed much the same: the email gets written a little faster, the meeting comes with a summary."
"Now the frontier is moving to knowledge work, and people are starting to hand Claude whole tasks too."
The most striking new addition is undoubtedly Claude Meetings, which will allow Claude to join video calls as a visible participant.
Claude follows the conversation and starts on the work as people talk, taking notes, drafting plans, outlining timelines on whiteboards, answering chat questions, and utilizing connected work apps while conversations happen - and when the call ends, the notes, action items and everything Claude made are waiting in claude.ai.

Also new is Claude Whiteboards, a shared, real-time board which helps teams turn brainstorms and retrospectives into structured plans, timelines, and action items, and integrates directly into Claude Meetings, and Claude Sheets, a spreadsheet tool which allows teams to build and edit trackers and budgets collaboratively with Claude, complete with tabs, formulas, and dropdown menus.
Finally, Claude Data (formerly known as Claude Dashboards) connects company data sources (such as CRMs and warehouses) to generate dashboards, data stories, and narrated videos, featuring beta capabilities like certified queries and live sharing.
(Image credit: Anthropic)
Alongside this, new Interactive Connectors will allow full versions of partner tools (like Adobe, Atlassian, HubSpot, 
Salesforce
, NetSuite, and Workday) to open directly inside Claude, which can take actions directly within these apps with user approval.
Connectors respect existing user permissions, and admins can utilize features like Claude auto-connect, usage controls, and Smart Reports to monitor team productivity and costs.
Claude Meetings, Claude Whiteboard and Claude Sheets are all still in beta, with Claude Data and Interactive Connectors generally available now.

Details
Open a connected tool beside the conversation or expand it to full screen, then ask Claude to change a page, row, or file and watch the edit appear. Claude's actions use the same approval flow as other connector actions.
Tools like Confluence and Notion open the full editor signed in to your own account, not a limited preview. Frequently used tools can be pinned to the sidebar.
Launch tools include Asana, Canva, Carta, Dropbox, monday.com, Smartsheet, Vercel, Webflow, Adobe, Atlassian, Box, HubSpot, and Notion.
For developers, Claude now supports more of the MCP Apps extension, including app tools and embedded sites, so a full app can run inside Claude. This part is in public preview, and apps built this way also run in other AI apps that support the extension.
Rolling out on web and the desktop app on all plans. Admins can restrict a connector's tools the same way they do today.
Best for
Working inside a connected app while Claude changes pages, rows, or files in it directly.
When to use it
You would otherwise copy results back and forth between Claude and a tool like Notion, Confluence, or Smartsheet.
Who benefits
Teams that live in those tools, and developers who want to ship an app that runs inside Claude.
