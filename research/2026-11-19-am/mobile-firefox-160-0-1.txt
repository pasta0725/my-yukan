Track the latest Firefox desktop versions, release dates and what changed, checked against Mozilla's official release notes.
This tracker lists the latest Firefox desktop releases, with their version numbers, release dates and what each one changed. Every entry is checked against Mozilla’s official 
release notes
, and the page is updated when Mozilla ships a new version.
TL;DR:
 Firefox 160.0.1 is the latest release, first offered on November 17, 2026.
Last updated: November 17, 2026.
How Firefox versions work
Firefox now ships a new major version about every two weeks. The five releases below came on September 1, September 15, September 29, October 13 and October 27. A small fix uses a third number, such as 155.0.1.
Firefox updates itself. To check, open the menu, choose Help, then About Firefox.
Firefox 160.0.1 (November 17, 2026)
Version number: 160.0.1.
Released: November 17, 2026.
Fix: Fixed thin lines in PDFs printing as thick black boxes on some printers on Windows. ( Bug 2091728 )
Fix: Fixed PDFs, web page graphics, and WebGL content appearing blank or broken on Macs with AMD graphics, such as black cells in Google Sheets. ( Bug 2091596 )
Fix: Fixed incorrect colors in WebGL and canvas content, such as games and Google Meet backgrounds, on some Linux systems using Wayland. ( Bug 2089043 )
Fix: Fixed links on some sites, such as the Google Store, taking a very long time to load. ( Bug 2087787 )
Fix: Fixed tabs crashing on some sites, most notably ChatGPT. ( Bug 2088486 )
Fix: Fixed WebTransport connections being unable to send datagrams after a site sent many in quick succession. ( Bug 2092532 )
What it means for you: Firefox updates itself. Open Help, then About Firefox to apply it.
Source: 
Firefox 160.0.1 release notes
.
Firefox 160.0 (November 10, 2026)
Version number: 160.0.
Released: November 10, 2026.
New: The Picture-in-Picture player now has a playback speed setting, with options ranging from 0.25x to 2.0x speed. The setting appears only when the player window is medium-sized or larger.
New: Mini Window moves a tab or a selected part of a page into an always-on-top window while browsing. We’d appreciate feedback on Mozilla Connect as we develop and improve this early version of the feature.
New: History entries can now be dragged from the sidebar to the tab strip to open them in new tabs.
New: The address bar context menu now shows “Paste and Search” instead of “Paste and Go” when the copied text is a search term rather than a web address.
New: Pages saved as PDF now make mathematical content (MathML) accessible to assistive technology such as screen readers.
New: Websites that repeatedly ask to handle email (mailto:) and other links can now be blocked with a new “Never allow” button, and blocked sites can be managed in Settings.
What it means for you: Firefox updates itself. Open Help, then About Firefox to apply it.
Source: 
Firefox 160.0 release notes
.
Firefox 159.0.1 (November 3, 2026)
Version number: 159.0.1.
Released: November 3, 2026.
Fix: Fixed the dot that marks a tab needing attention being hard to see with some themes, depending on the system accent color. ( Bug 2086347 )
Fix: Fixed a command prompt window briefly appearing on Windows when Firefox restarts to apply an update. ( Bug 2081809 )
Fix: Fixed passkey sign-in failing on websites that share passkeys across related sites, such as Facebook and Instagram. ( Bug 2085450 )
Fix: Fixed crashes on Windows that could occur with some antivirus or other security software installed, in some cases also leaving WebGL disabled. ( Bug 2083648 )
Fix: Fixed red and blue colors appearing swapped on some websites that use WebGL on Linux, including video call background effects. ( Bug 2087301 )
New: Updated time zone data to reflect Cuba’s decision not to end daylight saving time on November 1, 2026. ( Bug 2086609 )
What it means for you: Firefox updates itself. Open Help, then About Firefox to apply it.
Source: 
Firefox 159.0.1 release notes
.
Firefox 159.0 (October 27, 2026)
Version number: 159.0.
Released: October 27, 2026.
New: on macOS, sharing uses the native share picker, and you can share several tabs at once.
New: saved passwords are in the sidebar by default.
New: Smart Window can watch pages for changes like price drops or restocks and send a desktop notification. It is a progressive rollout, so not everyone sees it yet.
Fix: the file upload dialog opens in the folder you last used for uploads.
Fix: memory use no longer grows fast on sites like the Zoom web app left open in a minimized window.
Fix: bookmarks import from signed-in Chrome profiles.
Security: Mozilla lists various security fixes.
Source: 
Firefox 159.0 release notes
.
Firefox 158.0 (October 13, 2026)
Version number: 158.0.
Released: October 13, 2026.
New: JPEG XL image support.
New: a library of custom New Tab wallpapers.
New: translation for Albanian, Belarusian and Filipino.
New: Smart Window can suggest form-fill data from your open tabs and saved autofill entries, as a progressive rollout.
Change: scroll positions are no longer rounded to whole screen pixels, which Mozilla says makes scrolling smoother.
Known issue: web apps launched with PWAsForFirefox may fail to start until PWAsForFirefox is updated to 2.20.1 or later.
Security: Mozilla lists security fixes.
Source: 
Firefox 158.0 release notes
.
Firefox 157.0 (September 29, 2026)
Version number: 157.0.
Released: September 29, 2026.
New: a visual refresh across toolbars, sidebar and menus, with new light and dark themes and a compact mode.
New: WebRTC video calls can use hardware AV1 decoding on supported devices.
New: Firefox warns you if it has been set up to record encryption keys.
Change: the updated sidebar is the default for everyone. The old one can be restored with the sidebar.revamp setting until the end of 2027.
Change: Amazon was removed as a built-in search engine, but you can add it back by hand.
Security: Mozilla lists various security fixes.
Source: 
Firefox 157.0 release notes
.
Firefox 156.0 (September 15, 2026)
Version number: 156.0.
Released: September 15, 2026.
New: on macOS, Firefox can launch at login from the Startup section of Settings.
Change: the built-in PDF viewer starts up to 45% faster, per Mozilla.
Change: Windows ARM64 devices may use hardware H.264 decoding for WebRTC video calls.
Fix: several issues, including image dragging in rich-text editors and some sites failing to load with DNS over HTTPS.
Security: Mozilla lists security patches.
Source: 
Firefox 156.0 release notes
.
Firefox 155.0 (September 1, 2026)
Version number: 155.0.
Released: September 1, 2026.
New: Smart Window is available to all users in the US, Canada and France.
New: the address bar shows how many trackers Firefox has blocked. You can hide the count in settings. It is a progressive rollout.
New: Marathi and Urdu translation.
Known issues: vertical tabs may not keep the sidebar across restarts, and some sites may load slowly on networks that block UDP. Mozilla says a fix is in Firefox 155.0.1.
Source: 
Firefox 155.0 release notes
.
