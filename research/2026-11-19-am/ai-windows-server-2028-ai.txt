Windows Server 2028 won't be compatible by default

Testing times ahead for administrators: beefed-up security out of the box means some things might not 'just work'
Richard Speed                                
Wed 18 Nov 2026                                    
 // 
13:16 UTC                                
Microsoft has pushed Windows Server 2028 into public preview, with an eye on beefed-up security, new infrastructure support, and the inevitable nod to AI.
Neil Hinnant, a director on the Windows Server team, talked up the security tweaks. There's a hardened Server Core configuration by default and a new security baseline. "Trusted Launch extends protection to virtual machines," 
he wrote
. "Confidential VM support begins a journey to support integrity-protected runtimes on supported CVM hardware."
Server Core will therefore arrive locked down by default – good news for security, potentially less so for administrators whose existing configurations depend on more permissive settings. 
"For years, Windows Server shipped compatible by default," 
wrote
 Senior Product Manager Christina Curlette. "Making the server secure was up to you, usually by applying the Security Baseline or your own hardening scripts after setup."
With Windows Server 2028 (and starting from Windows Server Insider Preview build 29706), Server Core will be installed hardened. "Hundreds of security settings are on from first boot," Curlette wrote.
"Because the defaults are now locked down, some things that worked on Windows Server 2025 may not work on Windows Server 2028 without changes. This includes older protocols, legacy authentication, and some management tools and scripts."
For a company obsessed with backward compatibility, this is quite the step. Welcome though the hardening is, administrators will need to test carefully: working on Windows Server 2025 won't guarantee a smooth ride in the brave new world.
AI gets a role on both sides of the security fence: helping uncover vulnerabilities and giving Microsoft another reason to sell servers. Windows Server 2028 is being pitched for running models locally, with support for accelerators such as AMD's Instinct MI350P.
Not every server is destined to babysit a model, however, and the storage changes may be more immediately useful to enterprise administrators. Windows Server 2028 will enable native NVMe storage by default, along with NVMe over TCP and RDMA. Booting from ReFS is also planned, adding another item to the storage upgrade list.
Intune management for Windows Server has also entered preview. Azure Arc, with its cloud-native management workflows, is obviously still around, while Intune brings a more familiar management interface for administrators already using it for endpoints.
Hinnant acknowledged that this was a "major release," and it looks like the security hardening alone will require a good deal of thought from administrators before organizations adopt the eventual production release.
Esben Dochy, Principal Technical Evangelist for SecOps at Lansweeper, told 
The Register
 that Microsoft had indicated that the hardened security only applied to new installations. "If that remains in the final release," he said, "in-place upgrades could be easier. The catch is that those servers may also miss out on the new security defaults."
"Hardening is the right direction," he said, "but it will add work for teams moving to Server 2028."
According to Lansweeper’s figures, as of October 2026, Windows Server 2019 ruled the roost with 33 percent. Windows Server 2025 had reached just 7 percent.  "From behavior we've seen in the past," said Dochy, "adoption is primarily driven by lifecycle, so until the more used versions start going EOL, I don't expect much adoption, similar to what Server 2025 is experiencing."
 Windows Server 2025 remains under extended support until 2034, but Microsoft's direction of travel is clear: beefed-up security by default, a home for AI applications, and Intune management for fleets of servers. ®

News
Microsoft has announced Windows Server 2028 to public preview at Ignite 2026, positioning it as a major LTSC release that runs AI inference on customers' own servers through what it calls "token factories." The mature, testable pieces land in storage and management: native NVMe is on by default, ReFS boot is ready, and Windows Admin Center Virtualization Mode is now GA with a VMware migration path coming. The AI ambitions, though, lag months behind, since AMD's MI350P and NVIDIA's GB300 hardware don't ship until later, and no GA date for the OS itself has been announced. Until official release notes arrive, many of the security and AI features remain reported rather than confirmed.
Windows Server 2028 enters public preview, betting the datacenter on on-premises AI
Microsoft has officially opened Windows Server 2028 to public preview, confirmed at Ignite 2026 and posted by the Windows Server team's Neil Hinnant. This is a major LTSC release, not the kind of tidy incremental upgrade you can drift through. The headline bet is bigger than that: run AI inference on your own servers, next to your data, in what Microsoft is calling "token factories."
Here's the bit that matters. A "token factory" is just Microsoft's word for a datacenter server that processes AI inference locally instead of forwarding every request to the cloud. Hinnant frames it plainly. "Now customers are asking where AI should run when it needs to work with those applications and data. The cloud is part of the answer, but so is the local infrastructure they operate themselves."
The pitch is that you shouldn't have to stand up a separate AI stack at every location. Windows Server 2028 is Microsoft planting a flag there, extending Foundry straight down into the datacenter. Early access runs through the Technology Adoption Program at aka.ms/WSTAP.
A few caveats before you get excited
Let me be straight with you about the reporting. Microsoft's own blog names Trusted Launch VMs, post-quantum crypto, and a hardened Server Core baseline. But Confidential VM support, the Server Core-first default, and automatic certificate management are coming via third-party reports, not the primary announcement. Treat those as unconfirmed until release notes actually land. Same for the build number: 29706 is floating around from reporters since Microsoft doesn't cite one itself.
The storage work, though, is real and mature. Native NVMe first shipped in Windows Server 2025 as an opt-in checkbox, meaning you needed the October 2025 cumulative update, a registry override, or a Group Policy toggle to turn it on. In 2028 it's simply on by default. The performance case is decent. In Microsoft's own DiskSpd testing, 2025 with native NVMe delivered up to 80% more IOPS and roughly 45% fewer CPU cycles per I/O on 4K random reads versus 2022. Only it shows up on drives using the in-box StorNVMe.sys driver. Vendor-supplied drivers won't make the difference. Watch for that.
The management side is where some of this is actually testable today. Windows Admin Center Virtualization Mode is generally available as of 2611, announced November 16, and a single instance can cover up to 1,000 Hyper-V hosts and 25,000 VMs. There's bulk Azure Arc onboarding, encrypted backup and restore of the management database, and cert management through AD Certificate Services. Intune for Windows Server is in preview too, folding the configuration, compliance, app, and update workflows you already know onto "eligible, persistent servers." Less painful than you'd bet, honestly.
And here's the part worth leaning into. Microsoft is candid about why it built vMode, since licensing churn and renewal uncertainty have pushed a lot of teams toward alternatives. VMware ESXi-to-Hyper-V conversion is coming to vMode in private preview. That reads as a direct dig at anyone currently weighing a migration out of VMware.
The silicon problem
Now for the catch, because there's always a catch. The accelerators are months out. AMD's Instinct MI350P enters preview in the first half of 2027, and NVIDIA's GB300 Grace Blackwell Ultra is slated for general availability with up to around 748 GB of coherent memory. AI early access is gated behind both hardware requirements and a limited program.
So here's the short version: no inference without silicon, and the silicon isn't here yet. General availability for Windows Server 2028 itself also hasn't been announced. Follow Microsoft's rough 2-to-3 year LTSC release schedule and you'd guess the second half of 2027, but that's inference from history, not a stated date. The partner lineup rounds out the story, with AMD, Dell, HPE, Intel, and Lenovo all firing off quotes on security, post-quantum crypto, and hybrid AI. Intel's Srini Krishna calls the Xeon plus Windows Server 2028 combo a "strong PQC-capable foundation," and Microsoft's Quantum Safe Program targets transitioning to post-quantum cryptography by 2029. Windows code-signing is set to move to post-quantum signing in 2027, with TLS 1.3 required for PQ key establishment. If you're sketching a PQC compliance plan today, that timeline is the only anchor you've got.
Don't put the preview into production. Stand up a lab on spare UEFI hardware or a Generation 2 Hyper-V VM instead. Benchmark native NVMe against your Server 2025 baseline, and confirm your drives are on the in-box driver. Try ReFS boot on something non-critical first, since third-party backup and imaging agents sometimes assume an NTFS system drive. ReFS itself is no slacker, offering online integrity checks without chkdsk, metadata checksums, volumes up to 35 PB, and block cloning for faster VHDX creation.
If Hyper-V consolidation or a VMware exit is on the roadmap, take a real look at vMode, which is GA now. And if you want direct time with Microsoft engineers on AI workloads, the Technology Adoption Program is the door, though it's gated and hardware-dependent.
Head here
 to join the Windows Server Insider Program and test the security, storage, and management features. Keep in mind that Windows Server 2028 is a preview. The storage is solid, the management wins are real, and the AI vision is genuinely compelling. But the AI is months behind the rest, and a lot of the buzzier claims haven't been confirmed in Microsoft's own words yet. Wait for release notes before you commit anything to a procurement plan.

Windows Server 2028: A trusted foundation for an evolving enterprise
Neil_Hinnant
Microsoft
Nov 17, 2026
Windows Server 2028 is now in Public Preview!
Enterprise infrastructure has evolved in response to changing and increasing business demands. Windows Server helped connect the enterprise by bringing people and resources together with Active Directory. As more business processes moved into software, it became a place to run business-critical applications. And when those applications multiplied, Hyper-V helped customers host the infrastructure they depend on more flexibly. Windows Server has evolved and grown with customers through each shift.
Now customers are asking where AI should run when it needs to work with those applications and data. The cloud is part of the answer, but so is the local infrastructure they operate themselves. With Windows Server 2028, we’re strengthening the platform across the work it already does—and beginning to enable enterprise hybrid intelligence.
Today, we’re introducing Windows Server 2028, in public preview now. This major release raises the security and access bar, accelerates enterprise infrastructure, and simplifies management at scale. It also begins our long term investments extending Microsoft Foundry to bring AI inference to fleets of local token factories, giving customers more choices to put the right intelligence in the right place with the right cost structure. For customers interested in early access to Windows Server 2028 features and direct engagement with Windows Server engineering, consider applying to Windows Server Technology Adoption Program (TAP) at 
aka.ms/WSTAP
Enable enterprise hybrid intelligence
AI raises an infrastructure question: where should inference run? A cloud service may be the right choice for one application. Another may need inference close to its data, near a physical operation, or within an environment the customer controls. Customers need to make that choice without building and operating a separate AI stack for every location, and want to scale their local inference servers on the same trusted platform delivering storage, compute, networking, and databases across their enterprise today.
With Windows Server 2028, we’re investing across the stack needed to run inference on enterprise infrastructure. At the hardware layer, we’re introducing powerful new AI accelerators with Windows Server 2028. We’re excited to share that 
AMD’s Instinct MI350P card is in preview
 starting H1 2027 for in-market supported Windows Servers and Windows Server 2028. At the platform layer, we’re developing capabilities to deploy and configure inference environments, manage accelerated hardware, and direct model requests to the right environment. At the runtime layer, we’re working to support open-weight and custom models across technologies including Foundry Local, Windows ML, vLLM, and Llama.cpp.
Running inference in an enterprise also means protecting and governing it. Windows Servers benefit from broad Windows investment in agent security and management, including 
Microsoft eXecution Containers
 for isolation, integration with Microsoft Foundry for model catalogs, and 
Agent 365
 for agent identity and governance. Together, these capabilities are intended to help customers run AI close to their applications and data while connecting that work to a broader hybrid AI architecture.
Raising the security and access bar
The more an organization relies on its servers, the more important it is to keep them secure. Administrators need to protect the operating system and the virtual machines it hosts, maintain the certificates that secure connections, and prepare for threats that will change over the life of the infrastructure. Doing that well should not depend on every team starting from scratch.
Windows Server 2028 is designed to give customers a stronger starting point. A hardened Server Core configuration by default and a new security baseline help reduce the work of establishing a secure baseline from day 1. Trusted Launch extends protection to virtual machines, guaranteeing boot integrity across your VM fleet, and Confidential VM support begins a journey to support integrity-protected runtimes on supported CVM hardware. We’re also investing in automatic certificate management and post-quantum cryptography, addressing both the day-to-day task of maintaining secure connections and the longer-term need to modernize them against the threats of tomorrow.
Accelerate enterprise infrastructure
Applications and data keep placing new demands on the systems beneath them. Customers are adopting faster storage and moving larger volumes of data, but the value of that hardware depends on whether the rest of the infrastructure can keep up. For organizations running critical workloads on Windows Server, performance improvements need to reach the applications they already operate.
Windows Server 2028 adds native NVMe storage enabled by default and NVMe over TCP and RDMA transports, along with the ability to boot from ReFS. These technology ingredients combine to deliver high-performance, scalable, resilient storage solutions for Windows Server customers and  help customers make better use of modern hardware to give demanding workloads more room to grow.
Simplify administration and management at scale
Managing a server and managing a server estate are different jobs. Across datacenters, clouds, and remote sites, teams need ways to apply policy, manage updates, and see what is running across the estate across an extraordinary diversity of Windows workloads. We hear regularly from customers who want to use proven Windows management processes and manage Clients and Servers as one fleet. We are proud to build on our recognition as a 
leader in Server Virtualization
 to help customers manage Windows Servers at scale. 
For teams that already manage Windows clients with Microsoft Intune, we are excited to announce Intune management for Windows Servers is now in Preview. Intune support for Windows Server brings familiar endpoint-management workflows including configuration, compliance, applications, and updates to eligible, persistent servers. Azure and Azure Arc continue to provide cloud-native management workflows for production and business-critical servers wherever they run.
When a workload needs attention or a virtualization host needs troubleshooting, administrators need to get close to the machine and understand what is happening. Enterprise customers around the world run Windows Server VM fleets at scale, and need modern management tools to keep up. Windows Admin Center Virtualization Mode gives administrators the depth to work with individual servers and virtualized infrastructure as one fabric, and we are pleased to announce that WAC vMode is now in GA.
These Cloud and On-Premises approaches complement one another. Customers can start with the workflows that fit their environment today, and grow into tomorrow with a consistent toolset that meets them where they are with the best of Azure and Windows management all together.
Bringing Windows Server 2028 to enterprise infrastructure
Bringing this vision to life takes an ecosystem spanning software, silicon, and systems integrators. We’re working closely with hardware partners to bring accelerated computing to the enterprise infrastructure customers already rely on. The strength of Windows and the strength of our ecosystem go hand in hand, and we thank our fantastic partners for their work scaling with us to support the needs of today’s enterprises.

Going forward
Windows Server 2028 is part of a bigger picture: intelligence across the cloud, enterprise infrastructure, and personal devices. As AI-accelerated workloads diffuse across the enterprise, different workloads have different needs. Some call for the breadth and scale of the cloud. Others need to run close to business-critical applications and data, on infrastructure customers control. Still others belong on the devices people use every day. Cost, latency, IP protection, data residency, and regulatory requirements all shape that decision. Our vision is to extend Microsoft Foundry across these environments, so teams can build with familiar tools and run each workload where it makes the most sense, from client, to cloud, to powerful Windows Server token factories running in corporate datacenters. As we move toward general availability, we’ll keep working with customers to learn where running inference on their own infrastructure makes the greatest difference—and to shape how Windows Server fits into a broader hybrid AI architecture. We’re excited about what Windows Server 2028 makes possible, and we look forward to sharing more as these capabilities develop.
