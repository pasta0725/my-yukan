NDLOCR-Lite ver.2を無料公開　表と手書きに対応した
国立国会図書館は11月24日、
NDLラボ
を通じてOCRソフト「NDLOCR-Lite ver.2」を公開しました。無料で使え、ライセンスはCC BY 4.0です。GPUは要らず、ふつうのノートPCで動きます。
図書や雑誌をスキャンした画像から、文字をテキストに起こすソフトです。動作を確かめたOSはWindows 11とmacOS SequoiaとUbuntu 22.04の3つです。アプリはGitHubのリリースページから落とせます。
NDLのお知らせで挙がった主な変更点は次のとおりです。下の3つは画面の「出力設定」から選びます。
英文と手書きの文字に正式に対応した
旧字体などの異体字を新字体に直して出せる
表の中の文字をHTMLの表に組み直せる
視覚障害などがある人向けのテキストデイジー形式で出せる
くずし字や漢籍も読める場合はあります。ただ本格的にテキスト化するなら、NDL古典籍OCRかNDL古典籍OCR-Liteを使うよう勧めています。

分析・考察
NDLOCR-Liteの強みは、紙の資料を手元のPCだけで文字にできる点です。顧客の申込書や古い契約書のように、クラウドのAIへ渡しにくい書類を抱える部署には合いそうです。
気をつけたいのは、情報システム部門が社内へ配るときの手順書です。Macは標準のままだと表の構造化で止まるので、Windowsと同じ手順書では足りない可能性があります。配る前に表のある書類で1回試しておきたいところです。
よくある質問
NDLOCR-Lite ver.2は無料で使える？
無料で使えます。国立国会図書館はNDLOCR-LiteをCC BY 4.0のライセンスで公開しています。ただし同梱の学習済みモデルを使うときは、DINOv3のライセンスも守るよう求めています。仕事で使う前に、GitHubのREADMEとLICENCEで条件を確かめると確実です。
MacでNDLOCR-Lite ver.2の表の構造化が使えないときは？
onnxruntimeの版を確かめてください。編集部のMacにpipで入れると1.23.2が入り、表のモデルが読み込めずに止まりました。エラー文は1.25以上を使うよう求めています。編集部では1.32.0に入れ替えると、15マスの表がHTMLで出ました。配布元が決めた組み合わせからは外れる点に気をつけてください。
GPUのないノートPCでもNDLOCR-Lite ver.2は動く？
動きます。NDLラボはGPUが要らないと説明しています。編集部のApple M6のMacでは、CPUだけで1枚0.398〜0.506秒でした。pip版は初回だけモデル4本を取りに行くので60.06秒かかります。起動にはPCのメモリに1GB以上の空きが目安です。
NDLOCR-Lite ver.2でくずし字や古文書も読める？
読める場合はありますが、本格的なテキスト化には向きません。NDLラボは、くずし字や漢籍の資料にはNDL古典籍OCRかNDL古典籍OCR-Liteを勧めています。旧字体はver.2で新字体に直して出せるようになりました。編集部の試験では旧字体16字がすべて新字体になりました。

この記事には Amazon アソシエイトのリンクを含みます。
古いノートや手書きのメモをスマートフォンで撮影しても、手書きの部分だけ文字起こしが進まず、そのまま放置している資料がある。国立国会図書館が無料で公開しているOCRツール「NDLOCR-Lite」が2026年11月24日にバージョン2.0になり、この手書き文字を読み取れるようになった。GPU(画像処理用の高性能な部品)も要らず、普段使っているノートパソコンだけで動く。
視覚障害のある人向けの電子書籍形式や、表をそのままHTMLに変換する機能も加わった。具体的に何が変わり、どの程度の精度で読み取れるのか、順に確かめる。
手書き文字も正式対応に
NDLOCR-Liteはこれまで何が苦手だったのか。NDLラボの公式発表は、従来の版が英文や手書き文字を不得意としていたと説明している(
NDLラボ公式発表
、2026-11-25確認)。v2.0でこの2つに正式対応したと伝えている(同上)。GitHubのv2.0.0リリースノートも、認識性能の改善として手書き文字の認識精度向上を挙げている(
GitHub v2.0.0リリースノート
、2026-11-25確認)。
NDLOCR-Liteは国立国会図書館のラボが開発した、CC BY 4.0ライセンスの無償ツールだ(
GitHub README
、2026-11-25確認)。図書館の資料デジタル化のために作られたものだが、誰でも自分のPCに入れて使える。研究者が旧字体の交じった古い論文をまとめてテキスト化する作業にも、個人が手元の手書きノートを整理する作業にも使える範囲が広がる。
では、新しくできるようになったことは何か。
新機能で何ができるか
手書き文字が読めるようになった以外に、何が新しくなったのか。公式発表とリリースノートは、次の3つを新機能として挙げている。
テキストデイジー出力
: 視覚障害や読みに困難のある人向けの、読み上げソフトや点字ディスプレイで使えるアクセシブルな電子書籍規格「デイジー」のテキスト版で出力できる
異体字包摂
: 旧字体などの異体字を、読みやすい新字体に変換して出力できる
表の構造化
: 紙面の表に書かれた文字を、行と列の構造を保ったままHTML形式に変換できる。2023年度に研究開発した表構造認識のデータセットとモデルを、最新の技術で発展させて組み込んだという
(いずれも
NDLラボ公式発表
、
GitHub v2.0.0リリースノート
、2026-11-25確認)
このうち表の構造化は、スキャン画像にある表の罫線や文字の並びから行と列の区切りを推定し、文字を1つずつ正しいマス目に収める作業にあたる。結果をHTML形式で受け取れれば、ブラウザでそのまま表として表示したり、表計算ソフトへ貼り付けたりしやすくなる。これらの設定は、デスクトップアプリの「出力設定」画面から選ぶ(
NDLラボ公式発表
、2026-11-25確認)。
これだけの機能を動かすには、どんな環境が要るのか。
無料でGPUなしに動く
GPUを積んだ高性能なPCでなければ動かないのか。NDLOCR(GPU版)はGPUを前提にするのに対し、NDLOCR-Liteは名前のとおりその前提を外した軽量版として作られている。動作確認済みの環境はWindows 11・macOS Sequoia・Ubuntu 22.04で、いずれも一般的なノートPCで使われるものだ(
GitHub README
、2026-11-25確認)。
導入は2通りある。コマンドラインで使う場合はPython 3.11以上を用意し、
pip install ndlocr-lite
または
uv tool install ndlocr-lite
を実行する。マウス操作だけで使いたい場合は、GitHubのReleasesページからOSに合ったデスクトップアプリをダウンロードする(いずれも
GitHub README
、2026-11-25確認)。コマンドラインでは
--sourceimg
で画像を1枚指定し、
--output
で保存先を指定すればその1枚を処理できる。フォルダごとまとめて処理したい場合は
--sourcedir
を使う(同上)。
コマンドライン版は初回のOCR実行時に、約157MBの認識モデルをNDLのサイトから取得し、SHA-256で検証してキャッシュする。表の構造化を使う場合は、約28MBの表構造推定モデルも追加で取得される(
GitHub README
、2026-11-25確認)。デスクトップアプリはこれらのモデルを同梱しているため、この取得作業は要らない。対応GPUと
onnxruntime-gpu
がある環境では
--device cuda
で処理を速くできるが、これは案内の時点でベータ機能にあたる(同上)。

手書き文字の文字誤り率(CER、読み違えた文字の割合)は、GitHubのREADMEが評価結果として公開している(
GitHub README
、2026-11-25確認)。中央値は13.27%、横書きは11.56%、縦書きは17.76%で、縦書きのほうが誤りやすい(同上)。
自分はこの数値を見るまで、無料のGPU不要ツールが手書きを読むといっても実用にはほど遠いだろう、と予想していた。だが100字のうち10〜18字程度という具体的な割合が示されたことで、どの程度の下書きとして使えそうかの見当がついた。全部を自動で仕上げるところまでは届かず、読み取ったあとに人の目で誤りを直す作業は引き続き要る水準だ。縦書きで誤りが増える理由はREADMEに明示されていない。自分の見立てでは、続け字が多い縦書きの手書きは文字の境目が曖昧になりやすく、読み取る順番も崩れやすいことが影響していそうだ。
では、この精度でも対応しきれない資料はあるのか。
向かない資料もある
どんな資料には、今回のアップデートでも手が届かないのか。今回対応したのは現代的な筆跡の手書き文字と英文までで、くずし字(歴史的な手書きの崩し字)や漢籍はこの範囲に含まれない。NDLラボの公式発表は、くずし字や漢籍を本格的にテキスト化する場合、より読み取り精度の高い「NDL古典籍OCR」「NDL古典籍OCR-Lite」の利用を推奨すると明記している(
NDLラボ公式発表
、2026-11-25確認)。古い和装本や漢籍をあつかう場合は、専用ツールへ切り替える判断が要る。
実際に試す際の注意点も1つある。デスクトップアプリは、全角文字(日本語)を含むフォルダ名に置くと起動しないことがあると公式READMEにある(
GitHub README
、2026-11-25確認)。展開先のフォルダ名は半角英数字にしておいたほうがよい。
まとめ
NDLOCR-Lite v2.0は、GPUなしの一般的なノートPCで、手書き文字と英文を文字誤り率10〜18%程度で読み取れるOCRツールになった。読み取った結果は、視覚障害者向けのテキストデイジー形式や、行と列を保ったままの表HTMLとしても出力できる。導入は
pip install ndlocr-lite
かデスクトップアプリのダウンロードで数分で終わる。現代的な筆跡の手書きノートや旧字体混じりの古い論文なら、くずし字専用ツールを使わずこの1本でテキスト化できる。

NDLOCR-Lite ver.2の公開について
NDLラボ公式GitHub
（外部サイト）から、NDLOCR-Lite ver.2を公開しました。
NDLOCR-Liteは、NDLOCRの軽量版を目指して開発したOCRであり、ノートパソコン等の一般的な家庭用コンピュータやOS環境で、図書や雑誌といった資料のデジタル化画像からテキストデータが作成できるOCRです。
GPU（Graphics Processing Unit。画像描画等の高度な並列計算を処理する装置。）を必要とせず、軽量なOCR処理が可能です。
今回公開するver.2では、認識性能を改善し、視覚障害者等向けテキストデータを作成するための機能を新たに追加したほか、一般ユーザ向けの機能も改善しています。
また、NDLOCRが不得意としていた英文や手書き文字等についても、ver.2から正式に対応しています。
新機能（１）テキストデイジー出力機能
視覚障害や読みの困難がある方向けのアクセシブルな電子書籍規格であるテキストデイジー形式での出力に対応しました。
新機能（２）異体字包摂機能
旧字体等の異体字を新字体に変換して出力することができます。

新機能（３）表の構造化機能
資料中の表内から読み取ったテキストデータについて、html形式に構造化することができます。
2023年度に研究開発した表構造認識用データセット及び表構造認識モデルを、最新の技術をもとにさらに発展させて組み込んでいます。

NDLOCR-Lite ver.2について
GitHubリポジトリ（
https://github.com/ndl-lab/ndlocr-lite
）
これまで公開してきたNDLOCR-Liteと同様に動作にGPUは不要です。
あわせて、デスクトップアプリケーションを用意しているため、マウス操作のみで簡単にお使いいただけます。
Windows（Windows 11）、Mac（macOS Sequoia）及びLinux（Ubuntu 22.04）の各OS環境において動作を確認しています。
次のURLからご利用のOSに合わせた最新版をダウンロードしてお使いください。
https://github.com/ndl-lab/ndlocr-lite/releases
使い方については次のページをご覧ください。
NDLOCR-Liteの使い方
NDLOCR-Liteは、国立国会図書館がCC BY 4.0ライセンスで公開しています。詳細はGitHubのREADMEをご参照ください。
なお、これまで提供していたGPUを必要とするNDLOCRについても、引き続き同リポジトリ（
https://github.com/ndl-lab/ndlocr_cli
 ）からご利用いただけます。
（留意点）
くずし字や漢籍の資料も読み取れる場合がありますが、これらの資料に対して本格的なテキスト化を行う場合は、より読み取り精度の高いNDL古典籍OCRやNDL古典籍OCR-Liteをご利用いただくことを推奨します。
