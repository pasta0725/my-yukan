Microsoft released the November preview updates for Windows 11 versions 26H2, 26H1, and 25H2 today. This is happening a week earlier than usual, probably because of the Thanksgiving holiday break. There will also be no December 2026 preview updates in the second part of the month, as the Windows team will be on minimal operations during the holidays.
The 
optional KB5132057 update
 for Windows 11 versions 26H2 and 25H2 was made 
available for Insiders on the Release Preview Channel
 last week. It includes the following new features, which will be rolling out gradually to users who install the update:
New Windows Search experience with inline actions
: It’s now possible to complete common tasks such as changing Windows settings right from the Windows Search window. The new experience also displays richer results with file previews.
File Explorer improvements
: Searching from ‘This PC’ is now indexer-based, and the experience now matches the speed of searching from File Explorer Home.
Windows Hello improvements
: A new option in Facial recognition settings can temporarily brighten the screen to help users in dark environments to sign in.
Xbox mode improvements
: Quick settings are now available from the Gaming Task View navigation bar.
Live captions improvements
: New options in Live captions settings let users choose to caption system audio, microphone audio, or both.
Screen capture
: This update changes the border displayed during screen capture from yellow to a more visible red color.
Pointer indicator
: This new accessibility feature makes it easier for people with low vision to locate and use the mouse pointer.
Widget notifications
: Windows 11 will now show a notification when a new widget becomes available after installing an app.
For ARM-based PCs running Windows 11 version 26H1, the 
optional KB5132265 update
 is available today. It includes the updated context menu in File Explorer, the Cloud Rebuild recovery option, and other new features from the 
November Patch Tuesday update for Windows 11 versions 26H2 and 25H2
.

November 19, 2026 — KB5132057 (OS Builds 26300.10075 and 26200.10075) Preview
Applies To
Windows 11 version 26H2, all editions
Windows 11 version 25H2, all editions
This cumulative update for Windows 11, versions 26H2 and 25H2 (KB5132057), includes production-quality improvements. 
Announcements and messages
This section provides key notifications related to this release, including announcements, change logs, and end-of-support notices.
Important
There will be no December 2026 non-security preview update in the second part of the month due to minimal operations during the Western holidays and the upcoming new year. Normal monthly servicing for both security and non-security preview updates will resume in January 2026.
Windows Secure Boot certificate expiration
Important:
 Secure Boot certificates used by most Windows devices started to expire in June 2026. Microsoft has been updating these certificates on consumer and non-managed business devices over the past several months. Devices that haven’t received the newer certificates will continue to start and operate normally, and standard Windows updates will continue to install. Updated certificates will continue to be delivered through Windows Update in the coming months. For more information, see 
Windows Secure Boot certificate expiration and CA updates
.
Highlights
This update is available through two release phases: gradual rollout and normal rollout. A 
gradual rollout
 delivers an update in phases, so features reach devices over time instead of all at once, meaning availability varies by device. A 
normal rollout
 is the broad release to all eligible devices at the same time, usually when it reaches general availability (GA). 
Note
 If you installed earlier updates, your device downloads and installs only the new updates contained in this package.
Gradual rollout
The following summary outlines new Windows 11 PC experiences, along with improvements and fixes. The bold text within the brackets indicates the item or area of the change.
[Windows Search]
New!
 This update introduces a new Windows Search experience with a streamlined design, improved performance, and new ways to complete tasks directly from search.
Streamlined design:
 Windows Search now displays results in a single, simplified list, making it easier to scan and find what you need. The updated experience also improves performance and memory efficiency.
Inline actions:
 You can now complete common tasks directly from Windows Search without opening Settings. For example, you can turn on dark mode or Bluetooth, adjust screen brightness, mute your device, or arrange open windows. If you have an Android phone connected through Phone Link, you can also call or text contacts and use phone actions like “Find my phone” and “Do Not Disturb.”
Richer, more relevant results:
 Preview files directly in Windows Search and see details like when a file was last modified, where it's saved, and who created it. You can also get quick answers about weather, stocks, and facts without leaving search. Windows Search also better recognizes typos and synonyms, so you'll find what you need even when your search terms aren't an exact match.
The new Windows Search experience is initially available in English. For more information, see 
From searching to doing: Building a faster, more streamlined Windows Search
.
[Windows Hello]
New!
 Windows Hello facial recognition can now temporarily brighten your screen to help you sign in when you're in a dark or dimly lit room. To turn on this feature, go to 
Settings > Accounts > Sign-in options > Facial recognition (Windows Hello)
 and turn on 
Automatically adjust screen brightness during face recognition
.
[Run dialog]
New!
 The Run dialog has been updated with a more modern design and improved usability. You can try the new experience by going to 
Settings > System > Advanced
 and turning on 
New Run dialog
. For more information, see 
The new Run dialog: faster, cleaner, and more capable
.
[XBOX Mode]
This update brings 
Quick settings
 to the 
Gaming Task View
 navigation bar in XBOX mode, giving you access to the full set of Quick settings available on the Windows taskbar without having to leave XBOX mode.
[Widgets]
New!
 Windows can now notify you when a new widget becomes available after you install an app. Select the notification to open the Widgets Board, where the new widget is highlighted so you can quickly add it to your board.
[File Explorer]
New!
 Search from This PC in File Explorer is now indexer-based, making it much faster and consistent with search from File Explorer Home.
[Settings]
New!
 Discover your account benefits. Windows Settings now makes it easier to find the benefits and services available with your Microsoft account.
[Screen capture]
New!
 This update changes the border displayed during screen capture from yellow to red, making it easier to identify when a capture session is active.
[Mouse cursor]
New!
 The new Pointer indicator makes it easier for people with low vision to locate and use the mouse pointer. To turn it on, go to 
Settings > Accessibility > Mouse pointer
 and touch and enable 
Pointer indicator
. After you enable the setting, press 
Windows logo key + Ctrl + Shift + X
 to turn the pointer indicator on or off. This update also improves mouse pointer performance during screen captures, reducing visible cursor latency in scenarios such as game streaming.
[Magnifier]
New!
 This update adds a Keyboard shortcut for Magnifier toggle in 
Settings > Accessibility > Magnifier
. It lets you choose whether 
pressing Windows logo key + Plus (+) starts Magnifier
. The shortcut is on by default.
New!
 Magnifier now includes a help menu that makes it easier to discover key features and access relevant support resources. You can also open Feedback Hub directly from Magnifier to share feedback.
[Narrator]
New!
 Narrator now supports math reading in additional languages: Greek, Hungarian, Indonesian, Norwegian (Bokmål), Polish, Russian, Swedish, and Vietnamese.
[Live captions]
New!
 Live captions now gives you more control over which audio is transcribed. In Live captions settings, you can choose to caption system audio, microphone audio, or both. This makes it easier to caption an in-person conversation without including system audio or follow audio from your PC during a meeting or while watching a video.
[Keyboard shortcuts]
New!
 If you accidentally trigger the keyboard shortcut for 
Sticky Keys
, 
Filter Keys
, or 
Toggle Keys
, you can now turn it off directly from the prompt that appears. You can still manage notifications and sounds for these features under 
Settings > Accessibility > Keyboard > Notification preferences
.
[Voice typing]
This update improves reliability of configuring voice typing settings.
[Web sign-in]
New!
 Web sign-in is now supported on Microsoft Entra hybrid joined devices, in addition to Microsoft Entra joined devices. At the lock screen, you can sign in without a password by using a FIDO2 security key, a passkey on your phone, or a Temporary Access Pass (TAP). After you sign in, Windows gets a Kerberos ticket, so access to on-premises file shares and internal sites continues to work. For more information, see 
Web sign-in for Windows
.
[RemoteApp]
This update fixes an issue that might cause an extra character to appear at the beginning of Japanese text entered in RemoteApp applications.
[TPM]
This update fixes an issue that might cause boot failures or TPM initialization errors on Arm-based systems that use a TPM 2.0 Command Response Buffer (CRB) interface.
[Security]
This update improves the security key sign-in experience. The "Other user" icon has been removed from the PIN entry screen for a simpler appearance. On devices with display-based NFC readers, a new on-screen indicator shows where to tap your security key during sign-in. The indicator adjusts to the device's screen orientation, making it easier to locate the NFC reader.

This non-security update includes quality improvements. The following summary outlines key issues addressed by the KB update after you install it. Also, included are available new features. The bold text within the brackets indicates the item or area of the change.

 This update addresses an issue that might cause Sage 50 Accounting to close unexpectedly when you select options in the application.
[Display]
 This update fixes an issue that might cause Miracast connections to default to a lower resolution when connecting to certain wireless display receivers.
[Passkeys]
 This update fixes an issue that caused cross-device passkey authentication on Android devices to display a “Something went wrong” error.
[Restart and shutdown]
 This update fixes an issue that might incorrectly display the “Someone else is using this PC” warning when restarting or shutting down, even when no other user is signed in.
[Settings]
 This updated fixes an issue where spacing between sections was missing on the 
System > Advanced page
.
[File History]
 This update fixes an issue where the File History restore interface might not find backups when a drive is selected as the backup location.
[RemoteApp]
 This update fixes an issue where Japanese text input in RemoteApp applications might add an extra character at the beginning of the entered text.
[Fax]
 Fixed: This update addresses an issue where Windows Fax and Scan might fail to connect to a fax server due to an authentication issue.
[Activation]
 Fixed: This update addresses an issue that could prevent Windows IoT Enterprise LTSC devices from activating correctly using Key Management Service (KMS) or Token-Based Activation (TBA).

Known issues in this update
SQL Server linked server connections might remain open
Symptoms
After Windows updates released October 13, 2026, and later are installed on server devices, connections created by SQL Server linked server queries might remain open after the queries complete. As additional queries are performed, connections to external databases can accumulate instead of closing as expected. This can slow or degrade server performance after prolonged run time.
This issue affects SQL Server linked server queries that use OLE DB providers to connect to external databases. Oracle and PostgreSQL connections are among those known to be affected. In affected environments, administrators might observe an increasing number of open connections to external databases, even when the associated SQL Server linked server queries are no longer running.
If idle connections can be identified, it is possible to manually close them in order to temporarily relieve server load. It is also possible to temporarily restore system stability by restarting the SQL service. However, these steps can also interrupt active queries or transactions, and the problem can resurface again after sufficient operation time.
Workaround:
A mitigation is available for affected enterprise devices. To apply this mitigation in your organization, contact 
Microsoft Support for business
.
