How Outlook Search is changing: ranking, resilience, and the feedback loop
ElbioAbib
Microsoft
Nov 03, 2026
Search quality is easy to describe and difficult to engineer. A user may remember a sender, a phrase, or the approximate time of a message—but not the exact terms that an index expects. The system must retrieve the right candidates, rank them well, and respond quickly across large, noisy mailboxes.
We’ve been listening closely to customer feedback and looking at where the search experience isn’t meeting expectations and where we can do better. That feedback, together with our engineering signals, has helped us focus on the areas that matter most. Over the past several months, the Outlook team has been working on all three parts of that problem: improving result ranking, making search more resilient when connectivity is poor, and building a tighter feedback loop between user experience and our engineering signals. Here is what has changed, the technical reasoning behind it, and what we are testing next.
1. Changes users can see
Expanding the relevance-ranked set
The ranking system now has more room to surface likely matches before results transition to chronological order.
Outlook now shows up to seven relevance-ranked results at the top, followed by the remaining results ordered by date. Ranking considers signals such as recency, sender, and prior interaction with messages. Increasing the relevance-ranked set is a presentation change, but it also creates a larger surface for evaluating ranking quality. We are continuing to tune both the ranking logic and the boundary between relevance and date-based ordering, while keeping additional sort options accessible.
Availability:
 Classic Outlook for Windows Current Channel and Monthly Enterprise Channel with Subscription, Outlook on the web, new Outlook, and Outlook Mobile. Rollout on Outlook for Mac is in November. Available across Commercial and Consumer.
Comparison of the previous three-result relevance block with the expanded set of up to seven top results in Classic Outlook for Windows.
Cloud-first search with automatic local fallback
The goal is consistent capability when online and graceful degradation when the network is not reliable.
Classic Outlook combines Microsoft’s cloud search service with Windows Desktop Search, which maintains a local index on the PC. Some query classes historically stayed local, including Find Related, portions of advanced search syntax, and queries in a broader set of languages. Eligible searches now use the cloud service so they can benefit from the same search capabilities and service-side improvements as other Outlook clients. Local search remains necessary for offline scenarios and for content that is not stored in the cloud, including PST files and POP or IMAP accounts. Classic Outlook search now automatically falls back to the local index when connectivity or service latency prevents a timely response from the cloud service.
Availability for automatic fallback:
 Classic Outlook for Windows Current Channel with Subscription, Outlook Mobile, Outlook for Mac. New Outlook is in development.
Classic Outlook search automatically falls back to the local index when connectivity or service latency prevents a timely response.
Improving latency
Average latency matters, but the slowest searches disproportionately shape whether search feels dependable.
Two changes produced meaningful gains in the slowest 5% of Classic Outlook searches:
Authentication-path optimization:
 reduced latency for the slowest 5% of searches by 40% for Commercial mailboxes.
Migration to cloud search:
 for query classes moved from the local index to the cloud, latency for the slowest 5% fell from 4.5 seconds to 1.3 seconds.
Availability: 
Classic Outlook for Windows Current Channel and Monthly Enterprise Channel with Subscription. Available for Commercial and Consumer.
Calendar search spotlight adds temporal context
Calendar search spotlight renders matching events directly in the calendar view. That context matters: the event before or after a match, and any overlap, may be as useful as the match itself. Users can switch back to the traditional list with one click.
Availability: 
Rolling out to Outlook on the web and new Outlook in November. Available across Commercial and Consumer. We are evaluating feedback before expanding this experience across Outlook clients.
Calendar search spotlight displays matching events in their surrounding schedule context, with an option to return to list view.
2. How we evaluate and improve ranking
How we measure search improvements
Search improvements need repeatable evaluation before they reach production.
We begin with offline tests against generated mailboxes designed to reproduce the characteristics of real enterprise inboxes: thousands of messages, meeting invitations, newsletters, group mail, and topics that overlap across projects. Generated data gives us control and repeatability without using a customer mailbox as a test fixture.
The evaluation set contains thousands of queries with known expected answers. Its distribution is informed by thousands of real search patterns, including keywords, names, email addresses, and combinations of those terms. Offline evaluation is useful for iteration, but it cannot reproduce every mailbox or intent. Before broad rollout, we therefore validate changes through controlled live experiments and online quality metrics.
Distilling a ranking model for Outlook scale
Better semantic ranking is useful only if it fits the latency and throughput constraints of a service used at Outlook scale.
We are building an Outlook-specific small language model ranker. The model is trained through distillation: a larger model provides supervision to a smaller model that is practical to serve within Outlook’s performance envelope. The engineering objective is not simply model quality in isolation; it is a better relevance-latency trade-off under production load. Early offline results are promising. Internal testing is underway.
Alongside this work, we rolled out several smaller service changes, including better handling of stop words such as “the,” “and,” and “is.” This stop-word improvement affected about 3% of searches. Those searches saw an increase in result clicks where users opened and engaged with the mail.
Availability for stop words handling: 
All Outlooks endpoints. Available for Commercial and Consumer.
Knowledge distillation trains a smaller, Outlook-specific student ranker to mimic a larger teacher model's relevance scores, meeting production latency requirements.
3. Closing the gap between metrics and user intent
Outlook now includes a thumbs-up or thumbs-down prompt on the search results page. With appropriate diagnostic context, that signal helps engineers identify query classes and result patterns that need investigation. One finding is especially important: behavioral metrics can suggest success—for example, a result was opened or read—while the user still reports that the search failed. Explicit feedback exposes cases where proxy metrics do not capture intent.
Availability:
 Classic Outlook for Windows Exchange Online and Outlook.com accounts on Current Channel with Subscription, Outlook on the web, new Outlook, Outlook Mobile, and Mac. We are adding thumbs to more Outlook Search surfaces in November and December. Available for Commercial and Consumer.
The in-product feedback prompt captures an explicit quality signal alongside diagnostic context.
Why explicit feedback matters
If a search result doesn’t match your intent, use the thumbs-up or thumbs-down prompt to tell us. Enterprise mailboxes vary widely in vocabulary, communication patterns, retention history, and organizational structure. Two users can issue the same query with different intended results, or remember the same message through entirely different details. That makes search a continuing systems problem rather than a feature that reaches a fixed endpoint. If a result set misses your intent, the thumbs signal gives us evidence that clicks and dwell time alone cannot provide—and helps us prioritize the next investigation.

Searching for a specific email in Outlook can prove challenging. Outlook search can sometimes return irrelevant results while missing the exact email you need. Microsoft is looking to improve that frustrating experience with a revamped search.

emphatically

Outlook now handles stop words better. Those words, such as "the," "and," and "is," often clog search results with irrelevant emails. I can't tell you how many times those tiny words have led to terrible searches that made me fish through the results that appear chronologically.

Microsoft published a 
Microsoft Tech Community post
 on November 3, 2026 titled “How Outlook Search is changing,” detailing changes to how Outlook ranks search results, how search behaves when the connection is poor, and how a new thumbs-up/thumbs-down prompt feeds back into ranking.

 the update.

What Happened: The Outlook Search Update in Plain Terms
Microsoft’s post groups the changes into three areas: ranking, resilience when connectivity is poor, and a tighter feedback loop. Here they are one at a time.
1. Ranking: up to seven top results instead of three
According to 
Microsoft’s post
, Outlook now shows 
up to seven relevance-ranked results
 at the top, followed by the remaining results ordered by date. Microsoft’s own comparison image shows the previous three-result relevance block next to the new one. Ranking considers signals such as:
Recency
: how new the message is
Sender
: who the message came from
Prior interaction
: how you’ve engaged with the message before
Microsoft says it’s still tuning both the ranking logic and where results switch from relevance to date order, and that other sort options stay available.
Microsoft lists availability for the expanded ranking as Classic Outlook for Windows (Current Channel and Monthly Enterprise Channel with a Microsoft 365 subscription), Outlook on the web, new Outlook, and Outlook Mobile, with Outlook for Mac rolling out in November. Microsoft says the expanded ranking covers both work and personal accounts; the fallback, latency and feedback changes have their own, narrower client lists below.
Microsoft also says it now handles stop words such as “the,” “and,” and “is” better, so they don’t drag irrelevant mail into results. Microsoft says this affected about 3% of searches, which saw more result clicks afterward, and lists it as available on all Outlook endpoints.
Behind the ranking is an Outlook-specific small language model ranker, trained by distillation from a larger model.

This is the change that matters most if you search mail on hotel Wi-Fi, a train, or a flaky office network.
Classic Outlook combines Microsoft’s cloud search service with Windows Desktop Search, which keeps a local index on your PC. Microsoft says more kinds of searches now go to the cloud service, and 
Classic Outlook now automatically falls back to the local index

Microsoft lists automatic fallback as available in Classic Outlook for Windows (Current Channel with a subscription), Outlook Mobile, and Outlook for Mac. For 
new Outlook

Microsoft focused on the slowest 5% of Classic Outlook searches, the ones that make search feel unreliable. It reports two figures:
An authentication-path change cut latency for the slowest 5% of searches by 
40% for work (Commercial) mailboxes
.
For query types moved from the local index to the cloud, latency for the slowest 5% fell from 
4.5 seconds to 1.3 seconds
.
These numbers are Microsoft’s own, and they apply to Classic Outlook for Windows on Current Channel and Monthly Enterprise Channel with a subscription. We found no independent measurement of them in the coverage we reviewed.

Outlook now shows a 
thumbs-up or thumbs-down prompt on the search results page
. Microsoft says the signal, together with diagnostic context, helps engineers find searches where people opened a message but still didn’t find what they wanted.
Microsoft lists the prompt as available in Classic Outlook for Windows (Exchange Online and Outlook.com accounts on Current Channel with a subscription), Outlook on the web, new Outlook, Outlook Mobile, and Mac, with thumbs coming to more Outlook search surfaces in November and December.
Also mentioned: Calendar search spotlight
Microsoft also describes a Calendar search spotlight that shows matching events directly in the calendar view, so you can see what comes before and after a match. It’s rolling out to Outlook on the web and new Outlook in November, and you can switch back to the regular list with one click.
What’s still thin
Microsoft’s post lists channels and client availability but no build numbers or completion dates. We also found no documented way to opt out of or roll back the ranking change in the sources we reviewed, though that doesn’t rule one out.

O
utlook search has long been bad at one specific thing. You type a few words you're sure are in the email, and the results are full of messages that happen to share a "the" or an "is" with your query. The email you actually wanted is somewhere further down. Microsoft is now trying to fix that, and it's asking users to help by grading the results.
The changes are described in a November 3 Outlook Blog post on Microsoft's Tech Community titled "How Outlook Search is changing: ranking, resilience, and the feedback loop." It covers several separate updates. Some are already rolling out, one is still in internal testing, and the update for each Outlook client arrives on a different schedule. That last point matters, as you'll see below.
The grading part: thumbs up, thumbs down​
The headline feature is a thumbs-up or thumbs-down prompt on the search results page. Windows Central reports that Microsoft says Outlook search now surfaces more relevant emails and lets users rate results with a thumbs up or thumbs down.
Microsoft explains why it wants your rating instead of just counting clicks. Behavioral data can mislead. If you open an email from your results, that looks like a successful search, even though you may have opened it only to check whether it was the right one and then given up. In its blog post, Microsoft says an explicit rating exposes cases where clicks and dwell time don't show what the user actually wanted. Microsoft also says the rating is sent "with appropriate diagnostic context," which helps engineers find the types of queries that fail.
Be realistic about what the button does. Microsoft presents feedback as evidence that helps engineers decide what to investigate next. It does not say that a thumbs-down will fix your own future results. You're filing a report, not training a personal assistant.
Where the feedback prompt is available, according to Microsoft:
Classic Outlook for Windows with Exchange Online and Outlook.com accounts on Current Channel with a subscription
Outlook on the web
New Outlook
Outlook Mobile
Outlook for Mac
More search surfaces getting the prompt in November and December 2026, for both commercial and consumer users
In short:
 The thumbs prompt gives Microsoft a direct signal when a search fails. It doesn't let you correct your own results.
Seven ranked results instead of three​
The most visible change is how results are laid out. Windows Central puts it simply: when you search for an email within Outlook, you will see seven ranked results rather than three. According to Microsoft's post, Outlook now shows up to seven relevance-ranked results at the top, and the rest of the results follow in date order. The ranking looks at signals such as how recent a message is, who sent it, and how you've interacted with it before.
Microsoft says it is still adjusting both the ranking logic and the point where relevance order switches to date order. Other sort options remain available.

If you'd rather keep strict date order​
Not everyone wants Outlook choosing what's "relevant," and a bigger ranked block means more of that. The setting to turn it off already exists. In a Microsoft Q&A support thread, the suggested fix for Outlook on the web is to go to Settings > General > Search, clear the checkbox for "Show top seven most relevant results," select Save, then refresh the page and perform the search again. The same answer notes that disabling this option usually makes the results appear closer to chronological order. You can also open Sort in the upper‑right corner of the results pane and select Newest on top after running a search.
For Classic Outlook on Windows, an older Microsoft Q&A answer gives the path Outlook > File > options > search > uncheck - Show most relevant search results on top. That answer dates from 2023, so the exact wording may be different in current builds.
Before you switch it off, think about whether the new ranking might work better than the old three-result block did.
In short:
 Most clients now get more ranked results, and you can still turn ranking off if you prefer date order.
The stop-word fix is already live​
This is the change that actually addresses the "the" and "is" problem. Microsoft says it has rolled out service changes that improve how Outlook handles common stop words such as "the," "and," and "is." According to the company, the change affected about 3% of searches, and those searches saw more result clicks where users opened and engaged with the mail. Microsoft didn't say how large that increase was.
Windows Central illustrates the change with Microsoft's before-and-after example of a search for "the FY27 budget." The example shows how Outlook's updated search ranks relevant emails higher in the results instead of surfacing messages that only happen to contain common search terms.
Microsoft lists the stop-word handling as available on all Outlook endpoints, for commercial and consumer users.
The AI model isn't shipping yet​
Windows Central's coverage gets one thing wrong. It states that the improved rankings in Outlook are the result of a small language model ranker built specifically for Outlook. Microsoft's own post doesn't support that.
Microsoft says it is 
building
 an Outlook-specific small language model (SLM) ranker. It is trained through distillation: a larger "teacher" model supervises a smaller "student" model that is cheap enough to run at Outlook's scale. The company calls early offline results "promising" and says internal testing is underway. It gives no release date and doesn't say the model is generally available.
So the stop-word improvement and the seven-result layout are shipping now. The SLM ranker is still in testing. Microsoft actually describes the stop-word fix as one of several "smaller service changes" made "alongside" the model work, not as something the model produced. If your searches got better this week, credit the stop-word change and the new layout, not an AI model.
Microsoft's reasoning for distillation is sound. It says the goal isn't model quality on its own but a better balance between relevance and speed under real-world load. A large model that finds the perfect email after eight seconds would still make search feel broken.
In short:
 The SLM ranker is still in internal testing. The improvements you can see today come from the stop-word fix and the new layout.
Classic Outlook gets faster and handles bad connections better​
Classic Outlook users get two more changes, and the details matter.
Cloud first, with automatic local fallback.
 Classic Outlook combines Microsoft's cloud search service with Windows Desktop Search, which keeps a local index on the PC. Microsoft says some query types used to stay local, including Find Related, parts of the advanced search syntax, and queries in a broader set of languages. Eligible searches now go to the cloud, so they get the same service-side improvements as other Outlook clients.
Local search is still needed offline and for content that isn't in the cloud, such as PST files and POP or IMAP accounts. Classic Outlook now switches to the local index automatically when the connection or a slow service response prevents a timely cloud result. Microsoft lists automatic fallback for Classic Outlook for Windows (Current Channel, subscription), Outlook Mobile and Outlook for Mac. For new Outlook, the feature is still "in development."
Latency numbers, with their limits.
 Microsoft credits two changes for improvements in the slowest 5% of Classic Outlook searches:
Authentication-path optimization:
 a 40% latency reduction for the slowest 5% of searches, for commercial mailboxes only.
Migration to cloud search:
 for query types moved from the local index to the cloud, latency for the slowest 5% fell from 4.5 seconds to 1.3 seconds.
These are tail-latency figures for specific groups of searches, not averages for every search. Microsoft argues that the slowest searches shape whether search feels dependable, and anyone who has watched the "searching..." spinner while a meeting starts will agree. Microsoft lists these gains for Classic Outlook on Current Channel and Monthly Enterprise Channel with a subscription.
For admins:
 Users on PSTs or POP/IMAP accounts still rely on Windows Desktop Search, so a healthy local index still matters. And if new Outlook users complain that search fails on weak hotel Wi-Fi, the automatic fallback hasn't reached that client yet.
How Microsoft tests ranking​
Microsoft says it starts with offline tests against generated mailboxes built to resemble real enterprise inboxes: thousands of messages, meeting invites, newsletters, group mail and overlapping project topics. Using generated data means no real customer mailbox becomes a test fixture. The evaluation set has thousands of queries with known correct answers, based on real search patterns such as keywords, names, email addresses and combinations of those.
Microsoft admits that offline tests can't cover every mailbox or every user's intent. That's why it runs controlled live experiments before broad rollout, and why it wants the thumbs feedback. As the post notes, two people can type the same query while looking for different emails.
Also new: Calendar search spotlight​
The same post announces 
Calendar search spotlight
, which shows matching events directly in the calendar view so you can see what's before, after or overlapping them. You can switch back to the old list view with one click. It's rolling out to Outlook on the web and new Outlook in November 2026, and Microsoft says it is reviewing feedback before bringing it to other clients. It's a calendar feature and has nothing to do with grading email results.
Verdict​
This is a worthwhile set of updates. The stop-word fix addresses a long-standing complaint, the Classic Outlook latency gains are measured where users notice them most, and asking for explicit feedback is a reasonable admission that click data doesn't tell the whole story.
Keep expectations in check, though. The AI ranker isn't shipping yet, automatic fallback hasn't reached new Outlook, and a thumbs-down tells Microsoft about a problem without fixing your own results. Rate your searches honestly anyway. Microsoft says it will use those ratings to decide which search failures to investigate next.
