Safety
Before release, we evaluated Muse Ember under our Meta Superintelligence Scaling Framework, including chemical and biological, cybersecurity, and loss-of-control risks. Across the categories assessed, our evaluations found that Muse Ember remained below the framework’s high-risk thresholds. Though it’s a small model, it received the same core safety training and testing. We also evaluated how Muse Ember behaves when acting on users' behalf. That covers whether it respects user intent, handles sensitive information appropriately, resists instructions hidden in web pages, documents, or tool outputs that try to redirect it, and seeks human input before high-impact actions.

Meta Superintelligence Lab released a new AI model on Monday called Muse Ember, the lab’s lightest and most cost-efficient AI model yet. In its release, Meta said Ember was “designed for complex reasoning execution and the work agents repeat all day: tool calls, coding subtasks, routing, extraction, and long document parsing.”
Meta particularly emphasized Ember’s cost-per-task, using 
Artificial Analysis’s composite benchmark score
 to show Ember as cheaper and smarter than competitors like Anthropic’s Haiku and OpenAI’s Luna.
Image Credits:
Meta Superintelligence Labs
At 10 cents per million input tokens, Ember is significantly cheaper than frontier competitors like Haiku and Luna. Not only that, it’s cost-competitive with open source competitors like DeepSeek V4.1 Flash and GLM 5.3 Flash. 
Given the emphasis on low cost and accuracy at scale, Ember is designed to pair with a larger model like Meta’s Muse Wonder in an agentic harness. In the case of a customer-support agent, for instance, you might see a heavier model establishing rules for how to handle a particular issue, then sending a lighter-weight model to apply the rules across tens of thousands of cases. As Meta puts it in the announcement, “Muse Wonder plans, Muse Ember handles the volume.”
With volume-heavy use cases in mind, Meta also trained Ember to work well across different types of media, including text, images, and audio. The result makes the model surprisingly flexible in what kind of inputs it can handle. As Meta puts it in the announcement, “agents can read screenshots, charts, and scanned documents, or work from voice memos, meeting recordings, and video without a separate model.”

What happened
Meta's Muse Ember hits 36 on AA's Intelligence Index, tying Claude Haiku 5.5 at $0.136 vs $0.411 per task.
$0.10/$0.50 per 1M tokens, 1M context.
Meta just pushed the small-model price floor down another notch. Muse Ember is live today on the Meta Model API and Muse Code as 
muse-ember-1.0
, at $0.10 per million input tokens, $0.004 cached input and $0.50 output.
The number that matters is on Artificial Analysis Intelligence Index v5: Ember (max) scores 36, tying Claude Haiku 5.5 (max), with GPT-6 Luna (max) at 28. But one AA task costs $0.136 on Ember versus $0.411 on Haiku 5.5. Same score, a third of the bill. Every Luna reasoning setting sits below it.
The spec sheet is built for agent pipelines: 1M-token context, up to 512K output tokens, native text, image, audio and video input, and Responses API support. Meta's positioning is blunt. Muse Wonder plans the hard problems; Ember handles the volume: tool calls, routing, extraction, long-document parsing, running tests and targeted fixes.
The more interesting part is the lineage. Ember is the first model trained using Muse Wonder Full, the first payoff of Meta's plan to distill its biggest model into specialized small ones. And it undercuts Meta's own lineup: Ember scores 36 on the AA index to Muse Spark 1.3's 37, but costs $0.14 per task against Spark's $2.39. That's 17x cheaper for one point. For good-enough subagent work, Spark just got cannibalized.
The widest gaps are on agent work: AutomationBench-AA 37.8 vs Haiku's 13.9 and Luna's 20.2; Coding Agent Index-AA 46 vs 37 and 31; Terminal-Bench 4.0 40.9 vs 39.2 and 16.4; OSWorld 2.1 binary 33.8 vs 27.8.
Don't read the table as a sweep. On FrontierCode 2.0-AA, which grades real engineering tasks on mergeability, Ember's 27.2 loses to Haiku's 34.9. Hard work still belongs to bigger models. Agents' Last Exam, PSI, OSWorld and PerceptionBench are Meta-internal evals, and Terminal-Bench compares each model in its own best harness (mini-swe-agent for Ember, Claude Code for Haiku, Codex for Luna), not like for like. Ember's cost-per-task points are also estimates at list pricing.
Early partners lead with latency. Cloudflare says tail latency ran up to 30% faster than the comparable model it tested; You.com measured a 2.2-second p95 on coding tasks, 4x to 13x faster than leading open-weight models, with 36–48% fewer output tokens. Box, Cline and Oracle are also in the launch cohort. It's API and Muse Code only; no weights.
For the past year, small models competed on how close they could get to the big ones. Ember changes the question to who's cheapest at the same score. If $0.136 a task holds up in production, the next move from Haiku and Luna won't be a higher score. It'll be a lower price.

Meta released Muse Ember today, its smallest and most efficient model, built for the work agents repeat all day: tool calls, coding subtasks, routing, extraction and long documents. It is on Meta Model API now as muse-ember-1.0, and in Muse Code. Mark Zuckerberg announced it on X at 17:54 UTC; @AIatMeta followed at 18:04.
THE PRICE AND SPECS
$0.10 input / $0.50 output per 1M tokens, $0.004 for cached input. That is the same sticker as Claude Haiku 5.5 (for prompts up to 100K tokens).
1M-token context window and up to 512K output tokens, per Meta.
Text, image, audio and video in; text out. It supports the Responses API.
Meta says Ember is the first model trained using Muse Wonder Full, the stronger Wonder variant in Muse Code.
OpenCode added it to its Zen gateway the same day, at the same price.
THE INDEPENDENT NUMBER
Artificial Analysis scores Muse Ember (Max) 36 on its Intelligence Index, the same as Claude Haiku 5.5 (Max); its model pages list Haiku 5.5 first and Ember second of 32 on intelligence (read on its site today). It puts Ember's cost at $0.14 per index task. Meta's "about a third of the cost" is per task, not per token: the two list at the same price, and Meta's chart, built from Artificial Analysis results, has Haiku 5.5 at $0.41 a task at max effort.
META'S OWN BENCHMARKS
These are Meta's figures, at max reasoning effort, against Claude Haiku 5.5 and GPT-6 Luna:
Terminal-Bench 4.0: 40.9, against 39.2 and 16.4.
AutomationBench-AA: 37.8, against 13.9 and 20.2.
OSWorld 2.1 (partial credit): 69.5, against 68.9 and 50.5.
Meta's internal Personal Superintelligence Index: 46.8, against 36.1 and 37.0.
SAFETY
Meta says it evaluated Ember under its Meta Superintelligence Scaling Framework for chemical and biological, cybersecurity and loss-of-control risks, and that it stayed below the framework's high-risk thresholds in every category assessed.

WHAT WE DO NOT KNOW
