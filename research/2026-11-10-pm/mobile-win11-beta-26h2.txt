Announcing new builds for 6 November 2026
							Written By
								Stephen Lines
							published
							November 6, 2026
Hello Windows Insiders,
Today, we’re releasing new Windows 11 Insider Preview builds to the Beta and Experimental channels.
New builds this week
Select your channel below to view its release notes:
Beta: 
Build 26320.9876
Experimental: 
Build 26340.9882
For those on other specific Windows build versions, here are today’s new builds and release notes:
Beta (26H1): 
Build 28020.3445
Experimental (26H1): 
Build 28120.3454
Experimental (Future Platforms): 
Build 29704.1000
Experimental (Future Platforms) synthetic payload releases
Insiders in the Experimental (Future Platforms) channel will begin to notice in the coming weeks that we will be releasing a new build version on a weekly basis, in-between our usual weekly Insider preview builds. These in between releases are just synthetic latest cumulative updates (LCU’s), and do not contain any new features or payload. They are helping us test backend flighting and updating services. As such, we will not publish weekly release notes or blogs for these updates, but will keep track of versions in 
Flight Hub
. 
Notable new features:
[Windows Hello]
Release channel: 
Experimental
Windows Hello sign-in improvement
Sign-in and unlock now behave more consistently and give clearer guidance. You no longer have to wait for face or fingerprint recognition to finish before entering your PIN. Use whichever method works first. At certain times, such as after a restart, you’ll need your PIN first. After that, biometrics work as usual.
Sign in with face, fingerprint, or PIN, whichever works first.
Thanks,
Stephen and the Windows Insider Program team

Microsoft today released five pre-release Windows 11 builds through the Windows Insider Program, but there’s only one notable change plus a note about a change to one channel.
The new builds are:
Beta: 
Build 26320.9876
Experimental: 
Build 26340.9882
Beta (26H1): 
Build 28020.3445
Experimental (26H1): 
Build 28120.3454
Experimental (Future Platforms): 
Build 29704.1000
The only notable change is an improvement to Windows Hello in the Experimental channel: Now, whichever sign-in method you use will work immediately, so you no longer have to wait for face or fingerprint recognition to finish before you can enter your PIN. Oddly, Windows 11 will sometimes require you to enter a PIN before you can use biometrics, like after a restart. That’s how mobile devices work and I don’t get it.
As for the channel change, those on Experimental (Future Platforms) will soon start seeing additional interim weekly builds between each normal weekly build. Microsoft says these interim builds are “just synthetic latest cumulative updates (LCUs), and do not contain any new features or payload” that help it “test backend flighting and updating services.”

Windows 11 Insiders can now type their PIN without waiting for Windows Hello to finish scanning their face or fingerprint.
 Sign-in and unlock should feel more consistent, with clearer guidance, and you can use whichever method works first.
The change arrived on November 6, 2026, in new Windows 11 Insider Preview builds announced by Stephen Lines and the Windows Insider Program team. Microsoft lists the Windows Hello improvement for the 
Experimental
 channel. Separate Beta and Experimental builds also shipped for other Windows 11 tracks, including 26H1 and Future Platforms.
Table of Contents
Toggle
In the new Experimental builds, you can start typing your PIN while Windows is still trying face or fingerprint recognition. Graphic: Windows Mode, based on Microsoft’s Windows Insider blog.
Windows Hello no longer makes you wait to type your PIN
Windows Hello
 is the face and fingerprint sign-in built into Windows. On many PCs, if Hello did not unlock you right away, you still had to wait for that scan to finish before you could enter a PIN instead.
That wait is gone in the new Experimental builds. You can start typing your PIN while the PC is still trying face or fingerprint recognition. Microsoft says sign-in and unlock now behave more consistently, give clearer guidance, and let you use 
whichever method works first
.
There is one exception Microsoft calls out: at certain times, such as after a restart, you will need your PIN first. After that, face and fingerprint sign-in work as usual.
This is an Experimental-channel preview
Microsoft lists the Hello improvement for the Experimental channel, not Beta. If you are not a Windows Insider, you will not see it on regular Windows 11 yet. Microsoft has not said when, or whether, the change will reach a broader release.

Flight Hub
 lists the main Beta and Experimental builds under Windows 11 version 26H2. Those builds are delivered on top of Windows 11 version 25H2 (build 26200), with an enablement package that raises the build number to 26320 in Beta and 26340 in Experimental.
The 26H1 builds are a separate track. Microsoft says 26H1 is not a feature update for 25H2. It includes platform changes to support specific silicon, and most customers do not need to do anything about it.
Experimental (Future Platforms) builds are not tied to any retail release of Windows. For last month’s Insider changes, see our recap of the 
October 30 Windows 11 Insider builds
.
Synthetic test updates are coming to Future Platforms
Insiders in the Experimental (Future Platforms) channel will start seeing an extra weekly build, in between the usual Insider preview builds, in the coming weeks.
Microsoft says those extra releases are 
synthetic latest cumulative updates (LCUs)
. An LCU is the usual cumulative package Windows Update installs. A synthetic one does not add new features or other payload. Microsoft is using them to test backend flighting and updating services, meaning how updates are selected and delivered, rather than to preview new Windows features.
Because of that, Microsoft will not publish weekly release notes or blog posts for the synthetic updates. It will keep track of the versions in Flight Hub. If a new Future Platforms build appears without a blog post, check Flight Hub before assuming new features arrived.
What Insiders should take from this week
The practical change is on Experimental devices that use Windows Hello: you can type your PIN right away instead of waiting for face or fingerprint recognition to give up. The other builds are the regular weekly preview drops, and the synthetic LCUs are a delivery-system test for Future Platforms, not a feature preview.

(status 200)
Microsoft released Windows 11 Insider Preview Build 26320.9876 to the Beta Channel on November 6, 2026. The build moves Beta Insiders from version 25H2 to Windows 11, version 26H2, and brings a rebuilt Windows Search. Stephen Lines announced it on the Windows Insider Blog, and the full beta changelog sits on Microsoft Learn.          
The move to 26H2
The jump to 26H2 arrives through an 
enablement package
, so Microsoft says the higher build number should not bring significant changes by itself. Four other builds shipped alongside it: 26340.9882 for Experimental, 28020.3445 for Beta 26H1, 28120.3454 for Experimental 26H1, and 29704.1000 for Experimental Future Platforms.          
A faster Windows Search
The 
headline feature
 is a new Windows Search built on WinUI 3, rolling out gradually. Microsoft calls it faster and more efficient, with better matching for typos and synonyms. Inline actions let you turn on dark mode or Bluetooth, adjust brightness, mute your device, or arrange windows from the results. English is the only supported language for now.          
Gaming and File Explorer
In Xbox mode, the Gaming Task View navigation bar gains the full set of taskbar quick settings. File Explorer’s address bar now accepts the tilde as a shortcut to your user profile folder, so typing ~\AppData jumps straight to that subfolder.          
Sign-in, accessibility, and settings
Web sign-in now works on Microsoft Entra hybrid-joined devices, previously limited to Entra-joined hardware. You can sign in at the lock screen with a FIDO2 security key, a phone passkey, or a Temporary Access Pass, and Windows then obtains a Kerberos ticket so on-premises file shares keep working.          
Windows Hello facial recognition can brighten the screen in dim rooms. Enable it under Settings > Accounts > Sign-in options > Facial recognition (Windows Hello). Live Captions now transcribes system audio, your microphone, or both, and Sticky Keys and Filter Keys prompts now include an option to stop asking again.          
Settings also shows shared Microsoft 365 Family storage under Settings > Accounts > Cloud storage. Subscriptions bought after October 8, 2026, will show now; older ones will appear after the first renewal on or after May 2, 2027.
