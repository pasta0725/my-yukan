同社は現地時間2026年11月17日、WindowsおよびmacOS向けに「Google Chrome 158.0.8127.37」「同158.0.8127.36」、Linux向けに「同158.0.8127.36」をリリースした。今後数日から数週間をかけて順次展開していく。

===== https://webutility.io/tool-news/chrome-158-security-update-204-fixes-six-critical
(status 200)
Google promoted Chrome 158 to Stable on November 17, and this Chrome security update packs 204 security fixes for Windows, Mac and Linux. Six of those flaws carry Google’s highest Critical rating, and the new version is reaching desktop and Android users over the next few days and weeks.
That is a very large batch for a single release, more than double the 83 fixes in the previous big update. Bugs rated Critical can, in the worst case, let a booby-trapped web page run code on your computer, so this is an update worth installing soon.
At a Glance
Chrome 158 is now on the Stable channel for Windows, Mac, Linux and Android.
Google lists 204 security fixes: 6 Critical, 62 High, 82 Medium and 54 Low.
Google does not mark any of the fixed bugs as exploited in the wild.
The desktop build is 158.0.8127.36 or .37, and Android gets 158.0.8127.42.
What Google Fixed in Chrome 158
According to Google’s release post, the desktop version is 158.0.8127.36 on Linux and 158.0.8127.36 or .37 on Windows and Mac. The six Critical bugs sit in core parts of the browser that handle almost everything you do online.
Three of them are use-after-free bugs, a common type of memory mistake, found in WebView, the WebAudio sound system and Chrome’s garbage collection code. The other three are memory writes that go past their limits, in the GPU code, the media code and ANGLE, the layer that turns web graphics into instructions your graphics card understands.
Beyond those six, Google rates 62 issues as High, 82 as Medium and 54 as Low. Several bugs are in V8, the engine that runs JavaScript on websites. As usual, Google is keeping most bug details private until the majority of people have updated.
Who Found the Bugs
Google’s own teams reported many of the flaws, alongside a long list of outside researchers. Four of the six Critical bugs were credited to one researcher, Xinyang Ge, and for two of them the release notes say the work was assisted by the Claude AI model.
That detail is a small sign of a wider shift. Security researchers are now using AI tools to help find hidden memory bugs, which may be one reason the number of fixes in some recent browser releases has grown so large.
Is Chrome 158 on Android Too?
Yes. Google released Chrome 158 for Android as version 158.0.8127.42, and it should show up in the Play Store within a few days. Google says Android builds carry the same security fixes as the matching desktop release unless it notes otherwise.
The Android post itself mentions only stability and speed improvements. Still, because the security fixes are shared, it makes sense to install it as soon as the Play Store offers it.
What This Means for You
None of the 204 bugs is flagged as being used in real attacks, so there is no need to panic. But once fixes are public, attackers often study them to build attacks against people who have not updated, so waiting weeks is a poor idea.
Chrome usually updates itself in the background, yet the new version only takes effect after a restart. If you keep dozens of tabs open for days, you may be running old code without knowing it. Other browsers built on the same Chromium code, such as Edge, Brave and Opera, are likely to ship their own updates soon.
How to Update Chrome Now
On a computer, open the three-dot menu in the top-right corner of Chrome, then choose Help and About Google Chrome. Chrome checks for the update, downloads it and shows a Relaunch button. Click it, and your tabs will reopen after the restart.
When you are done, the About page should show version 158.0.8127.36 or later. On Android, open the Play Store, search for Chrome and tap Update if the button appears. If the new version has not reached you yet, check again in a day or two.
A browser update is also a good moment to clean up old logins. If you still reuse passwords, a 
strong password generator
 can create unique ones for each account.
Conclusion
Chrome 158 is one of the biggest security releases Google has shipped, with 204 fixes and six Critical bugs closed across desktop and Android. Nothing is known to be under attack yet, so the simple advice is to update, restart Chrome and keep your other Chromium-based browsers current too.
