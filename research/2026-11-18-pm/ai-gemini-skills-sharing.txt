Gemini skills gain sharing and files from more Google apps
Gemini users can share reusable skills with view or edit access and add files from Drive, Gemini Notebook and Photos. The rollout began November 12 and can take up to 15 days to reach eligible users.

Gemini users can now share reusable skills with view or edit access, rather than keeping the custom instructions to themselves. The changes also let users attach files from 
Google
 Drive, Gemini Notebook and Google Photos when creating or uploading a skill, Google said in a Workspace update on November 16.
The gradual rollout began on November 12 for Rapid Release and Scheduled Release domains and can take up to 15 days for the features to become visible. The features are available to all Google Workspace customers and users with personal Google accounts.
Sharing a skill
A skill contains reusable instructions that guide Gemini. People can grant view or edit access from the Skills page; editors can change the instructions and uploaded files and share the skill with others.
A shared skill appears as inactive on the recipient's Skills page. Recipients can review it before adding it, and the owner can send an email notification; the help page notes that the sender can choose to skip that notification. Once added, a skill can be invoked by mentioning it in a chat, or Gemini can use it automatically when relevant.
For now, sharing and managing access are limited to the Gemini web app, not the mobile app. Only a skill's owner and people with editor access can share it.
Files as references
When manually creating or uploading a skill, users can add files from the three Google apps alongside files from their device. Gemini can reference those files when the skill runs in chats and tasks. Drive files and notebooks update in real time, so the skill works from the latest version.
Uploaded files cannot exceed 100 MB per skill. Drive files must also be shared separately with the people receiving a skill. Downloaded skills do not include Drive files and notebooks, preserving their live connection, according to the Gemini help page.
Google gives examples of a marketing team sharing a skill based on brand guidelines in Drive, a team lead using a handbook for onboarding, and a teacher building a lesson-planning skill around a curriculum notebook.
Organization controls
For organizations, skill sharing is on by default, but administrators can disable it in the Admin console. The feature follows an organization's Drive sharing settings: if Drive files can be shared outside the organization, skills can be shared externally too.
There are no administrator controls for adding files to skills. A skill can also be created from a chat or task, from a template, or by uploading a skill file or folder, according to Google's help documentation.
Transition from Gems
Skills are replacing Gems, another way to customize Gemini. For personal accounts belonging to users aged 18 or over, Gems transition to skills and become read-only on November 17, 2026. Gems are scheduled to be removed from Gemini Apps on December 17.
The transition is scheduled for March 2027 for Workspace business, enterprise and nonprofit accounts, and June 2027 for education accounts. Google says it will automatically transition Gems and supported files, though some file types will not carry over.

Google has added two features to Skills, the reusable custom-instruction function in the Gemini app: sharing with other users, and attaching files from Google Drive, Gemini Notebook and Google Photos. Files from Google Drive and Gemini Notebook are reflected in real time, so a skill always works from the latest version. The source is a Japanese-language report from KeyMan's Net (ITmedia), published November 18, 2026.
According to the report, Google made the update on November 16, 2026.
What changed
Skills appeared in mid-October 2026 as the replacement for Gems, Gemini's earlier custom-instruction feature. At launch they offered only basic functions, so two Gem capabilities were missing: sharing with other users and Google Drive file integration. This update adds both.
Sharing
Skills can be shared with separate view and edit permissions, as with Gems.
Recipients get an email notification. They can review the prompt and referenced files before installing the skill in their own environment.
Installed skills are used automatically by Gemini when relevant. Users can also call one directly with an @mention in chat.
Multiple skills can be combined in a single chat through @mentions or automatic detection. The report describes this as more flexible than Gems.
File attachments
When creating or uploading a skill, users can add files from their device, Google Drive, Gemini Notebook and Google Photos.
Gemini refers to the registered files each time the skill runs in a chat or task.
Google Drive files and Gemini Notebook content update in real time.
Uploaded files are capped at 100MB per skill.
Google's example use cases include a marketing team sharing a skill that references a brand guidelines document in Drive, a team leader distributing an onboarding skill based on a handbook, and a teacher sharing a lesson-planning skill built on a Gemini Notebook of curriculum materials.
Limits and admin controls
Sharing and access management are available only in the web version of the Gemini app, not the mobile app.
If a skill includes a Google Drive file, the recipient must also be granted access to that file.
Skill sharing is enabled by default. Administrators can turn it off in the admin console.
The sharing scope follows the organization's Google Drive sharing settings. If Drive files can be shared outside the organization, Gemini skills can be shared externally too.
No administrator setting exists to restrict adding files to skills.
Availability
According to the report, the rollout began on November 12, 2026 and is gradual, covering both Rapid Release and Scheduled Release domains. It is expected to take up to 15 days to complete. The features are available to all Google Workspace users and to users of personal Google accounts. Pricing was not mentioned.
What this means
Skills now cover the Gem functions that were missing at launch, and they add live file references. A shared skill can point to a Drive document or Gemini Notebook and always use its current contents, so the person who maintains the source file does not need to redistribute the skill when the content changes.
The report flags a point for IT administrators. Because skill sharing is on by default and follows Drive sharing rules, an organization that permits external Drive sharing also permits external skill sharing. With no admin setting to block file attachments, the available controls are the sharing toggle in the admin console and the existing Drive sharing configuration. The report advises administrators to review their external sharing settings.
