ホロライブ麻雀 -ホロじゃん-
2026/11/10 00:00
イベント
推しの声に励まされ，牌を切る。「ホロライブ麻雀 -ホロじゃん-」のメディア先行体験会で，最新の“推し活”を体験してきた【オリジナル雀卓コード付】
編集部：ゆん
　Aimingが開発を手がける
「ホロライブ麻雀 -ホロじゃん-」
は，VTuberグループ・ホロライブのタレントたちと一緒に麻雀が楽しめるオンラインゲームだ。
　対応プラットフォームは
iOS
と
Android
，
PC
，
ブラウザ
で，総勢37名のタレントたちによる録り下ろしボイスやスタンプ，雀卓を彩るカスタマイズ要素などで“推し活”をしながら，
基本プレイ無料
のオンライン対局が楽しめる。
　そんな同作の
メディア先行プレイ会
が2026年10月26日，Aiming本社で開催された。会場では，メディア陣による対抗戦が行われたほか，ゲームのフリープレイや開発陣の合同インタビューも実施されたので，その模様をレポートする。
　また記事末には，
4Gamerオリジナルの雀卓が使用できるようになるコード
も掲載しているので，本作に期待している人はぜひ最後まで読み進めてもらいたい。
リリースは2026年11月25日の予定。基本プレイは無料で，ガチャによるアイテム課金方式での運営が予定されている
「ホロライブ麻雀 -ホロじゃん-」公式サイト
“推し”を選んで雀卓をカスタマイズ。手厚いアシストで初心者にも優しい麻雀ゲーム
　まずは本作の概要から紹介していこう。冒頭でも触れたように，本作はホロライブのタレントと共に，マッチングしたほかのプレイヤーとオンラインで対局できる麻雀ゲームだ。
　ゲーム内に用意された
「控え室」
で自身の“推し”が設定できるようになっていて，選んだタレントをホーム画面に表示させたり，プレイ中に表示されるカットインやボイスで対局を盛り上げたりできる。
■実装タレント一覧（敬称略）
0期生：ときのそら / ロボ子さん / さくらみこ / AZKi
1期生：白上フブキ / 夏色まつり / アキ・ローゼンタール / 赤井はあと
2期生：百鬼あやめ / 癒月ちょこ / 大空スバル
ゲーマーズ：白上フブキ（1期生と兼ねる） / 大神ミオ / 猫又おかゆ
3期生：兎田ぺこら / 不知火フレア / 白銀ノエル / 宝鐘マリン
4期生：角巻わため / 常闇トワ / 姫森ルーナ
5期生：雪花ラミィ / 桃鈴ねね / 獅白ぼたん / 尾丸ポルカ
秘密結社holoX：ラプラス・ダークネス / 鷹嶺ルイ / 博衣こより / 風真いろは
ReGLOSS：音乃瀬奏 / 一条莉々華 / 儒烏風亭らでん / 轟はじめ
FLOW GLOW：響咲リオナ / 虎金妃笑虎 / 水宮 枢 / 輪堂千速 / 綺々羅々ヴィヴィ
このほかプロフィールやストーリー，ボイスを確認できるモードも用意されていて，対局以外でも好きなタレントの姿や声を楽しめる
　さらに目を引くのは，タレントごとの個性を取り入れた
演出や装飾アイテム
の数々だ。麻雀牌やリーチ棒，リーチ演出に加え，アイコンフレームまで細かくカスタマイズできるようになっていて，それぞれ好きなタレントのものを組み合わせられる。
　すべてを推しで統一するもよし，好みのユニットやモチーフで固めて自分だけのセットを作るもよしで，さまざまな楽しみ方ができる。
　また組み合わせたアイテムは，プリセットとして保存もできる。対戦相手の装飾を見て「その組み合わせもいいな」なんて思うこともあり，新しいアイテムを手に入れるたびに，装飾を考え直すことになりそうだった。
　麻雀に慣れていない人に向けたアシストも充実している。
　おすすめの打牌を示す機能に加え，対局画面には
「役候補表示」
や
「欲しい牌」
のボタンも用意されている。麻雀は役や定石を覚えるとなると，どうしても身構えてしまうものだが，まずはアシストを頼りに，少しずつ遊びながら覚えていける。
　さらにシングルモードでは，ホロライブのタレントを相手にしたCPU戦が行える。こちらには時間制限もないので，ゲーム内のガイドを確認したり，推しのボイスを聞いたりしながら，自分のペースで麻雀のルールに慣れていけるのがありがたい。
シングルモードのCPUは強さが選べるほか，タレントごとに「守備」「万能」「攻撃」といった打ち方の特徴も用意されている
推しの声や音楽で推し活を楽しむ
　対局をさらに賑やかにしてくれるのが，プレイ中に差し挟まれるタレントのセリフの数々だ。
　「莉々華もアガりたかった」「ロンされても諦めない」「1位のご褒美は，牛丼で決まりだね！」といったボイスには，タレントそれぞれの個性が表れている。
　役名の読み上げはもちろんのこと，ゲームの流れに応じたさまざまなリアクションが用意されていて，ファンなら全部のボイスを確認したくなること間違いなしだ。セリフには小ネタも詰まっていて，タレントのことをさらに知りたくなってしまう。
負ければもちろん悔しいが，そのときの反応まで聞きたくなってしまう
ボイス以外にも，牌を切るときの「手」にもタレントごとの個性が付けられている。手袋や袖口などのカスタマイズも可能で，まるでタレントと同じ卓を囲んでいるような感覚が味わえる
タッチ操作のスマホ版は，牌を切るときのアクションにもリアリティが感じられた。もちろん実物の牌を扱う感触とは違うが，操作感は良好で気持ちがいい
　ファンにとってうれしいのが，ホロライブの全体曲のアレンジ版がBGMとして使われているところだ。
　また，
「対局BGM」
と
「リーチBGM」
が別々に設定でき，その選択画面には
「Shiny Smily Story」
や
「Color Rise Harmony」
などの曲名が並んでいる。
　今回の試遊では，リーチがかかるとアップテンポな曲に切り替わるなど，対局の緊張感が増す選曲になっていた。こうした音楽の部分は，まさに本作ならではの要素といえるので，今後の楽曲追加にも期待したい。
知っている曲が流れると，やはりテンションがあがってくる。ファンにとってはうれしい要素だ
　セリフや装飾，そして音楽まで，あらゆるポイントで“推し活”が楽しめる本作。見慣れた牌の並ぶ卓が，カスタマイズを通して居心地の良い場所になっていく感覚を味わえたので，ファンならばプレイする価値はありだろう。
メディア対抗戦は，東風戦ルールによるトーナメント形式で実施された。2卓に分かれて行われた予選の上位2名が決勝に進む形で，4Gamerも決勝までは進めたが，残念ながら優勝は叶わなかった
対戦中の様子。卓を囲んだ相手の反応を見ながら遊べるのは，オフラインならではだ。初めて対局する相手とも，スタンプを使って和やかにコミュニケーションできたのは本作のおかげかも？
開発陣に聞く，本作の狙い。4Gamerオリジナル雀卓のプレゼントも
　対局後，Aimingとカバーそれぞれの開発担当者への質疑が合同で行われたので，その内容をピックアップして紹介しよう。
　本作の狙いについて，開発陣はまず初心者でも楽しめるものを目指したと話していた。
　麻雀というと，どうしてもハードルの高さを感じる人が少なくないが，身構えず，まず触れてみてほしいとのこと。また対人戦が苦手な人も楽しめるタイトルを目指しているという。
　カバー側としては，これまでのゲーム展開を踏まえ，ファンとホロライブ，配信の関わりを重視しているという話もあった。ファンが喜ぶことに加え，タレント自身が楽しめることも大切にしているという。
　またボイス収録のエピソードとしては，役名を読み上げるとき，麻雀に詳しくないタレントには，必殺技のような言い方でよいと伝えたという話も明らかにされた。
　継続して遊ぶ動機として挙げられたのが，
タレントとの親密度
の要素だ。
　これは特定のミッションをクリアしたり，ガチャなどで手に入るプレゼントを渡したりすると上昇し，ストーリーなどの開放が行われる仕組みだという。
　また各種アイテムの入手について，スタンプはタレントとセットだが，麻雀牌やリーチ棒，演出などは，個別のアイテムとしてガチャから排出されるとのことだった。
　今後の運営方針について問われた両者は，麻雀の対局を軸に，月1回程度のイベント開催を検討していると回答した。
　これは日々の対局と並行し，その時期のアイテムを獲得できるものを想定しているという。詳細は不明だが，普段の遊びの延長として楽しめる内容を目指しているそうなので，続報に期待したい。
　最後に，4Gamerのロゴをあしらった
オリジナル雀卓のシリアルコード
をAimingに用意してもらったので，これをお知らせして本稿の締めとしたい。コードは
【4gamermentanpin】
で，ゲーム内で入力すれば全員が受け取れるものになるとのこと。
　リリースは11月25日の予定なので，サービス開始後にぜひ活用してみてほしい。

本作の舞台は
「牌源郷」。

「拘束具によって真の力を封じられたまま、果たしてこの大会を勝ち抜くことはできるのか……？」
という紹介文からして、総帥の設定をしっかり押さえており早くも胸が高鳴る。

立直・平和・一気通貫・ドラ2・裏ドラ1。親の

悪の総帥にあるまじきこの隙の多さ

初心者に優しい各種アシスト機能

【推し活パート】推しが喋る・動く！推しと絆を結ぼう！
とにかく喋る！動く！ボイスの量に驚き
実際にプレイして驚いたのが、
タレントたちが本当によく動き、よく喋る
こと。ボイスが細かいところまで行き届いていて、ランクマッチや大会といったメニューを選んだ際の専用ボイスが用意されているほどだ。
対局中もずっと賑やかで、まるで
推したちがわいわい楽しく卓を囲んでいる
ところに、自分も混ぜてもらっているような感覚になれる。これはファンにはたまらない！
▲ボイスの収録量は驚くほど多い。ありがとう、ありがとう……
ちなみに、後述する「親密度レベル」を上げれば上げるほど、新規ボイスが解禁されていく仕様となっている。
控え室で、雀卓まるごと「総帥仕様」に！
推し活勢が一番時間を溶かしそうなのが、
対局で使うアクセサリーを設定できる「控え室」
だ。リーチ棒、リーチ演出、和了演出、鳴き待機演出、牌を切る「打ち手」、アイコンフレーム、雀卓、雀牌、さらに対局BGMやリーチBGMまで、自由に組み合わせられる。
もちろん筆者は
全部総帥のもので固めた
。リーチ棒も雀卓も総帥仕様で、雀牌は総帥のそばにいる長い付き合いのカラスをあしらった
「カラスの麻雀牌」
だ。
▲雀卓も雀牌も総帥カラーに
さらに打ち手を変えれば、
牌を切る手が総帥のトレードマークである萌え袖になる
というこだわりっぷり。
▲牌を切る「打ち手」は総帥の萌え袖に設定
そして注目してほしいのが演出の名前。リーチ演出は
「秘められし力」
、和了演出は
「解き放たれし力」
なのだ。
本来は頭も良く膨大な力を持ちながら、今はその大半が封印されているという総帥の設定を汲んで、リーチで力を溜め、アガリでその力を解き放つ。
この演出名、わかってらっしゃる！
▲リーチ演出は総帥専用の「秘められし力」
対局BGMには
「Shiny Smily Story」「夢見る空へ」「キラメキライダー☆」
など、ホロライブの楽曲をアレンジしたものがずらり。リーチBGMも別に設定できるので、勝負どころの盛り上がりも自分好みに演出できる。
▲対局BGMにはホロライブ楽曲のアレンジが並ぶ
ほかにも、カスタム画面ではコスチュームや対局中のカットインを切り替えられるし、
スタンプからお気に入りを登録しておくことも可能
。筆者のお気に入り1枠目は、当然
「刮目せよ！」
である。
▲お気に入りスタンプの1枠目は「刮目せよ！」
親密度を上げて推しと「絆」を結ぼう
タレントにプレゼントを贈ると
親密度がアップ
。プレゼントにはスイーツやアクセサリー、花束などさまざまな種類があり、1日に贈れる回数には上限があるので、
毎日コツコツ通うのが推しとの距離を縮める近道
だ。
プレゼント画面では、総帥が「そんでお姉さんたちに褒めてもらう！　吾輩は天才だ！！」とご満悦。
褒められたい総帥、かわいすぎませんか。
アイテムの中には、タレントの好みに合うと親密度がさらに上がりやすくなるものもある。
推しが喜ぶプレゼントを探す
のも、楽しみのひとつになりそうだ。
親密度は全5段階で、上げていくと
タレントにまつわるストーリーが順番に解放
されていく。推しの新たな一面を知るためにも、親密度上げは欠かせない。
さらに親密度を最大まで上げ、ペンライトやうちわといった推し活グッズ（！）の素材を集めると
「絆を結ぶ」
ことができる。絆を結ぶと、新たなストーリーやボイスが解放される仕組みだ。
ミッションをこなせば称号も手に入る。総帥の称号には
「ラプラス・ダークネス推し」「ラプラス・ダークネス一筋」「ラプラス・ダークネスしか勝たん」「ラプラス・ダークネスこそが至高」
などがずらりと並ぶ。ぷらすめいととしては、全部集めるしかない。
ガチャはタレントとアイテムの「混合型」
ガチャは、
タレントとアイテムが同じガチャから排出される混合型。
タレントごとにコスチュームとアクセサリーを合わせて8種類のアイテムがあり、それぞれ個別に排出される仕様だ。
ただし、タレントごとのピックアップガチャが開催される予定とのこと（詳細は後述のインタビューにて）。推しのアイテムを狙って集めやすくなりそうだ。

開発陣合同インタビュー
対抗戦後には、開発陣への合同インタビューが行われた。各メディアからの質問とその回答を、要点を絞ってお届けする。
──これまでホロライブのIPを使ってさまざまなタイトルを展開されてきましたが、その知見で本作に活かされたものはありますか？
開発陣
これまでのタイトルでも、ユーザーさん、ホロライブのIP、そして配信という3つの要素を掛け合わせたときに、どうすればお客さんにとって新しく、いいものになるかを考えてきました。また、ファンの皆さんだけでなく、タレントさんがいかに楽しめるか、喜べる状況を作れるか、という視点も大事にしています。
今作については、Aimingさんからデータ面でのご提案もいただいて、
「これは皆さんに喜んでいただけるのでは？」
という実感が後押しになりました。
──タレントさんが実際に触れてみた中で、面白い反応などはありましたか？
開発陣
アガリ時の役の読み上げは、タレントさんと収録する際に、麻雀に詳しくない方には
「必殺技みたいに言っちゃっていいですよ」
とお伝えしていて。とてもかわいらしく役名を読み上げてくださった方もいて、麻雀に詳しい方もそうでない方も、楽しんで収録していただけたと思います。
また、先日の情報解禁配信では、Aimingさんが作ってくださったリーチ演出のアニメーションがかわいいと好評でした。
──麻雀がよくわからない人にも本作を遊んでほしいと思いますが、どんな気持ちで遊べばいいでしょうか？
開発陣
気軽に遊べる機能をたくさん用意しています。対人戦が苦手な方向けには、CPUと対戦できるシングルモードがあり、持ち時間を無制限にしているので、どれを捨てようかじっくり考えながら進められます。
間違いなく楽しめる内容になっているので、
少しでも面白そうだと思ってもらえたら、ぜひ「麻雀」という言葉に壁を感じず、インストールして遊んでみてほしい
です。
──麻雀ゲームは長く遊んでもらうことが不可欠だと思いますが、ゲーム体験の設計で意識した点は？
開発陣
毎日の対局やミッションのクリアでプレゼントアイテムがもらえて、それをタレントにコツコツ渡していくことで親密度が上がり、新しいストーリーが読めるようになったりします。推しが好きな方には、ぜひ毎日遊んでほしいですね。
また、
麻雀部分は本格的に作っている
ので、ホロライブを知らない麻雀好きの方でも、強い方同士でしっかりバチバチやり合えるようになっています。
──キャラクターや装飾品の入手方法について教えてください。
開発陣
最初の1人は自分で選べる形になっています。装飾品は一部ゲーム内で手に入るものもありますが、基本的にはガチャから入手していただく形です。
推しのアクセサリーを全部集めたいという楽しみ方もありますし、シングルモードなどで他のタレントさんの見た目や装飾品を目にして「この人もいいな」と思っていただけたら嬉しいです。ガチャだけでなく、一人ひとりのキャラクターの魅力をしっかり伝えていきたいと考えています。
──ガチャはタレントとアイテムが同じガチャに入っているのでしょうか？
開発陣
37名全員が入っているガチャを基本に、タレントさん一人ひとりをピックアップしたガチャも開催していこうと思っています。
ピックアップ時はそのタレントさんのアクセサリーも一緒にピックアップされるので、タレントさんを引けた頃には、周りの装飾品も大体そろっているくらいのイメージです。なお、牌やリーチ棒、演出などはそれぞれ別のアイテムとして排出されます。
──BGMについて教えてください。
開発陣
ホロライブの楽曲をアレンジしたBGMが、現在10曲ほど入っています。
各曲テーマ性を持ってアレンジしていただいている
ので、ぜひ聴いてみてください。
──麻雀ゲームの発表に対して、タレントさんの反応はいかがでしたか？
開発陣
博衣こよりさんはとても喜んでくださいましたし、麻雀好きのタレントさんからは収録時に
「オープンリーチを実装してください！」
といった要望もいただきました。
普段から麻雀が好きなタレントさんほど、「ホロライブの麻雀ゲームが出るのが素直に嬉しい」と言ってくださっていましたね。
──今後のイベントやアップデートの予定は？
開発陣
麻雀の対局を主軸に据えつつ、それだけだと飽きてしまうと思うので、月1回ほどイベントを用意する予定です。対局をしていれば自然とイベントもクリアでき、その時期にしか手に入らないアイテムがもらえる、といった形を考えています。
アップデートでは、イベントやルールの追加に加え、リリース後にいただいたご要望などを反映して、細かな部分も改善していきます。
