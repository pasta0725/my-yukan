160.0
Firefox Release
November 10, 2026
Version 160.0, first offered to Release channel users on November 10, 2026
                            New
The 
Picture-in-Picture
 player now has a playback speed setting, with options ranging from 0.25x to 2.0x speed. The setting appears only when the player window is medium-sized or larger.
Mini Window moves a tab or a selected part of a page into an always-on-top window while browsing. We’d appreciate feedback on 
Mozilla Connect
 as we develop and improve this early version of the feature.
History entries can now be dragged from the sidebar to the tab strip to open them in new tabs.
The address bar context menu now shows "Paste and Search" instead of "Paste and Go" when the copied text is a search term rather than a web address.
Pages saved as PDF now make mathematical content (MathML) accessible to assistive technology such as screen readers.
Websites that repeatedly ask to handle email (mailto:) and other links can now be blocked with a new “Never allow” button, and blocked sites can be managed in Settings.
Firefox now plays Matroska (MKV) files with FLAC, MP3, or PCM audio.
WebGL content on macOS is now rendered using Apple's Metal graphics API, which can improve performance on some sites.
In 
Smart Window
, Organize Tabs is now available in French. Firefox can suggest groups of related open tabs and name each group in French.
This feature is part of a progressive roll out.
What is a progressive roll out?
Certain new Firefox features are released gradually. This means some users will see the feature before everyone does. This approach helps to get early feedback to catch bugs and improve behavior quickly, meaning more Firefox users overall have a better experience.
                            Fixed
Fixed the first character typed into the address bar or search bar sometimes being lost when typing quickly right after clicking into it.
Increased the contrast between the domain name and the rest of the address in the address bar, making it easier to see which website is open.
Fixed Firefox freezing for several seconds when signing in to intranet sites that use NTLM or Kerberos (Negotiate) authentication.
Fixed double-tapping or long-pressing a word to select it, and tapping to place the cursor, not working near the cursor in text fields.
Fixed links opened in the background from other apps on macOS, such as RSS readers, bringing Firefox to the foreground.
Fixed downloaded files on macOS sometimes opening in the wrong application instead of the default one set in Finder.
Fixed simultaneous downloads on macOS never finishing when Firefox is set to ask where to save files. Only the first file showed a save dialog.
Restored meaningful filenames and the usual save workflow for PDFs opened in Preview from the macOS print dialog.
