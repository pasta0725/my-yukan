Microsoft now automatically installs Windows 11 26H2 on unmanaged devices
                            By 
Sergiu Gatlan
November 20, 2026
07:14 AM
1
Starting this week, Microsoft has begun automatically upgrading eligible devices that aren't managed by an IT department to Windows 11 26H2.
As the rollout progresses, more Windows 11 devices will upgrade automatically, without users having to check for updates manually.
The automatic upgrade depends on each device's Windows Update settings and is available for personal and non-managed business devices running Windows 11 24H2 and 25H2.
"Since late October 2026, all devices eligible to run Windows 11 have been able to get version 26H2 by manually checking for updates. Starting November 18, we are taking the next step in version 26H2's phased rollout to make it easier to get the update," 
Microsoft said
 in a release health dashboard update.
"We are gradually expanding automatic delivery, beginning with devices running Windows 11, versions 24H2 and 25H2, that are not managed by IT departments."
You can also manually install Windows 11 26H2 after checking for the update by going to Settings > Windows Update and selecting "Check for Windows updates," and you can ensure that it's installed as soon as possible by toggling the "Get the latest updates as soon as they're available." option.
Also known as the Windows 11 2026 Update, Windows 11 26H2 
became generally available
 in September 2026 as an enablement package and will reach end of support in less than three years, in October 2029.
"This new version contains all the recently announced features in Windows 11, versions 25H2 and 24H2. It's delivered using servicing technology, providing a fast installation experience," Microsoft says.
Last month, Microsoft also warned customers to upgrade devices running unsupported versions of Windows, as they 
will stop receiving security updates
 after next year's Windows Update certificate rotation.
More information about Windows 11 servicing dates is available using the 
Lifecycle Policy search tool
 or on the 
Windows Lifecycle FAQ page
.
On Wednesday, 
Microsoft confirmed
 that this month's hotpatch for devices running Windows 11 24H2 and later is causing installation and launch issues for Office and third-party applications.

(status 200)
Windows 11 version 26H2, the latest version of the OS released officially released on September 29, 2026, is now available on more PCs. Until now, the update was available for early adopters with compatible devices via the “seeker” experience in Windows Update, but Microsoft is now ready to roll out the update automatically on supported PCs.
“We are gradually expanding automatic delivery, beginning with devices running Windows 11, versions 24H2 and 25H2, that are not managed by IT departments,” the company said yesterday on the 
Windows Release Health dashboard
. “As the rollout progresses, more devices receive the update automatically, without needing to check for updates or initiate the download manually. This process depends on Windows Update settings and is available for personal devices and non-managed business devices.”
As a reminder, Windows 11 version 26H2 is being delivered via an enablement package on PCs running versions 25H2 and 24H2 of the OS. The update doesn’t have exclusive new features, but it enables everything that Microsoft is gradually rolling out to users still on older versions of the OS. It also reboots the support cycle, with 24 months of support for Home and Pro users, and 36 months for Enterprise and Education users.
A last note about new ARM-based PCs running Windows 11 version 26H1: The 26H2 update isn’t available for these devices, as the version 26H1 is based on a different core. The upcoming 27H2 update, which will be released next year, is expected to be available for both x86 and ARM-based PCs.

===== https://windowsreport.com/microsoft-expands-windows-11-26h2-rollout-no-manual-update-check-needed/
(status 200)
Image credit: Microsoft
Microsoft has expanded the rollout of Windows 11 26H2, allowing more eligible PCs to receive the latest feature update automatically through Windows Update.
According to 
Microsoft’s Windows release health dashboard
, the expanded rollout began on November 18, 2026, and targets devices running Windows 11 24H2 and 25H2.
The automatic rollout applies to personal computers and business devices that IT departments do not manage.
Windows 11 26H2 is reaching more PCs automatically
Microsoft confirmed that all eligible devices have been able to manually download Windows 11 26H2 since late October. The company is now gradually expanding automatic delivery, meaning users no longer need to manually check for the update.
However, Microsoft is rolling out the update in phases, so not every eligible PC will receive it immediately. The timing also depends on individual Windows Update settings.
The expanded rollout covers both Windows 11 24H2 and 25H2, allowing users on either version to move to Windows 11 26H2.
Microsoft has also made it possible for users with 
eligible Windows 10 PCs to upgrade directly to Windows 11 26H2
, without installing an earlier Windows 11 version first.
Users can still install Windows 11 26H2 manually
Users who do not want to wait for the automatic rollout can open 
Settings > Windows Update
 and select 
Check for updates
.
If Windows 11 26H2 is available for their device, they can follow the instructions to install it.
Microsoft will continue expanding availability to more eligible PCs over the coming weeks.
In other Windows news, Microsoft recently 
released new Defender updates for Windows 10 and 11 ISO images
, improving security for fresh installations.
The company also 
updated the Windows 11 Media Creation Tool
 to include the November 2026 cumulative update KB5132061, allowing users to create installation media with the latest security fixes.
